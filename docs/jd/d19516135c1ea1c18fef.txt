McKesson Prescription Automation Solutions, or MAPS, develops software that supports large-scale automated pharmacy fulfillment operations across the United States. Our technology connects software, robotics, conveyor systems, databases, APIs, and user applications to help pharmacies deliver medications safely, accurately, and efficiently. As a Software Engineer, you will design, develop, enhance, and support software for mission-critical pharmacy automation systems. You will work across Windows-based desktop applications, backend services, distributed systems, databases, hardware integrations, and modern user interfaces. You will collaborate with product management, automation engineering, quality assurance, operations, customer support, and customers to solve complex technical challenges. This is an opportunity to work across the full software development lifecycle, contribute to technical decisions, modernize established applications, and see the direct operational impact of your work. What You’ll Do Design, develop, test, deploy, and support software for large-scale automated pharmacy fulfillment systems. Enhance and modernize Windows-based applications developed with C++ and Microsoft Foundation Classes, or MFC. Build and maintain scalable backend services, multi-threaded applications, distributed systems, databases, and RESTful API integrations. Translate customer, business, and technical requirements into reliable and maintainable software solutions. Integrate software with robotics, conveyor systems, industrial automation equipment, and other hardware devices. Investigate complex production issues, perform root-cause analysis, and implement sustainable corrective actions. Monitor and improve application performance, reliability, scalability, maintainability, and availability. Apply software engineering practices such as source control, code review, automated testing, Test-Driven Development, and continuous integration and delivery. Collaborate with engineering, product, quality, deployment, support, and operations teams throughout the software development lifecycle. Participate in customer discussions, technical reviews, troubleshooting sessions, and solution-design activities. Contribute to technical planning and architecture discussions involving system integrations, application modernization, and product enhancements. Participate in an on-call rotation supporting mission-critical applications during designated evenings and weekends. Basic Requirements Degree or equivalent experience and typically 4 or more years of relevant professional software development experience. Professional experience developing Windows-based software applications using C++ and MFC . Experience developing multi-threaded or distributed applications . Experience working with relational databases and SQL using Microsoft SQL Server, MySQL, or a comparable platform . Experience troubleshooting complex software or production issues and performing root-cause analysis. Experience using Git or another version-control system . Experience with continuous integration, automated testing, or Test-Driven Development. Ability to participate in an evening and weekend on-call support rotation. Authorization to work in the United States. Preferred Skills/Experience Service-Oriented Architecture, microservices, or RESTful API development and integration. Entity Framework or Entity Framework Core. WPF, WCF, MVVM, or other Windows desktop application technologies. Angular, React, HTML5, JavaScript, or other modern web technologies. Jenkins, CI/CD pipelines, DevOps practices, or release automation. Application monitoring, observability, performance analysis, or performance-tuning tools. Hardware integration using sockets, serial communication, or similar protocols. Industrial automation, robotics, programmable logic controllers, or Beckhoff control systems. Windows administration, Active Directory, VPNs, firewalls, or network-connectivity troubleshooting. Software development experience in healthcare, pharmacy operations, manufacturing, fulfillment, logistics, or another regulated, mission-critical environment. Experience working with customers, operations teams, or nontechnical business stakeholders. Travel, Work Environment and Physical Requirements This position is eligible for remote work within the United States, subject to McKesson’s applicable workplace policies. Ability to travel up to 20% for customer engagements, site visits, installations, and team collaboration. Participation in a scheduled on-call rotation may require evening or weekend availability.
