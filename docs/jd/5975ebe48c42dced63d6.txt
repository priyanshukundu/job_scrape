Senior Security Software Engineer - AV Platform
NVIDIA
Location: US, CA, Santa Clara
Link: https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite/job/US-CA-Santa-Clara/Senior-Security-Software-Engineer---AV-Platform_JR2027143

The Autonomous Vehicles Platform team is looking for a hands-on Cybersecurity Software Engineer. As part of our team, you will work on our Autonomous Driving Platform software, implementing performant and scalable solutions for data collection and autonomous vehicle fleets. Our team is responsible for developing platform and middleware features for self-driving cars. This includes software security features that interact with various sensors including Cameras, LIDAR, RADAR, GPS, IMU, Vehicle CAN etc. We are seeking candidates with interests in implementing security concepts and developing state-of-the-art security features for AV Platform. The role encompasses working with various teams across the stack, from platform and embedded software to cloud infrastructure, underpinned by safety and performance. It extends an opportunity to contribute to the technology that will drive the cars of the future! What you'll be doing: Integrating security features into our AV driving software stack. Develop and improve security work-products for our AV stack. Working on security-related software code ranging from sensor abstraction layers to data processing to middleware software. Work on security governance topics and guide other teams with security mechanism implementation. Collaborate with hardware, platform software, product, safety, performance, algorithms and cloud teams. What we need to see: BS or MS degree in Computer Science, Electrical Engineering, or related field (or equivalent experience). 5+ year of professional experience working on system software. Excellent programming skills in C++, C and Python. Experience in architectural security analysis techniques such as threat modeling, risk analysis, attack trees, etc. (using STRIDE, HEAVENS) and managing resultant Product Security Requirements. Experience with automotive cybersecurity standards/regulations (e.g., ISO 21434, SAE J3061, UNECE Regulation 155) or other standards/regulations relevant to the automotive industry and/or cybersecurity (e.g., GDPR). Solid understanding of Linux, QNX, ROS, and/or real-time operating systems. Experience in developing user-space system software, with a willingness to delve into kernel-space and/or low-level hardware when needed. Knowledge about embedded system programming, threading, mutex, synchronization, communication, and parallel computing to build highly-scalable and efficient applications. Prior experience working in the following areas: Autonomous Vehicles, Robotics, Self-Driving-Cars, CPU/GPU technology, Embedded Systems, Computer Vision. Ways to stand out from the crowd: Deep understanding of system architecture, CPU/GPU/Memory/Storage, everything related to performance optimization. Experience in Autonomous Vehicle or Robotic system building. Hand-on experience in embedded development, operating systems and real-time software. Your base salary will be determined based on your location, experience, and other objective job-related factors. The expected base salary ranges for this position are: 152,000 USD – 241,500 USD for Level 3; and 184,000 USD – 287,500 USD for Level 4. You will also be eligible for equity and benefits .
