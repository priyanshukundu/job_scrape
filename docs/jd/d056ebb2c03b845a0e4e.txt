Duties: Collaborate with various product, infrastructure, operations, security, and production control teams to elicit and fulfil technical requirements of these teams. Manage and support AWS Infrastructure, using AWS EC2, IAM, S3, VPC, AMI and security groups. Automate deployment and configuration of AWS infrastructure using Ansible and Terraform, managing EC2 instances, VPC networking, IAM access controls, S3 storage, and ELB load balancer services to support scalable and high available infrastructure. Develop automation frameworks using Terraform to manage configuration of Apache Kafka and IBM MQ messaging systems, performing validation of topic and queue configuration, message routing workflows, and consumer processing to ensure reliable data exchange between distributed systems. Deploy and repave Kafka clusters for developers using Terraform, Jenkins, Ansible and Docker. Perform Harness deployments through HELM chart and Kubernetes clusters. Provision and operate Kubernetes clusters on AWS infrastructure by configuring worker nodes, network policies, and persistent storage, managing cluster lifecycle through Rancher, packaging and deploying applications using Helm and Harness deployment pipelines and implementing secret management through HashiCorp Vault. Design and implement end-to-end CI/CD automation pipelines using Jenkins Groovy scripting, GitHub source control, enabling automated build and testing workflows, static code analysis using SonarQube, security scanning using Veracode and Sysdig, artifact management using JFrog and deployment of Docker containerized applications across development, staging and production environments. Elicit requirements for sizing of application deployments to manage expected workload. Monitor and tune the performance of applications working with product teams. Confer with product teams leads and practitioners to create deployment plans. Confer with the Enterprise Architecture and Product Architecture teams to devise implementation details. Promote standards across application configuration towards the highest security. Collaborate with access management and security teams on setting up roles and permissions for systems and users using least privilege strategies. Collaborate with the integration/performance testing team to leverage integrated release tests in Integration/Release Acceptance environments. Collaborate with operations and enablement teams to deliver, configure, and test applications. Collaborate with production controls teams on monitoring, failover, logging, etc. Provide guidance to systems and DevOps engineers for building highly performant environment. Ideate and implement infrastructure failover scenarios. Confer with networking teams on connectivity details and issue resolution, including between on-premises and AWS. Perform deployment of applications in VM based as well as container-based deployments. Develop documentation for operations of SDLC pipelines and practices to enable technical support of applications and infrastructure. About Us The Options Clearing Corporation (OCC) is the world's largest equity derivatives clearing organization. Founded in 1973, OCC is dedicated to promoting stability and market integrity by delivering clearing and settlement services for options, futures and securities lending transactions. As a Systemically Important Financial Market Utility (SIFMU), OCC operates under the jurisdiction of the U.S. Securities and Exchange Commission (SEC), the U.S. Commodity Futures Trading Commission (CFTC), and the Board of Governors of the Federal Reserve System. OCC has more than 100 clearing members and provides central counterparty (CCP) clearing and settlement services to 19 exchanges and trading platforms.
