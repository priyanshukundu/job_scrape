Job Description: Job Title: Associate Location: Cary, NC Overview DB Global Technology, Inc. seeks an Associate in Cary, NC to analyze and evaluate business requirements including collecting, interpreting, and mapping customer requirements to product capabilities. Requires a Master’s degree in Computer Science, or related field, or equivalent and one (1) year of experience fixing production issues in end-to end software development using Java, Spring Boot, Git, and Shell Scripting; performing backend development and RESTful API design to support low latency systems using Spring framework, Spring MVC, and JDK17; building scalable, fault tolerant data layers using SQL and Oracle PL/SQL procedural databases; utilizing CI/CD processing tools, including Jenkins, Maven, Git, and Gradle for source control, automated builds, dependency management and continuous deployment; utilizing Java, Shell, SQL, and PL/SQL for scripting, service orchestration, infrastructure automation and backend development; performing Unit and integration testing using Junit and Mockito to produce and maintain high quality code; and using frameworks including Spring Boot, Rest, CI/CD, Junit, Git, and Kubernetes to build, deploy, scale and monitor services in production. Salary range: $118,736.00 – $140,000.00/year. This position is eligible for Deutsche Bank's Employee Referral Incentive Program.
