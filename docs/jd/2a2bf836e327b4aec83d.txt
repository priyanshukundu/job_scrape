Job Description This position will be responsible for the analysis, design, testing, development and maintenance of best in class software experiences. The candidate is a self-motivated individual who can collaborate with a team and across the organization. The candidate takes responsibility of the software artifacts produced adhering to U.S. Bank standards in order to ensure minimal impact to the customer experience. The candidate will be adept with the agile software development lifecycle and DevOps principles. Essential Responsibilities: Design, develop, test, deploy, and support scalable backend applications and services using Java and Spring Boot . Build and maintain RESTful APIs and microservices that support reliable, high-volume business applications. Provide technical leadership throughout the software development lifecycle , from solution design and development through production implementation and support. Develop solutions using Spring Boot, Spring MVC, Spring Data, Spring Security , and related Java technologies. Design and support event-driven architectures using technologies such as Kafka and other messaging platforms. Develop applications that integrate with relational and NoSQL databases , ensuring efficient data access and application performance. Apply strong engineering practices around security, authentication, authorization, API security, resiliency, and data protection . Build comprehensive unit and automated tests using tools such as JUnit and Mockito to improve code quality and reliability. Support CI/CD, automated deployments, containerization, and cloud-native development using technologies such as Git, Maven/Gradle, Docker, and Kubernetes. Leverage AI-assisted development tools such as GitHub Copilot, Claude Code, or similar GenAI coding assistants to enhance development, testing, debugging, documentation, and engineering productivity while following responsible and secure development practices. Perform code reviews , establish development best practices, and help ensure solutions meet engineering, security, performance, and maintainability standards. Troubleshoot complex application and production issues, perform root-cause analysis , and implement solutions that improve system reliability and performance. Partner with architects, product owners, engineering teams, and other technology stakeholders to translate business requirements into effective technical solutions. Identify opportunities to modernize applications, reduce technical debt, automate development processes, and improve overall engineering efficiency. Provide technical guidance and mentorship to other engineers, sharing knowledge and promoting consistent engineering practices. Participate in Agile/Scrum ceremonies , technical design discussions, estimation, planning, and continuous improvement activities. Stay current with emerging backend, cloud, security, and generative AI development technologies and evaluate their appropriate use within enterprise applications. Basic Qualifications : Bachelor’s degree, or equivalent work experience Five to six years of relevant experience Preferred Skills & Qualifications: Strong hands-on experience with Java and Spring Boot for backend application development. Experience designing and developing RESTful APIs and microservices . Strong understanding of Spring Framework , including Spring MVC, Spring Data, and Spring Security. Experience with microservices architecture and distributed systems. Strong knowledge of SQL and relational databases ; NoSQL experience is a plus. Experience with Node, NPM and React framework , producing hygiene and secure front-end code. Experience with Kafka or other event-driven/messaging technologies . Familiarity with cloud platforms and scalable backend application development. Experience with Docker, Kubernetes, CI/CD, Git, and Maven/Gradle . Strong experience with unit and automated testing , including JUnit and Mockito. Experience developing high-volume, scalable, reliable, and secure backend services . Understanding of application security, authentication, authorization, and secure API development . Exposure to AI-assisted development tools such as GitHub Copilot, Claude Code, or similar generative AI coding tools to support code development, testing, debugging, documentation, and developer productivity. Familiarity with responsible and secure use of AI-assisted development tools , particularly when working with proprietary or sensitive code. Strong debugging, troubleshooting, and performance-optimization skills. Experience working in Agile/Scrum environments . Previous experience in banking, financial services, payments, or other regulated environments is a plus.
