Job Title Senior Software Engineer – Cloud Data Solutions About your role In this role, you will contribute to the development and support of the cloud-native Vision NEXT platform — Fiserv's next-generation, cloud-native card issuing and payment processing platform built on microservices, APIs, and event-driven architecture — leveraging APIs, event-driven architectures, AWS services, real-time authorization capabilities, and enterprise data platforms. You will serve as a technical resource for application development, data integration, analytics enablement, and client implementations while providing software solutions for our LATAM partners. What you'll do Design, develop, test, and implement software applications supporting Fiserv's Vision NEXT platform. Build event-driven data ingestion (RabbitMQ, webhooks) applying retry and idempotency patterns to ensure reliable, exactly-once processing. Design, build, and maintain data pipelines supporting enterprise data lake and analytics initiatives. Support ingestion, transformation, and integration of large-volume data sets across multiple platforms and applications. Collaborate with data engineering and analytics teams to optimize data processing, accessibility, and reporting capabilities. Develop and support Snowflake-based solutions for data storage, transformation, and consumption. Build API and data-validation test automation using RestAssured, Karate, and Postman/Newman. Ensure high standards for coding, testing, debugging, performance, security, and application reliability. Participate in code reviews to ensure adherence to coding standards, security requirements, and engineering best practices. Support cloud-native applications deployed within AWS environments. Monitor system and data platform performance and assist with troubleshooting production issues. Partner with clients and internal teams during implementations, upgrades, migrations, and production support activities. Experience you'll need to have 6+ years of experience in software development, software engineering, data engineering, or related technology disciplines. 3+ years of hands-on experience with Java, C#, C++, C, Python, or similar programming languages. 3+ years of experience working with SQL databases and data management solutions. 2+ years of experience developing or supporting applications within AWS, Azure, or Google Cloud Platform (GCP) environments. Experience working with APIs, microservices, and distributed application architectures. Experience working with Snowflake, Data Lake technologies, or modern cloud-based data platforms. Bilingual proficiency in Spanish or Portuguese. Bachelor’s degree in information technology, Computer Science, Engineering, Data Science, or a related field, or an equivalent combination of education, professional experience, and/or military experience. Experience that would be great to have Experience within financial services, payments, banking, or fintech environments. Experience with cloud-native architectures, event-driven systems, APIs, and real-time transaction processing platforms. Java/Spring Boot experience for building data integration services and APIs. Experience with event-driven ingestion patterns (RabbitMQ, webhooks, retry/idempotency) feeding data pipelines. API and data-validation test automation (RestAssured, Karate, Postman/Newman). Ability to write technical specifications for data integrations and pipelines. Experience applying promotion criteria that include data-quality gates beyond code quality. Hands-on use of AI tools, including AI/ML-enabled data and analytics use cases, with real production examples. Familiarity with running or deploying data workloads on Kubernetes or Red Hat OpenShift. Experience with Snowflake features including data sharing, Snowpark, Streams, Tasks, and performance optimization. Experience in designing and supporting enterprise data lakes within AWS environments. Experience with AWS data services such as S3, Glue, Lambda, Athena, Redshift, EMR, or related technologies. Familiarity with VisionPLUS, Vision NEXT, or large-scale card processing platforms. Important information about this role This is a fully onsite position, Monday through Friday. Fiserv believes in the value of in-person collaboration, which supports effective onboarding, drives innovation, strengthens teamwork, and enhances overall productivity. Must possess U.S. Citizenship or U.S. Permanent Resident (Green Card) status. Strong verbal and written communication skills are required.
