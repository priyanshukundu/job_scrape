Job Title Senior Software Engineer, Java Server Senior Software Engineer, Java Server What does a successful Senior Software Engineer, Java Server do at Fiserv? As a Senior Software Engineer on our Clover team, you will build and maintain cutting-edge merchant-facing applications that power business-critical point-of-sale systems and support multi-location business needs. You will work closely with our Infrastructure and Product teams in a fast-paced environment to deliver robust, scalable cloud services that impact millions of merchants daily. In this role, you will own your services end-to-end, balancing priorities and driving feature releases every other week while directly contributing to our merchant-facing platform. What you will do: Develop cloud-hosted services and features to translate product requirements into functional, maintainable, and extensible software. Design and implement Representational State Transfer Application Programming Interfaces (REST APIs) for mobile and web clients, payment devices, and third-party applications. Own merchant-facing services from initial development through deployment and production monitoring. Review peer code and designs while providing mentorship across the engineering team. Collaborate with the Infrastructure team to design data models supporting large-scale, highly available services. Partner with Quality Assurance (QA) teams to develop comprehensive test plans and strategies. Participate in an Agile Software Development Life Cycle (SDLC), including regular planning sessions, sprint boards, and on-call rotations to resolve production issues. What you will need to have: You will need 6+ years of experience in Java development. You will need 6+ years of experience in relational databases such as Structured Query Language (MySQL). You will need 6+ years of experience in API design. You will need 2+ years of experience in analytical databases such as Snowflake. You will need 2+ years of experience in Agile methodologies, including Scrum. Bachelor’s degree in Computer Science, Information Technology, or a relevant field, or an equivalent combination of education, work, and/or military experience. What would be great to have: Experience building microservices using frameworks like Spring Boot. Proficiency with containerization and orchestration tools, specifically Docker and Kubernetes. Hands-on experience with cloud platforms, preferably Google Cloud Platform (GCP). Scripting experience with Python and data warehousing expertise in Snowflake. Experience writing complex SQL queries using Java Database Connectivity (JDBC). Salary Range $110,000.00 - $186,000.00 These pay ranges apply to employees in New Jersey and New York.
