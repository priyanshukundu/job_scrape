Job Description Our team is growing, and we are looking for a curious, collaborative, and technically motivated Product Intelligence Consultant. This role will help design, build, enhance, and support internal applications and data-driven workflow solutions that reduce manual effort, improve operational processes, and give business partners reliable tools for managing their work. What You Will Do •Work with business partners to understand operational pain points, gather requirements, and translate them into practical application, workflow, automation, and data solutions. •Assist with developing and enhancing internal web applications and workflow tools using technologies such as C#, .NET, ASP.NET Core, Blazor or Razor, HTML, CSS, JavaScript, and related frameworks. •Build user-friendly application features for work intake, queue management, assignment, status tracking, quality processes, and operational support. •Help design integrations that move data between internal applications, SQL Server or Oracle databases, SharePoint, flat files, and other approved data sources. •Identify opportunities to replace manual spreadsheets, file transfers, and repetitive tasks with reliable application features, scheduled processes, scripts, or system integrations. •Participate in requirements analysis, solution design, coding, testing, deployment, and production support. •Investigate application defects, data issues, performance concerns, and user-reported problems; document findings and implement or recommend appropriate corrections. API and Integration Expectations •Assist with designing, developing, testing, and documenting secure REST API endpoints for workflow, application, and data integration needs. •Work with HTTP methods, JSON payloads, status codes, authentication, authorization, input validation, error handling, logging, and versioning. •Use Swagger/OpenAPI, Postman, or similar tools to review contracts, test endpoints, and document API behavior. •Build or support integrations between applications and approved enterprise data sources while following security and access-control requirements. •Look for opportunities to create reusable services or APIs that reduce duplicate logic and improve consistency across applications. Application Development Expectations •Apply foundational object-oriented programming and software development concepts to create clear, maintainable, and reusable code. •Use Git-based source control, feature branches, pull requests, and peer review practices to manage changes safely. •Create responsive and accessible user interfaces that provide a consistent experience across supported internal applications. •Assist with application deployments to development, test, and production environments and perform post-deployment validation. •Contribute to modernization of legacy applications and adoption of reusable components and current supported frameworks. What You Bring •University degree, college diploma, bootcamp credential, or equivalent practical experience in computer science, software development, information systems, analytics, engineering, or a related field. •Up to 2 years of relevant professional, internship, co-op, academic, or project experience in application development, data development, automation, or systems integration. •Foundational programming experience in C#, Python, JavaScript, PowerShell, or a similar language, with a willingness to develop deeper C# and .NET skills. •Foundational SQL skills and an understanding of relational databases, tables, joins, stored procedures, and data integrity. •Strong understanding of web applications, APIs, client-server concepts, and application-to-application data exchange. •Strong analytical thinking, attention to detail, curiosity, and willingness to learn unfamiliar technologies and business processes. Nice to Have •Exposure to ASP.NET Core, Blazor, Razor, Dapper, REST APIs, JSON, HTML, CSS, JavaScript, or responsive UI frameworks. •Experience with Microsoft SQL Server, Oracle, SSIS, SQL Agent, ETL processes, or scheduled automation. •Familiarity with Visual Studio, Git, CI/CD pipelines, IIS, Windows Server, application logging, or monitoring tools. What Success Looks Like •Delivers accurate, tested, and documented application changes on agreed timelines. •Asks thoughtful questions, learns the business process behind the request, and applies feedback to improve future work. •Gradually takes ownership of application features, database components, automations, APIs, integrations, and support activities of increasing complexity. •Builds trusted relationships with teammates and business partners through clear communication and reliable follow-through. •Contributes ideas that improve application reliability, maintainability, security, user experience, and team efficiency.
