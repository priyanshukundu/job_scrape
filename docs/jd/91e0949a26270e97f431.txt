Job Summary This role is responsible for driving the technical incubation of new AI technologies, exploring emerging market frameworks, and evaluating how next-generation AI software components impact client compute platforms. We are looking for an experienced software engineer who understands the deep relationship between AI models and memory architectures, hardware-level inferencing mechanics, and system execution runtimes (such as llama.cpp). Rather than focusing on developing or training foundation models, this role centers on systems-level AI execution: understanding how model architecture, precision, and quantization choices affect memory footprint, bandwidth, latency, compute utilization, and overall system performance. The role identifies execution bottlenecks, tunes optimization dials, analyzes hardware impact, and implements software optimizations. The role plays a crucial part in partnering with ecosystem leaders to run proof-of-concepts, define architectural requirements, and shape future hardware-software co-design strategies. Responsibilities Leads the technical evaluation and incubation of emerging AI technologies and software components from partners and the broader market, assessing their direct implications on client computers and system memory. Develops prototypes and implements software/runtime optimizations to improve AI workload execution, including instrumentation and changes to inference runtimes, memory-management strategies, scheduling, caching, and hardware resource utilization. Analyzes how AI workloads map across CPU, GPU, NPU (heterogeneous execution), system RAM, VRAM/shared memory, and storage, including KV cache management, memory movement, memory overhead, memory contention, bandwidth constraints, footprint scaling, allocation efficiency Investigates hardware inferencing mechanics and system runtimes (such as llama.cpp) to identify AI execution bottlenecks and optimization opportunities: measuring memory utilization, latency (e.g. time-to-first-token), throughput (tokens-per-second), inter-token latency, model load time, memory pressure, paging, and data movement (which impacts power, and overall PC resources). Evaluates the impact of concurrent AI and non-AI workloads on foreground application responsiveness, inference latency and throughput, system stability, power consumption, and battery life. Investigates workload prioritization and Quality of Service across CPU, GPU, and NPU resources, including how applications, agents, and OEM software can communicate workload intent and respond to system conditions. Translates AI workload behavior and profiling results into system architecture requirements and recommendations, including memory capacity, bandwidth, compute-engine selection, power/performance trade-offs, and opportunities for hardware-software co-optimization. Collaborates with silicon & OS partners, and software ecosystem partners to execute hardware-software proof-of-concepts (POCs), validating system performance and telemetry under realistic AI workloads. Designs and develops software tools, telemetry scripts, and run AI benchmarks to measure power, performance, thermal, and memory degradation boundaries thru test plans, success criteria, and experimentation methodologies.
