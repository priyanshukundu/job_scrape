The Web Platform team delivers performance as a service to BILL's engineering organization. By producing products for engineers, such as normalized client integrations with backend services, optimized project templates, libraries, and tools, the team enables higher velocity, consistent practices, and ease of constructing experiences in our composable architecture.BILL is transforming how software gets built, and the Web Platform team is the voice of the web and UI layer in that transformation. This Sr. Staff Software Engineer will build on and contribute to the AI Platform inference platform and software factory to shape an agentic software development lifecycle for application teams: one where AI agents do much of the building, testing, and modernizing, and humans stay in the loop where judgment matters most. The role sets architecture and governance direction for the web and UI layer, supports design across application and feature teams, and architects how BILL runs distributed campaigns that use the factory to make broad changes across many repositories and technologies. The role is cross-organizational and requires technical depth as well as the ability to bring people along as the way we work changes. What you will do Drive architecture and governance for the web and UI layer, including GraphQL backend conventions, through RFCs and architecture decisions that application and feature teams adopt. Support high-level and low-level design across application and feature teams, unblocking decisions and keeping web and UI standards consistent as agent-produced code scales. Tailor agentic workflows to the application lifecycle, defining human-in-the-loop (HITL) cut points, autonomy boundaries, and quality gates for UI and web work. Partner with AI Platform teams building inference and software factory capabilities, bringing web and UI needs and advising when work suits "light" or "dark" modes. Architect distributed campaigns that use the factory for broad updates across many repositories and technologies, producing refactors and draft merge requests for subject-matter expert teams to review. Lead web and UI security and modernization work, such as dependency upgrades, framework migrations, and front-end vulnerability remediation, in partnership with Security and owning teams. Establish developer experience practices for agentic development in web repositories, including skills, context, conventions, templates, and evaluations, working with AI Platform on shared pieces. Guide pilot teams from experimentation to adoption, measuring cycle time, review load, and quality, lead culture change, and mentor engineers and technical leaders. This is a hands-on software engineering role, not a machine learning role. You will build and use AI agents that build software, not train models.
