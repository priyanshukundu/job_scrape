Job Title Software Development Engineering - Advisor I Senior Cloud Automation Engineer What does a successful Senior Cloud Automation Engineer do at Fiserv? As a core technical leader within our Cloud Engineering team, you will shape our end-to-end strategy for cloud provisioning, continuous integration, and automated application lifecycles across microservices and monolith systems. You will own crucial components of our automation engine from initial code to production while building self-healing, auto-scaling infrastructure using Cloud Native Computing Foundation (CNCF) standards. Join us to elevate developer velocity, mentor engineering peers, and drive resilient operational excellence across our platform. What you will do: • Automate end-to-end cloud infrastructure provisioning using Python, Go (GoLang), and Infrastructure as Code to accelerate multi-cloud application delivery. • Build scalable CI/CD pipelines incorporating policy enforcement, secrets management, zero-trust controls, and container security scans. • Implement self-healing infrastructure, self-service developer environments, and automated disaster recovery mechanisms across cloud platforms. • Orchestrate containerized applications using production Kubernetes or HashiCorp Nomad clusters to ensure high availability. • Standardize infrastructure modules, reverse proxy routing, and service mesh patterns to establish robust Internal Developer Platforms (IDP). • Lead Agile engineering practices, technical grooming, and sprint planning to translate business priorities into technical execution. • Mentor team members through code reviews, operational runbooks, and constructive architectural blast-radius analysis. What you will need to have: • You will need 4+ years of experience in software engineering, cloud automation engineering, or DevOps/platform engineering roles. • You will need 2+ years of hands-on development experience using Python or Go (GoLang) for system automation and tooling. • You will need 2+ years of experience building and managing infrastructure on public cloud platforms like Amazon Web Services (AWS), Google Cloud Platform (GCP), or Microsoft Azure. • You will need 2+ years of experience with Infrastructure as Code using HashiCorp Terraform and configuration management tools. • You will need 2+ years of production experience with container orchestration using Kubernetes or HashiCorp Nomad, alongside GitOps and CI/CD practices. • You will need 2+ years of experience with core networking constructs, HashiCorp Vault secrets management, and API design standards. • You will need 2+ years of experience participating in production on-call operations, incident management, and post-incident reviews. • Bachelor's degree in Computer Science, Engineering, or a related technical field, or an equivalent combination of education, work, and/or military experience. What would be great to have: • Experience with Internal Developer Platforms such as Backstage, Open Application Model (OAM), Radius, or Helm. • Experience deploying and managing service mesh solutions like Istio. • Experience with workflow orchestration systems including Apache Airflow or Google Cloud Composer. • Experience configuring high-performance reverse proxies and traffic management tools like HAProxy.
