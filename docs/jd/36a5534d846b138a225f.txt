Establish and enforce standards for database availability, performance, security, patching, and lifecycle management. Install, configure, patch, and maintain SQL Server instances in on-premises and cloud environments. Manage performance tuning, indexing, replication, encryption, and secure configuration standards. Oversee high-availability and disaster recovery solutions, including Always On and clustering. Implement and maintain database monitoring, capacity planning, cost optimization, and scaling strategies. Uses enterprise-authorized AI capabilities within the work environment to accelerate data pipeline/design analysis and documentation, validating outputs and handling data according to sensitivity and security requirements.
