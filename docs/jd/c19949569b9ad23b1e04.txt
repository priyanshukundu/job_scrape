Job Title Software Engineer Your Role and Impact The Software Engineer is responsible for developing, implementing, and maintaining integrations between hardware, analytics and software. This role bridges the gap between technology delivery and information technology (IT), ensuring seamless integrations, reliable service levels, and actionable monitoring across IoT ecosystems. Key Responsibilities Implement APIs, iframe’s, MQTT brokers, RESTful services, and data pipelines to enable real-time data exchange. Integrate Python analytics modules as services with respective input and output requirements. Deploy and manage solution in various deployment models – on-premises, cloud and hybrid. Work with business stakeholders to define data mapping, transformation logic, and integration requirements. Analyze data flows, event streams, and service logs to identify integration issues or opportunities for optimization. Monitor and optimize data ingestion, transformation, and visualization workflows via business KPIs. Collaborate with vendors, developers, and infrastructure teams to resolve integration challenges. Maintain detailed documentation of integration architecture, APIs, and configuration. Conduct benchmarking and stress tests to ensure scalable and reliable integrations Manage code and work via Azure DevOps, Pipelines and Test cases Ensure compliance with cybersecurity, data privacy, and IoT standards (e.g., ISO 27001, NIST IoT framework). Required Qualifications Bachelor’s degree or Diploma in Computer Science, Information Technology, Engineering, or a related field. 3–5 years of experience in systems integration, data engineering, or IoT solution delivery. Experience with IoT/Cloud platforms (AWS IoT Core, Azure IoT Hub, PTC ThingWorx, etc.). Strong understanding of APIs, web services (REST/SOAP), and messaging protocols (MQTT, AMQP, CoAP). Knowledge of Python based analytical libraries (like NumPy, SciPy etc.) and web frameworks (like Flask, Django etc.) Knowledge of networking fundamentals (TCP/IP, VPN, firewalls) and cloud environments. Familiarity with industrial IoT (IIoT) systems and equipment reliability analysis an advantage Experience in Python, JavaScript or Java for integration scripting an advantage Knowledge of database systems (SQL/NoSQL) and data streaming (RabbitMQ, Kafka) an advantage Understanding of data analytics, dashboards, and visualization tools.
