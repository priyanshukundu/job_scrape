Join the Clinical Insights team as a key part of our engineering organization — a Data Engineer who helps keep clinical data pipelines and client-facing applications running reliably across 10+ client environments every single day. This role supports the full lifecycle of client data infrastructure and application delivery: SFTP ingestion, AWS data lake operations, application environment setup and deployment support, and pipeline monitoring and incident response, working closely with the team's DataOps lead. You'll sit at the intersection of DataOps, DevOps, and delivery engineering — comfortable helping configure a new client environment ahead of go-live, triaging a failed Jenkins run before standup, and confirming yesterday's data loads actually landed. This is not a business intelligence or analytics role. You'll build and operate the infrastructure that the entire product and client delivery organization depends on. This role reports to the team's DataOps lead and works under their technical direction on environment provisioning, infrastructure changes, and architectural decisions. Role Summary In this role, you will: Support daily operation and monitoring of data pipelines across 10+ concurrent client environments, triaging failures (no-data, bad-data, and processing errors) and escalating complex issues to the DataOps lead before they affect client-facing reporting. Set up, configure, and support deployment of client-facing applications — from environment setup through go-live stabilization and ongoing support. Validate that daily data flows complete successfully across all client environments — at a console/log level day to day, diving deeper into pipeline and application logs when something doesn't look right. Support provisioning and configuration of new client environments — SFTP ingestion setup, instance provisioning, access controls, and coordination with client IT teams on file formats, schedules, and encryption — partnering with the DataOps lead on more complex setups. Contribute to the team's CI/CD pipelines (Jenkins), AWS infrastructure (EC2, S3, Lambda, EventBridge, IAM), and Posit Connect analytics hosting platform, under the DataOps lead's direction. Build and maintain monitoring and alerting for pipeline health — distinguishing failure types, reducing false alarms, and keeping the team ahead of client-visible data issues. Maintain runbooks and documentation so operational knowledge is transferable, not siloed in one person's head. Key Responsibilities Application Deployment & Support Help set up and configure client application environments ahead of deployment, including app and infrastructure configuration. Run and support production deployments, including go-live stabilization and post-launch monitoring. Validate that daily data loads and refreshes complete successfully for every client application — console-level checks as the first pass, with deeper investigation when volumes or completion look off. Data Pipeline Engineering Build and maintain client-specific data ingestion pipelines (SFTP, S3, event-driven triggers, file validation), with architectural guidance from the DataOps lead. Build and maintain standardized data validation scripts — a reusable QA framework applied across client environments. DataOps & Pipeline Monitoring Operate and monitor the daily processing pipeline across all client environments; distinguish lambda failures from regular pipeline failures to reduce false alarms. Build data integrity alerts (e.g., null DRGs, late file delivery, failed runs) and route them to the team in real time. Investigate and resolve daily processing failures — root cause analysis, temporary fixes, and permanent remediation. Manage AWS Lambda functions — version control, deployment, and event-driven triggering (SNS/SQS). Build data volume QC dashboards to track pipeline health across clients. Infrastructure & Platform Help manage AWS infrastructure (EC2, S3, RDS, Athena, IAM, Lambda, SNS/SQS) across all client deployments, under the direction of the DataOps lead. Support Posit Connect administration — configuration, user access, and runtime management for the team's R-based reporting stack. Provision new client instances — database setup, ingestion configuration, and access controls. Handle SAML/SSO certificate management and PGP encryption setup for secure client file delivery. Help enforce code repository governance — branch protection, PR approval requirements, and deployment controls. DevOps & CI/CD Build and maintain Jenkins-based CI/CD pipelines (dev → staging → production). Set up and validate development and staging environments. Maintain runbooks for all operational procedures. Support the team's Docker-based mono repo deployment architecture across client environments. Execute and document client offboarding processes.
