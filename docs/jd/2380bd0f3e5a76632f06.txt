Regular or Temporary: Regular Language Fluency: English (Required) Work Shift: 1st shift (United States of America) Please review the following job description: This Software Engineer independently designs, develops, tests and maintains complex integration services for Wealth Brokerage and Trust. The role focuses on reliable movement of business data and orchestration of transactions across applications, platforms and organizational boundaries. The engineer is expected to combine strong .NET/C#, SQL Server and Azure engineering with practical integration expertise across REST APIs, messaging, batch processing and managed file transfer. Python may be used where appropriate for data transformation, reconciliation, automation and engineering utilities. The role works with product, architecture, data, security, operations and vendor teams to ensure integrations are secure, observable, supportable and aligned with business and control requirements. Scope of responsibility • APIs and integration services supporting Brokerage and Trust client, adviser, operations, accounting, asset, cash, case and reporting processes. • Integration across .NET applications, SQL Server databases, Azure services, enterprise platforms, vendor systems and legacy environments. • Real-time, event-driven, scheduled and file-based data exchange, including validation, transformation, reconciliation and exception handling. • Production reliability, security, data protection, auditability, monitoring, capacity, disaster recovery and operational support. ESSENTIAL DUTIES AND RESPONSIBILITIES Following is a summary of the essential functions for this job. Other duties may be performed, both major and minor, which are not mentioned below. Specific activities may change from time to time. 1. Design and develop secure REST APIs, integration services, background processes and reusable components using .NET and C#. 2. Create clear interface contracts, canonical data structures, validation rules, error models, idempotency controls and versioning approaches. 3. Implement data integration using SQL Server, stored procedures where appropriate, data access frameworks, Azure services, messaging, batch processes and SFTP or managed file transfer. 4. Use Python for targeted data transformation, reconciliation, automation, test utilities or operational tooling where it provides a sensible engineering fit. 5. Apply authentication, authorization, encryption, secrets management, certificate handling, network controls and least-privilege principles to integration designs. 6. Build robust error handling, retry, dead-letter, replay, correlation and reconciliation capabilities so failures are visible and recoverable. 7. Develop automated unit, component, contract, integration, performance and regression tests. Support test-data and service-virtualization approaches where dependencies are constrained. 8. Instrument integrations with structured logging, metrics, distributed tracing, dashboards and actionable alerting. Define operational runbooks and support procedures. 9. Partner with data owners and consumers to establish mappings, quality rules, lineage, retention and authoritative-source expectations. 10. Analyze and tune API, database, messaging and batch performance while accounting for throughput, latency, concurrency, capacity and downstream constraints. 11. Collaborate with architecture and platform teams on cloud migration, Azure PaaS patterns, network connectivity, deployment pipelines and reusable integration standards. 12. Troubleshoot complex defects and production incidents across application, API, database, identity, network and vendor boundaries. Complete root-cause analysis and corrective actions. 13. Participate throughout the software development lifecycle, including refinement, design reviews, coding, peer review, testing, deployment, release validation and production support. 14. Lead code and design reviews, mentor junior engineers and contribute patterns, libraries and documentation that improve integration delivery across Wealth Technology.
