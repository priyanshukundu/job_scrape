THE OPPORTUNITY This Senior Software Engineer position can work out of Alameda, CA location. We are seeking a Senior Software Engineer, Backend to design, build, and optimize Lingo's backend systems, ensuring they are scalable, resilient, and secure. Java Spring Boot is our primary backend technology, and you will use it daily, building high-performance APIs, event-driven services, and data integrations across our global deployments. In this role, you will work closely with Product, Mobile, Platform/SRE, and Data/ML teams to deliver robust cloud-native services, troubleshoot complex issues, and continuously improve reliability and developer experience. You will contribute your expertise to architecture discussions, lead implementation of key projects, and mentor junior engineers in best practices. What You'll Work On Design, develop, and maintain scalable microservices and APIs for real-time biosensor data processing. Build and evolve backend services using Java Spring Boot, applying best practices for RESTful API design, dependency injection, Spring Security, and service modularity across Lingo's microservices architecture. Implement event-driven integrations with messaging and streaming systems such as Kafka and RabbitMQ and contribute to analytics pipelines. Collaborate with SRE to ensure observability, performance, and operational excellence across backend services. Participate in architecture and design reviews, contributing to decisions on service boundaries, data models, and communication patterns. Optimize backend services for low latency, high throughput, and cost efficiency. Apply privacy-by-design and security standards in line with HIPAA and GDPR compliance requirements. Write clean, maintainable, and testable code and establish and uphold engineering standards within the team. Mentor junior engineers through code reviews, pair programming, and knowledge sharing sessions. Troubleshoot production issues and contribute to incident response and post-mortem analysis. Qualifications: Bachelor’s degree in computer science, Engineering, or a related technical discipline. Minimum 9 years of experience with distributed, cloud-native systems. Strong skills in microservices architecture and API design (REST), with familiarity with GraphQL or gRPC as a plus. Experience with Kubernetes in production environments and familiarity with service mesh concepts. Hands-on proficiency with messaging and streaming systems such as Kafka or RabbitMQ. Strong programming expertise in Java with hands-on production experience using Spring Boot, including RESTful API development, dependency injection, and Spring ecosystem tooling. Familiarity with Kotlin or Python is a plus. Knowledge of secure coding practices and compliance requirements including HIPAA, GDPR, or similar. Solid understanding of performance optimization, scalability patterns, and async data processing. Strong collaboration and communication skills, with the ability to work cross-functionally with engineering and product teams. Preferred Qualifications Experience integrating backend services with analytics and machine learning pipelines. Exposure to API gateways, authentication and authorization patterns, and rate limiting strategies. Background in digital health, IoT, or other mission-critical platforms. Familiarity with cloud platforms such as Azure, AWS, or GCP, and infrastructure-as-code tooling such as Terraform or Helm.
