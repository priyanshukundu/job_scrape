Job Description: About the Role We are seeking a motivated new college graduate to join our software engineering team and contribute to the development, testing, and automation of Linux-based software used in networking products. This is an excellent opportunity for an early-career engineer who enjoys working close to the operating system, solving technical problems, and developing software in C and Python . The successful candidate will work alongside experienced engineers and gain hands-on experience with Linux systems, embedded software, networking technologies, debugging, automation, and modern software-development practices. Key Responsibilities Design, develop, test, and debug software running in Linux environments. Develop and maintain software components using C . Develop Python scripts and tools for automation, testing, diagnostics, and developer productivity. Troubleshoot software issues across Linux user-space and system-level components. Participate in code reviews, design discussions, and technical problem solving. Write unit and functional tests and help improve automated test coverage. Use Git and modern source-control practices as part of the development workflow. Work with senior engineers to diagnose defects using Linux debugging and diagnostic tools. Contribute to technical documentation and engineering best practices. Collaborate with software, hardware, infrastructure, and networking engineers. Education Required Bachelor's degree in Computer Science, Computer Engineering, Electrical Engineering , or a related technical discipline. Recent graduate or candidate graduating soon. Required Qualifications Academic, internship, project, or practical experience developing software in a Linux environment. Programming experience in C . Programming or scripting experience in Python . Understanding of fundamental computer science concepts, including data structures, algorithms, operating systems, and software development. Familiarity with Linux command-line tools and shell environments. Basic understanding of software debugging and problem-solving techniques. Familiarity with Git or another source-control system. Strong analytical and troubleshooting skills. Ability and willingness to learn unfamiliar technologies. Good written and verbal communication skills and ability to collaborate within a technical team. Preferred Qualifications Coursework or projects involving operating systems, embedded systems, networking, or Linux. Experience with Bash, and shell scripting. Exposure to Linux internals, processes, memory management, system calls, or kernel concepts. Familiarity with debugging tools such as GDB, strace, tcpdump, or perf . Experience with CI/CD, automated testing, or software build systems. Exposure to embedded Linux, cross-compilation, or the Yocto Project . Basic knowledge of TCP/IP and networking fundamentals. Experience contributing to open-source software, university research, hackathons, or substantial personal software projects.
