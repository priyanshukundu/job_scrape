Your role at Baxter The Senior Principal Software Engineer (Mobile) is a hands-on technical leader responsible for the design, development, and evolution of mobile applications supporting both iOS and Android platforms using React Native. This role provides technical leadership across architecture, application development, platform integration, security, quality, and delivery within regulated healthcare environments. What you will be doing: Lead the architecture, development, and enhancement of Mercury mobile applications using React Native for iOS and Android. Design and implement scalable, secure, and maintainable mobile application features and services. Ensure functional parity and a consistent user experience across both mobile platforms. Collaborate with backend, web, UX, QA, cybersecurity, regulatory, and product stakeholders. Design and implement integrations using REST APIs, WebSockets, SignalR, and other modern application communication patterns. Apply HIPAA-aligned security practices for data handling, authentication, messaging, notifications, and mobile application security. Participate in Agile development ceremonies and work tracking using JIRA and Confluence. Contribute to design controls, requirements traceability, verification, and validation documentation using JAMA. Perform rigorous code reviews and champion mobile engineering best practices. Mentor engineers and raise the overall quality and consistency of mobile development. Support production readiness, monitoring, troubleshooting, and issue resolution in live healthcare environments. Evaluate and recommend mobile architecture patterns, frameworks, libraries, and platform capabilities to support long-term product evolution. Collaborate with cross-functional teams to define technical roadmaps and ensure successful delivery of strategic initiatives. Required Qualifications Bachelor's degree in Computer Science, Software Engineering, or a related discipline. 10+ years of professional software engineering experience, including significant mobile application development experience. Proven expertise with React Native and modern JavaScript/TypeScript development. Strong experience developing for both iOS and Android platforms. Strong experience integrating mobile applications with backend systems using REST APIs, WebSockets, and modern service-oriented architectures. Experience with mobile application lifecycle management, including deployment, monitoring, troubleshooting, and support. Strong understanding of mobile application security, authentication, authorization, and secure data handling practices. Experience working in regulated environments, preferably healthcare or life sciences. Proficiency with GitHub, PostgreSQL at the application consumption or interaction layer, and collaborative development workflows. Experience leading technical design discussions, architecture reviews, and mentoring engineering teams. What you will bring: Hands-on experience integrating mobile applications with real-time communications platforms or messaging services. Experience building secure communication, clinical communication, messaging, alerting, or workflow-driven applications. Familiarity with iOS and Android native platform capabilities, including notifications, background processing, device integrations, and platform-specific APIs. Experience troubleshooting complex mobile application performance, connectivity, reliability, and device compatibility issues. Familiarity with mobile deployment pipelines, release management, and mobile application lifecycle management. Understanding of healthcare workflows, clinical environments, nurse call, patient-care communications, or medical-device integrations. Experience collaborating with UX design using Figma. Experience leading technical designs, architecture reviews, and cross-functional engineering initiatives. Familiarity with WebRTC, SIP, VoIP, media sessions, telephony integrations, or other real-time communication technologies is a plus.
