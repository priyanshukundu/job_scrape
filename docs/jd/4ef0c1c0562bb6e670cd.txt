The Software Engineer standardizes the quality assurance procedure for software. Oversees testing and debugging and develops fixes. Research complaints and make necessary adjustments and/or recommendations to resolve complex software related issues. Begins to influence the department's strategy. Makes decisions regarding technical approaches for project components, and work is performed without direction. Exercises considerable latitude in determining objectives and approaches to assignments. This is a hybrid role in Louisville, KY. Lead technical discovery sessions and translate ambiguous requirements into clear architecture, implementation plans, and engineering deliverables. Design, develop, test, deploy, and support scalable full-stack applications across web, backend, cloud, data, automation, and AI-enabled use cases. Build responsive and maintainable front-end applications using modern frameworks such as Vue.js/ React/Angular/Next.js. Design and implement backend services, APIs, integrations, and microservices using Python Develop cloud-native solutions using Azure/ Google Cloud Platform/AWS , including compute, storage, identity, networking, serverless, managed databases, monitoring, and logging services. Integrate AI capabilities into applications using enterprise-approved AI platforms, APIs, SDKs, and cloud AI services. Design and implement automation solutions for business processes, software delivery, testing, monitoring, reporting, operational support, and developer productivity.
