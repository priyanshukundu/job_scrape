WHAT YOU WILL DO

Snowsight is a large, complex single-page application serving interactive analytics, data engineering, and AI workloads. As our user base and feature surface grow, we must treat performance as a first-class citizen. You will own the strategy, build the tooling, and drive the culture needed to keep Snowsight fast, and you'll partner across our platform and product teams to make performance a default rather than an afterthought.



This is a high-leverage role: the systems and practices you build will affect every page load, interaction, and data-rendering path in Snowsight. You will:

 - Define and drive the web performance strategy for Snowsight, setting goals grounded in real user metrics (Core Web Vitals, custom interaction metrics, time-to-visually-complete for data-heavy views).

 - Build and maintain performance infrastructure: RUM/synthetic monitoring pipelines, regression detection in CI, bundle analysis, performance dashboards, and alerting, making performance visible and actionable for every product team.

 - Identify and fix systemic performance bottlenecks across the application lifecycle: initial load, code splitting and lazy loading, rendering (React), data fetching and caching, large dataset rendering (virtualization, streaming), and runtime memory/CPU efficiency.

 - Optimize build and delivery: work with the team on bundle size, tree-shaking, chunk splitting strategies, CDN caching, and resource prioritization (preload, prefetch, HTTP/2+ multiplexing).

 - Establish performance budgets and guardrails integrated into CI/CD so regressions are caught before they ship.

 - Partner with product teams to design performance-aware architectures for new features, providing guidance on data-fetching patterns, rendering strategies, and progressive loading.

 - Mentor engineers across the org on performance best practices, conduct reviews of critical performance paths, and build a culture where teams own performance as a quality attribute.

 - Represent Snowflake's frontend performance perspective in cross-org architectural decisions (e.g., API design, service infrastructure, caching layers) where frontend impact is significant.




WHAT WE’RE LOOKING FOR

Our ideal Staff Software Engineer will have:

 - 8+ years of software engineering experience, with deep expertise in web performance for large-scale, complex web applications.

 - Expert-level JavaScript/TypeScript and React knowledge, including React rendering internals and experience diagnosing and resolving performance issues in large React codebases.

 - Strong understanding of browser performance fundamentals: the critical rendering path, layout/paint/composite pipeline, main-thread scheduling, Web Workers, browser DevTools/Performance panel profiling, etc.

 - Experience designing and operating RUM and synthetic performance monitoring at scale (e.g., custom metrics collection, percentile-based alerting, anomaly detection for regressions).

 - Deep knowledge of build tooling and delivery optimization: Webpack/Vite/Bazel, code splitting, tree-shaking, chunk strategies, lazy loading, CDN behavior, caching headers, resource hints, and their measurable impact on load performance.

 - Experience with large dataset rendering: virtualization (windowing), canvas/WebGL rendering for grids or charts, streaming/incremental rendering, and efficient DOM management.

 - Strong communication and influence skills: able to set technical direction, build consensus across teams, and explain performance trade-offs to both engineers and product stakeholders.

 - Experience working in a platform or infrastructure role where your customers are other engineering teams.

 - Ability to work on-site at our Bellevue, WA or Menlo Park, CA offices.
