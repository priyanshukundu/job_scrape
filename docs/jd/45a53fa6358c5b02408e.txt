Role Summary: We currently have exciting opportunities for a Senior Embedded Software Engineer – DSP Software. In this role, you will be contributing to the development of Autonomous/ADAS/AD/HAD/Active Safety Projects. This position is located at our Indiana Technical Center in Carmel, IN (relocation offered within the USA). Your Role: Develop and integrate embedded software for Radar DSP in support of Adjacent Markets. The software engineer develops software, creates and executes designs for new functionality, or enhances existing functionality for projects such as: Next generation automotive radars, tracking and sensor fusion algorithms, features like ACC, FCW/AEB, Vehicle Controls, Blind Spot Detection, etc. Engineers develop software in low level code in C/C++. They also test software using debuggers, emulators and simulators; perform software quality assurance activities; write unit and integration tests and work collaboratively and professionally with other teams within the project. Collaborates and adds value through participation in peer code reviews, providing comments and suggestions. Performs technical root cause analysis and outlines corrective action for given problems. Demonstrates proficiency using software engineering tools (configuration management systems, build processes, debuggers, emulators, simulators and logic analyzers). Works in an agile software development environment.
