Role Overview The Full Stack Developer is a hands on, full stack engineer responsible for designing, developing, and supporting enterprise applications and integrations that enable critical business operations. This role spans backend systems, frontend UI, and integration layers, delivering secure, scalable, and high quality solutions that meet business needs. The ideal candidate demonstrates strong technical execution, effective problem solving abilities, and the ability to work successfully within a large scale enterprise environment that requires adherence to governance, compliance, and security standards. The role includes partial ownership of technical solutions and active participation in design and architectural discussions. Full Stack Development · Design, develop, test, and deploy full-stack features using React, Java/Spring Boot, and Python. · Develop responsive, reusable UI components and workflows in React. · Build and maintain secure, scalable RESTful APIs and backend microservices. · Implement system integrations across internal applications and external vendor platforms. · Develop and enhance chatbot user interfaces within React applications. · Build conversational UI features such as: · Message streams and interaction flows · Structured and unstructured response rendering · User input handling and validation · Real-time integration with backend services · Ensure the chatbot UI delivers a seamless, intuitive, and accessible user experience. Cloud, DevOps & Operations · Develop and deploy cloud-native applications using Azure or AWS. · Work with Docker/Kubernetes for containerization and orchestration. · Contribute to CI/CD pipelines (Azure DevOps, Jenkins, GitHub Actions). · Collaborate with architecture and platform teams on security, performance, and monitoring. Team Collaboration & Quality Engineering · Participate in agile ceremonies including standups, planning, reviews, and retrospectives. · Collaborate with product owners, engineers, architects, and business teams to refine requirements. · Ensure code quality through unit tests, integration tests, and code reviews. · Apply best practices for security, maintainability, and performance. Nice-to-Have · Experience building or integrating AI/GenAI solutions, including LLMs, RAG, Azure OpenAI, LangChain, or Semantic Kernel, into enterprise applications.
