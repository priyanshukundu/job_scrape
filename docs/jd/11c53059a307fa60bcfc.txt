Description We are seeking a skilled Senior Software Engineer to lead the design, development, modernization, and integration of enterprise applications and data platforms. The successful candidate will act as an individual contributor and technical leader, taking responsibility for high impact integration and application modernization initiatives throughout the entire software development lifecycle. Operating in an Agile environment, this role focuses on migrating enterprise workloads to Microsoft Azure, developing cloud-native distributed systems, and architecting event-driven data pipelines. The ideal candidate will collaborate with seasoned engineering and business teams to translate complex technical requirements into scalable, maintainable solutions. Objectives: Implement a comprehensive collateral management platform that services client needs, drives simplification, and reduces redundant collateral capabilities bank wide Implement standard, simplified data management and systems integration to ensuring flexible, robust overall offering. Implement platform modernization using the latest cloud technologies to improve scalability, resilience, and operational efficiency. Major Responsibilities Lead the architectural design, migration, and modernization of enterprise applications and data platforms to Microsoft Azure, Azure Databricks, and Azure Kubernetes Service (AKS). Design, build, and operate full-stack, microservices-based applications, developing scalable backend services utilizing Java, Spring Boot, SQL, and PL/SQL, while maintaining reactive, user-friendly web interfaces utilizing ReactJS, Material UI, TypeScript, HTML5, and CSS3. Lead the implementation of responsive, scalable, and reusable user interfaces using ReactJS aligned with enterprise architecture and accessibility standards. Design and implement scalable, resilient, and secure microservices using Java and Spring Boot, with well-defined APIs, containerized deployment on Azure Kubernetes Service (AKS), and enterprise-grade monitoring and observability. Define and enforce API-first design standards for RESTful services, including versioning, documentation, error handling, and backward compatibility. Decompose monolithic applications into independently deployable microservices using domain-driven design, clear service boundaries, and reusable integration patterns. Implement secure service-to-service communication, authentication, authorization, secrets management, and data protection in accordance with enterprise security standards. Establish automated unit, integration, and performance testing to ensure microservices meet quality, scalability, and reliability requirements. Build fault-tolerant services using resiliency patterns such as timeouts, retries, circuit breakers, health checks, and graceful degradation. Modernize legacy Spark/Scala/Hadoop workloads by transitioning data processing workflows to PySpark on Azure Databricks. Architect and implement event driven integration solutions and near-real-time data pipelines utilizing Apache Kafka, Redis, and Azure Databricks. Develop and maintain enterprise CI/CD pipelines and automated deployment processes utilizing tools such as Jenkins, Harness, and Azure DevOps. Support application scheduling, batch processing (Autosys, CRON), and enterprise messaging integration (MQ). Monitor production applications, troubleshoot performance bottlenecks, and tune backend queries to optimize system scalability and reliability. Provide architectural leadership and technical guidance, conduct code reviews, and collaborate with product managers and cross-functional engineering teams to align solutions with enterprise technology standards. Skills and Requirements Bachelor's degree (or equivalent) in Computer Science or a related field. 5 years of professional experience as a Software Developer or other professional software development role. Must include 5 years of concurrent experience in each of the following: Familiarity with the Collateral Management or Financial Investment Management business domains. Knowledge of collateral management platforms and solutions, including Colline, Cassini, and Transcend. Cloud-native application development, migration, and deployment utilizing Microsoft Azure, Azure Kubernetes Service (AKS), and Azure Databricks. Developing full-stack or microservices-based enterprise applications utilizing backend frameworks (Java, Spring Boot) and modern frontend libraries (ReactJS). Developing, tuning, and working with event-driven messaging systems and Big Data technologies utilizing Kafka, Spark, and Azure Databricks. Configuring, automating, and managing CI/CD deployment pipelines utilizing tools such as Jenkins, Harness, or Azure DevOps. Relational database tuning (e.g., Oracle) and managing batch-processing workloads (Autosys, CRON).
