YOUR IMPACT Develops software consistent with Cisco ‘Design Thinking Principles’ with a focus on simplification and UX (User Experience) at its core, using secure coding practices, ensuring user privacy, and following software development best practices. Partners with other teams including design and product management to create the right solution for the customers. Creates technical design documentation to be used by the team as well as contributing to user documentation to be used by end users. Debugs and addresses software issues during development and in production systems to support customers. Brings new ideas for product innovation and helps improve software development processes. Linux Administration: Administer RHEL/CentOS environments, focusing on RPM packaging, signing, and security hardening (SELinux, kernel hardening). Automation & CI/CD: Utilize Python and YAML for build/manifest automation and contribute to CI/CD or image-build pipelines. Software Development: Design, code, and test small-to-medium features using agile practices and secure coding principles. Quality Assurance: Write clean code, perform unit testing, and execute tests for scale, reliability, and velocity. Collaboration: Partner with team members to resolve technical blockers, participate in code reviews, and share knowledge. Operational Support: Monitor and triage incident reports, participate in postmortems, and handle potential on-call duties. Project Management: Estimate assignment timelines, communicate status/blockers, and deliver technical design features. Problem Solving: Analyze business problems and apply standard procedures to deliver solutions for products and customers. MINIMUM QUALIFICATION S Bachelors + 2 years of related experience with proficiency in RHEL/CentOS Linux administration, RPM packaging, and signing. Experience with Python and YAML for automation. Foundational knowledge of Linux security hardening (SELinux, kernel hardening). PREFERRED QUALIFICATION S Advanced Security: Experience with UEFI Secure Boot, signed kernel modules, IMA/EVM, hardened distributions, FIPS, or OpenSSL/SSH crypto libraries. Vulnerability Management: Experience with CVE patch handling. Technical Leadership: Proven ability to lead and resolve complex technical problems.
