Overview The Mastercard Open Finance Connect team is looking for a Senior Software Engineer to help shape the future of financial connectivity and consumer experiences through consistent innovation and problem-solving. We are seeking an exceptional, hands-on engineer with advanced expertise in React.js, Node.js, TypeScript, API engineering, and cloud-native development. The ideal candidate combines strong software engineering fundamentals with intellectual curiosity, customer focus, and practical AI fluency. You will build scalable experiences and backend platforms, use tools such as GitHub Copilot, Claude, or Cursor responsibly, and explore AI-powered applications, agents, and agentic workflows while maintaining high standards for architecture, security, testing, reliability, and code quality. Role • Design, develop, and operate scalable customer-facing applications and backend services using React.js, Node.js, JavaScript, and TypeScript. • Build secure, reusable, commercial-grade REST APIs and integrations used by internal teams, financial institutions, data providers, and external partners. • Design microservices, distributed systems, and event-driven solutions with strong availability, performance, observability, and operational readiness. • Own features and services end to end, including design, estimation, development, testing, deployment, documentation, production support, and continuous improvement. • Use AI-assisted development tools to accelerate coding, testing, debugging, documentation, code reviews, and technical exploration without compromising engineering judgment. • Design and build AI-powered capabilities, intelligent automation, agents, and agentic workflows that address meaningful customer and engineering needs. • Lead technical and architecture discussions, conduct high-quality code reviews, mentor engineers, and promote reusable frameworks, standards, and engineering best practices. All About You The ideal candidate for this position should: • Bachelor's degree in Computer Science, Computer Engineering, Information Technology, a related field, or equivalent practical software development experience. • Extensive experience in software engineering. • Demonstrate advanced full-stack expertise in React.js, Node.js, JavaScript, and TypeScript, with a strong understanding of component architecture, state management, performance optimization, and modern testing practices. • Have deep experience designing and developing scalable backend services and REST APIs using Node.js and frameworks such as Express.js or NestJS, including API contracts, versioning, lifecycle management, gateways, caching, and asynchronous integration patterns. • Understand application security, authentication, and authorization, including OAuth2, JWT, OWASP secure coding practices, data protection, and vulnerability management. • Be experienced with microservices, distributed and event-driven architectures, relational or NoSQL databases, Docker, Kubernetes, CI/CD, cloud platforms, monitoring, logging, and observability. • Use AI coding assistants such as GitHub Copilot, Claude, or Cursor effectively and responsibly for code generation, refactoring, testing, debugging, and documentation, while validating outputs for security, quality, and maintainability. • Be an exceptional problem-solver and systems thinker who takes ownership, communicates clearly, collaborates across Product, UX, QA, and Engineering, and consistently delivers production-quality outcomes. Desirable Capabilities • Experience building AI-powered applications, agents, agentic workflows, or LLM integrations using platforms such as OpenAI, Anthropic, Azure OpenAI, or Gemini. • Knowledge of prompt engineering, retrieval-augmented generation, vector databases, model context protocols, and responsible AI practices. • Experience with technologies such as Kafka, Redis, GraphQL, Next.js, or similar tools used in scalable platforms. • Experience in FinTech, Open Banking, payments, or another regulated industry.
