About the Job We're looking for a hands-on Software Engineer III to contribute across application development and our evolving data ecosystem. In this role, you'll design, build, modernize, optimize, and support solutions spanning application services, data pipelines, relational databases, and cloud-based data platforms. You'll work across software engineering and data engineering, bringing hands-on experience with AWS Glue, Apache Iceberg, PostgreSQL, Amazon Aurora MySQL, and database and data-performance engineering. Partnering with engineering, architecture, product, and platform teams, you'll help deliver scalable, reliable solutions and modernize the systems that support them. What You’ll Do Design, build, test, and support scalable software and data solutions within AWS. Develop and maintain data ingestion, transformation, and processing pipelines using AWS Glue. Build data solutions using Apache Iceberg and Amazon S3-based data architectures. Design and develop solutions using PostgreSQL and Amazon Aurora MySQL. Use erwin Data Modeler to design, document, and maintain logical and physical data models, translating business and application requirements into scalable, maintainable data structures. Own database and data-performance optimization, including query tuning, indexing strategies, execution-plan analysis, schema optimization, and troubleshooting high-volume workloads. Identify data-access bottlenecks across applications, APIs, databases, and data pipelines, and drive improvements in latency, throughput, scalability, and reliability. Build reliable integrations between applications, APIs, operational databases, and enterprise data platforms. Help modernize legacy application, database, and ETL patterns into cloud-native architectures. Establish strong engineering practices for automated testing, CI/CD, observability, data quality, resiliency, and production support. Partner across software engineering, data engineering, architecture, product, and platform teams to deliver integrated solutions. What You’ll Bring to the Role Strong software engineering fundamentals and experience delivering production systems. Hands-on AWS Glue experience, including building and troubleshooting ETL and data-processing pipelines. Hands-on Apache Iceberg experience with modern data lake or lakehouse architectures. Strong PostgreSQL experience, including SQL development, schema design, indexing, and performance tuning. Strong Amazon Aurora MySQL or Aurora PostgreSQL experience, including database design, application integration, operational support, and performance optimization. Demonstrated experience diagnosing and improving database and data performance, including query and execution-plan analysis, index design and optimization, SQL optimization, schema and data-model optimization, connection and concurrency issues, large-volume data processing, and application-to-database performance bottlenecks. Experience with Amazon S3 and AWS-based data architectures. Strong SQL skills and proficiency with Python, Java, or another modern programming language. Experience building production-grade data pipelines and working with large structured and semi-structured datasets. Experience with CI/CD, automated testing, source control, monitoring, and production support. Additional Qualifications We’d Love Spark or PySpark experience. Experience modernizing or migrating legacy databases and ETL workloads. Experience with data quality, lineage, observability, governance, and metadata management. Experience working across both OLTP/application databases and analytical/data-platform workloads. Experience designing systems where application performance depends heavily on database and data-access performance.
