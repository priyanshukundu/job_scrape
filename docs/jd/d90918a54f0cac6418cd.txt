This role combines software development and test engineering, with a strong emphasis on Core Java programming, technical problem-solving, and automation development . You will design and develop scalable automated testing solutions across UI, API, and backend systems while applying software engineering principles to improve quality, reliability, and testability. The ideal candidate is a hands-on Java programmer who can independently write, debug, and maintain code and apply those development skills to build robust, scalable, and maintainable test automation solutions. Your Primary Responsibilities: Design, develop, and maintain Java-based test automation frameworks and solutions across UI, API, and backend applications.
