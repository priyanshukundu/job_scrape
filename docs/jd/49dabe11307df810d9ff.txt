NVIDIA is seeking a Senior Systems Software Engineer for the Apache Spark Acceleration group. GPU accelerated data processing has moved from proof of concept to production deployments. Enterprises now recognize the need for accelerated computing to handle large data processing needs. Multi-node GPU deployments reduce cloud computing costs and lower the latency of batch ETL workloads. At NVIDIA, we accelerate Apache Spark with an open source plugin that speeds up Spark applications on GPUs without code changes, and our cuDF Spark library is integrated with AWS EMR, Databricks, Google Dataproc, Oracle Cloud Data Flow, Bytedance Volcengine, Tencent Cloud and Cloudera. This role is on the team that runs that acceleration as a handled Spark service inside NVIDIA. The service accomplishes production data pipelines for NVIDIA’s internal data platform at thousands of jobs an hour on Kubernetes and AWS, under a customer SLA. It packages the cuDF Spark plugin and a CPU/GPU workload router into an API-based service built on Spark Connect, Kyuubi, Helm and Flux. You will work across all three layers: the service, the GPU Spark runtime, and the router. What you’ll be doing: Design, build and operate hosted Spark service control plane on Kubernetes: the Java REST API, the Spark Connect runner, Kyuubi, and deployment using Helm charts and Flux Own code review for one or more services end to end and keep them releasable on the release train Extend the cuDF Spark runtime and the CPU/GPU workload router in Scala and Java, including interoperability with Delta Lake, Apache Iceberg and Unity Catalog Investigate production failures on clusters running more than a thousand concurrent jobs together with the customer team and upstream library teams, and drive fixes to closure Instrument metrics, dashboards and alerts;
