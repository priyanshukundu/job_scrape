As a Lead Software Engineer at JPMorgan Chase, you will design and deliver the software products that power executive-facing reporting and analytics across firmwide technology programs -- and be a senior, visible contributor who can stand behind what you build in front of leadership at all levels. This role is for a self-directed engineer who moves fast, thinks architecturally, and is energized by the challenge of pioneering new ways of working. You will build Python-based web applications and reporting tools using agentic AI, deploy them into Cloud Foundry and AWS environments, and own the full software lifecycle from development through production. You set technical direction, establish patterns others follow, and bring the same energy to a stakeholder presentation as you do to a code review. Core responsibilities: designing and building production-grade Python web applications serving executive and program audiences; owning end-to-end deployment via CI/CD pipelines and enterprise tooling; developing lightweight web front-ends through Python frameworks; partnering with program leads to translate reporting requirements into scalable software products; and actively driving the adoption of AI-assisted development across the team. Qualifications: proven experience building and deploying production Python applications; experience with Cloud Foundry, AWS, or equivalent PaaS/cloud platforms; proficiency with CI/CD tooling and version-controlled development; comfort building web front-ends through Python frameworks; strong communication and presentation skills with experience working directly with senior stakeholders.
