SQL Server on Linux or adjacent depth with a demonstrable fast ramp Backup, restore, and high availability: Always On Availability Groups, and recovery proven against recovery point objective and recovery time objective targets; production Kubernetes with stateful workloads including StatefulSets, persistent volumes, and resource limits Production AWS experience across Elastic Kubernetes Service, Elastic Compute Cloud, Elastic Block Store, Simple Storage Service, Identity and Access Management, Virtual Private Cloud, and CloudWatch Strong backend engineering in C#/.NET: REST APIs, microservices, testing, and code quality practice; Linux fluency and clear written communication for a distributed team Preferred: SQL Server replication and change data capture at production scale including failure modes; backup to S3-compatible object storage and Elastic Block Store snapshot strategy; lakehouse exposure with Apache Iceberg or Delta Lake; streaming and integration using Kafka, Debezium, AWS Database Migration Service, and Spark; infrastructure as code using Terraform and Helm; very large database operations; working knowledge of Java Demonstrated proficiency in artificial intelligence concepts, with hands-on experience using AI tools to streamline workflows and enhance operational efficiency. Proven ability to implement AI-powered solutions to solve business challenges. Demonstrates a growing awareness of AI risk management and a commitment to responsible and ethical AI use Education Bachelor's or Master's degree in Computer Science, Engineering, or a related discipline, or equivalent professional experience Responsibilities Operate and continuously improve a self-hosted SQL Server estate on Linux and Kubernetes, ensuring availability, performance, and data integrity for Moody's Insurance Solutions products. Operate and harden SQL Server on Linux on Elastic Kubernetes Service: manage StatefulSets, storage classes, pod quality of service, upgrades, and day-two automation Own availability and recoverability: configure and exercise Availability Groups, run failovers, and prove restores against recovery point objective and recovery time objective targets Tune performance at the query, index, and instance level; run the estate to a defined standard through configuration baselines, drift detection, scheduled patching, and maintenance automation Keep databases secure and auditable through encryption, least-privilege access, auditing, and key and certificate rotation; protect data integrity through scheduled consistency checks, corruption detection, and tested recovery Baseline performance and alert on plan regressions, blocking, deadlocks, log growth, replica health, and job failures; build and run change data capture pipelines with attention to latency, ordering, schema evolution, and backfills Manage AWS storage and capacity: Elastic Block Store volume types, input/output operations per second and throughput headroom, expansion, snapshots, and cost; write platform services, automation, and infrastructure as code; maintain continuous integration and continuous delivery pipelines for database change Participate in on-call rotation, lead incident response, build the observability that shortens the next incident, and propose platform improvements through design reviews About the Team The Data Platform Team builds and operates the data services that power Moody's Insurance Solutions products, including a self-hosted Microsoft SQL Server estate running on Linux and Kubernetes in AWS. The team owns that platform end to end — availability, performance, recoverability, and cost — and is building the change capture path that makes operational data available for analytics in our lakehouse. By joining our team, you will contribute to mission-critical infrastructure and help shape the responsible adoption of modern data and AI technologies across the organization.
