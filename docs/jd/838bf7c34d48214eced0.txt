Description Lead Software Development Engineer Job Profile Summary The Lead Software Development Engineer provides technical and consultative support on highly complex technology initiatives. This role designs, develops, and supports cloud-native data ingestion, data processing, and enterprise data platform solutions leveraging batch, streaming, and event-driven architectures. The individual serves as a senior technical contributor, helping evaluate and implement technology solutions that are scalable, secure, resilient, and aligned with enterprise standards. Duties and Responsibilities Analyzes, designs, develops, and supports enterprise applications and platform services. Evaluates architectural approaches and recommends appropriate technologies based on business requirements, cost, scalability, reliability, and operational supportability. Develops cloud-native solutions using APIs, event-driven patterns, and distributed systems principles. Provides technical leadership and guidance during design reviews and implementation activities. Troubleshoots complex production issues and drives root cause analysis and remediation. Maintains knowledge of industry trends, cloud technologies, and enterprise integration patterns. Mentors less experienced engineers and serve as technical lead, leading by example on projects. Performs other duties as assigned. Basic Qualifications Bachelor's Degree. 7+ years of software engineering, platform engineering, or cloud engineering experience. Experience developing enterprise applications using Java and/or Python. Experience building and operating enterprise data platforms for high-volume batch and streaming workloads. Experience designing and supporting distributed systems and APIs. Preferred Qualifications Experience with cloud-native architecture and Google Cloud Platform (GCP). Experience with data platforms leveraging Dataflow, Cloud Composer, Bigtable, BigQuery, Pub/Sub, and Spark . Strong understanding of API, messaging, event-driven, and microservices architectures. Experience evaluating technology tradeoffs and selecting appropriate solutions for business and technical requirements. Experience with Pub/Sub, Dataflow, Apigee, and CI/CD practices. Strong analytical, troubleshooting, and communication skills. Ability to influence technical direction across multiple teams. Preferred Technical Skills Python, Java Scala, SQL Dataflow, BigQuery, BigTable, ​ Cloud Composer (Apache Airflow), Apache Spark GCP Spring Boot, REST APIs, Pub/Sub Data Ingestion Frameworks CI/CD and Automation Observability and Monitoring Key differentiator: Demonstrated ability to evaluate and choose between cloud services, APIs, messaging platforms, event-driven solutions, and data processing technologies based on scalability, reliability, operational supportability, security, and cost considerations.
