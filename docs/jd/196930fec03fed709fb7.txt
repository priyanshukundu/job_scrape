Job Description: Fidelity Investments has an exciting opportunity for a Senior Software Engineer in Test to join the Workplace Investing Digital Platforms Quality Engineering team. Strong programming experience in Java with the ability to build scalable automation frameworks. Hands-on experience developing API automation using REST Assured and Karate Framework . Experience building UI automation using Playwright . Strong understanding of RESTful services, API testing, and service virtualization. Solid experience with CI/CD pipelines using tools such as Jenkins , GitHub Actions , or equivalent. Experience working with Git , source control management, and branching strategies. Experience with Agile/Scrum methodologies and participation in all sprint ceremonies. Ability to analyze business requirements and translate them into effective test scenarios and automation solutions. Experience identifying quality risks, defining mitigation strategies, and driving defect resolution. Strong debugging, troubleshooting, and root-cause analysis skills. Self-motivated individual with the ability to work independently and contribute effectively within a highly collaborative team.
