Job Description We are looking for a Software Engineer, Senior Consultant I with hands-on experience in Kong API and AI Gateway technology, cloud platforms, and infrastructure automation. The ideal candidate should have experience supporting and managing API platforms, working with Linux-based systems, and automating deployments using Infrastructure as Code tools. Candidates must be able to work CT or ET hours. Required Skills Good experience in API Management and Gateway technologies. Hands-on experience with Kong API Gateway administration, configuration, and troubleshooting. Strong knowledge of Linux operating systems and shell scripting. Experience with AWS services such as EC2, VPC, Load Balancers, IAM, CloudWatch, and EKS. Experience with Infrastructure as Code tools such as Terraform . Experience with configuration management and automation using Ansible . Understanding of REST APIs, API security, OAuth, JWT, SSL/TLS, and networking concepts. Experience with CI/CD pipelines and source control tools such as Git. Ability to diagnose, troubleshoot, and resolve production issues. Responsibilities Deploy, configure, and support Kong API Gateway environments. Automate infrastructure provisioning and application deployments using Terraform and Ansible. Monitor platform health, troubleshoot incidents, and drive issue resolution. Work closely with development and platform teams to onboard and manage APIs. Implement security, performance, and reliability best practices. Support AWS-based infrastructure and containerized environments. Good to Have Experience with AI Gateway implementations and AI/LLM integrations. Exposure to Kubernetes and container platforms. Knowledge of Datadog, Prometheus, Grafana, or other monitoring tools. Experience with Apigee or other API management platforms. Skills Amazon Web Services (AWS), Ansible (Software), API Management, Gateway Software, Linux, Software Development, Terraform (Software) Compensation Compensation offered for this role is 85,000.00 - 145,075.00 annually and is based on experience and qualifications.
