About the Opportunity
MoonPay is building a developer platform that allows partners to create native payment and crypto experiences directly inside their own products.
Historically, partners integrated MoonPay through a hosted widget and redirected users into a fixed MoonPay journey. We are now breaking the underlying system into reusable modules covering authentication, identity, KYC, quotes, payment methods and purchasing.
These capabilities are exposed through APIs, SDKs, embedded components, iframes and web views. Our goal is for a partner developer to integrate MoonPay’s full capabilities without needing ongoing implementation support from our team.
This role owns the developer-facing layer between MoonPay’s underlying payments infrastructure and the products our partners build. You will work across browsers, mobile applications and backend APIs to make complex financial workflows feel simple, predictable and native.
As a Senior Software Engineer, you will hold a hands-on technical position. You will build the platform itself rather than implementing one-off integrations for individual customers.
Build the developer platform
Design and build APIs, SDKs and embedded components used by external developers.
Turn MoonPay’s existing authentication, identity, payment and purchasing capabilities into reusable platform modules.
Develop secure browser and mobile integration patterns across iframes, web views and native applications.
Create stable abstractions over complex payments, compliance and crypto infrastructure.
Build reference applications, sandboxes and tooling that help developers move quickly from exploration to production.
Understand the integration deeply
Own the complete developer journey, from obtaining credentials through to completing a live transaction.
Design clear interfaces for sessions, authentication, quotes, payment methods, transaction state and errors.
Handle the realities of browser and mobile environments, including cross-origin communication, redirects, storage restrictions and application lifecycle events.
Develop consistent behaviour across web, iOS and Android integrations.
Ensure integrations remain secure when operating inside products MoonPay does not control.
Make complex systems easy to use
Design APIs and SDKs that are difficult to misuse and straightforward to debug.
Establish clear versioning, compatibility and migration strategies.
Build documentation around how developers actually use the platform rather than treating it as a secondary deliverable.
Create useful errors, logs and observability so partners can resolve issues without contacting MoonPay.
Reduce integration time and the amount of direct support required from engineering.
Operate payment-critical software
Build systems where failures can prevent a customer from completing a purchase or leave a partner uncertain about transaction state.
Design for retries, duplicate events, delayed responses and dependencies failing in unexpected ways.
Implement idempotency, state recovery and graceful degradation across distributed payment flows.
Measure API and SDK adoption, integration success, reliability and developer experience.
Safely evolve the platform as MoonPay adds products, payment methods, regions and partners.
