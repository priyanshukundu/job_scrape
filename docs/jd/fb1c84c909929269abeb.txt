Cloud Architecture & Development: Design scalable microservices using AWS services, Java/Spring Boot, RESTful APIs, and event-driven architectures. Application Development & Data Management: Lead enterprise application development processing high-volume financial data using SQL/NoSQL databases and ETL/ELT pipelines. Integration & Middleware: Implement ESB solutions using Spring Cloud components, message brokers, and API gateway management for microservices orchestration. DevOps & Production Support: Build CI/CD pipelines, automate infrastructure with Terraform, manage zero-downtime deployments, and establish monitoring / disaster recovery solutions. Data & Performance Optimization: Design efficient data access layers, optimize database performance, implement caching solutions, and conduct load/stress testing.
