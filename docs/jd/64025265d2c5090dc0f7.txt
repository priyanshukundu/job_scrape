Job Description "This position is not open to visa sponsorship" This position will be responsible for the analysis, design, testing, development and maintenance of best in class software experiences. The candidate is a self-motivated individual who can collaborate with a team and across the organization. The candidate takes responsibility of the software artifacts produced adhering to U.S. Bank standards in order to ensure minimal impact to the customer experience. The candidate will be adept with the agile software development lifecycle and DevOps principles. Essential Responsibilities: Deploy, manage, and monitor cloud infrastructure supporting the Nimbus Uno model lifecycle platform Manage containerized workloads running in Azure Kubernetes Services Build and support ML workflows using frameworks such as scikit-learn, PyTorch, and XGBoost . Collaborate with engineers and product teams to design, develop, test, and deploy AI-enabled solutions. Develop scalable applications and APIs using Python and microservices-based architectures. Assist with deployment, monitoring, troubleshooting, and performance optimization of AI applications in production environments. Support cloud-based AI solutions across Azure and AWS platforms while following security and operational best practices. Contribute to CI/CD pipelines, automated testing, containerization, and infrastructure automation efforts. Participate in code reviews, documentation, and Agile delivery processes while following software engineering standards and best practices. Basic Qualifications: Bachelor’s degree, or equivalent work experience Two to three years of relevant experience Preferred Skills/Experience: Experience developing applications using Python and modern software engineering practices. Knowledge and experience with the Machine Learning Lifecycle. Experience with Azure and/or AWS cloud platforms and cloud-native application development. Understanding of REST APIs, microservices, distributed systems, and scalable application design . Experience with Docker, Kubernetes, CI/CD pipelines, and Infrastructure as Code (Terraform, ARM, or Bicep) . Understanding of application monitoring, logging, troubleshooting, and production support practices. Strong collaboration, problem-solving, and communication skills with the ability to work effectively in a team environment. Location expectations This role requires working from a U.S. Bank location three (3) or more days per week.
