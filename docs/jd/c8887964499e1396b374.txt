Title and Summary Senior Software Engineer Overview As a Senior Software Engineer in Mastercard’s Core Payments, Network Solutions team, you will develop software supporting payment and transaction-processing systems. You will combine software development and quality engineering to deliver secure, scalable, reliable applications and services. You will design, build, test, deploy, and maintain software components, automation frameworks, and validation tools. Working with engineers, architects, and product teams, you will contribute to technical decisions, strengthen operational readiness, review code, and mentor junior engineers. What You’ll Do Software Development • Design, build, test, deploy, and maintain software components, automation frameworks, and validation tools for payment-processing applications and services. • Apply data structures, algorithms, and efficient coding practices to deliver scalable solutions. • Contribute across the software development lifecycle, including deployment and monitoring. Design & Architecture • Translate business requirements into maintainable solutions using domain-driven design and established design patterns. • Contribute to architecture and system-design decisions supporting scalability, reliability, testability, observability, and performance. • Provide input into microservices and cloud migration strategies. Quality & Secure Engineering • Develop and maintain unit, functional, and integration tests across applications and services. • Build test automation frameworks and integrate validation into CI/CD pipelines using tools such as Jenkins and XL Release (XLR). • Design test strategies covering payment workflows, service interactions, performance, reliability, and production simulation. • Measure code quality and coverage using tools such as Sonar and Clover. • Apply and promote secure coding practices, vulnerability detection, and mitigation; integrate security testing into delivery pipelines. • Conduct and lead code reviews, and review system designs, test strategies, and implementation approaches. Performance & Operational Excellence • Improve system performance and scalability through load testing, tuning, and bottleneck analysis. • Build observability, monitoring, resilience, and operational readiness into solutions across environments. • Troubleshoot complex production issues, identify root causes, and support timely resolution. Collaboration & Technical Leadership • Partner with engineering, architecture, and product teams to deliver solutions and strengthen engineering practices. • Mentor junior engineers and share technical knowledge across teams. • Evaluate and recommend tools, technologies, and frameworks for continuous improvement.
