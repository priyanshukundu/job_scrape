About the Role We are seeking a Software Engineer to join our Dallas Service Delivery Center (SDC) and design, develop, deploy, and support services that automate privileged-access workflows. This role will build API- and event-driven solutions for privileged-account onboarding, vaulting, validation, membership management, and self-service capabilities across CyberArk, Delinea Server Suite, HashiCorp Vault, and related platforms. Key Responsibilities Design, develop, deploy, and support secure backend APIs, connectors, and workflow services that automate privileged-account onboarding, vaulting, lifecycle actions, role membership, and related PAM capabilities. Develop resilient integrations using REST APIs, Microsoft Graph, Azure Service Bus, microservices, event-driven architecture, queue processing, and PAM platform integrations. Translate business and technical requirements into solution designs, API contracts, user stories, test scenarios, and production-ready code. Implement secure development and automated testing practices, including unit, integration, API, end-to-end, regression, disaster-recovery, secrets management, code-quality, and least-privilege controls. Build and maintain CI/CD and deployment processes while troubleshooting application, API, queue, integration, data, and deployment issues using observability, resiliency, retry, and error-handling patterns. Collaborate across product, architecture, UX, DevOps, PAM, infrastructure, and engineering teams through Agile planning, design and code reviews, testing, release readiness, continuous improvement, and maintenance of technical and operational documentation. Required Qualifications, Skills and Technologies 3-8+ years of software engineering experience, including strong recent hands-on backend development experience. Strong proficiency in Java and Spring Boot, with working knowledge of Python and modern web technologies such as Angular, TypeScript, or JavaScript. Experience designing and consuming REST APIs, developing microservices, and implementing asynchronous or event-driven integrations. Experience with Microsoft Azure, Azure Service Bus, containerized applications, and Kubernetes-based deployment environments. Strong understanding of authentication, authorization, service accounts, Active Directory groups, secrets management, and secure application integration. Experience with automated unit, integration, API, and end-to-end testing, including the ability to diagnose failures across application, API, queue, and infrastructure layers. Experience with Git-based development workflows, CI/CD pipelines, automated deployment, code-quality practices, and DevSecOps tooling. Strong analytical, troubleshooting, documentation, communication, and collaboration skills. Ability to review existing code and architecture, identify gaps, and independently deliver production-ready enhancements. Preferred Skills & Technologies Application Development: Java, Spring Boot, Python, Angular, TypeScript, JavaScript, micro frontends, and .NET for selected legacy components. Cloud & Integration: Microsoft Azure, Azure Kubernetes Service (AKS), Azure Service Bus, Microsoft Graph, REST APIs, microservices, event-driven architecture, and containerized applications. PAM Platforms: CyberArk, Delinea Server Suite, HashiCorp Vault, AccessHub, and related onboarding and provisioning platforms. Privileged Access: Safes, privileged and shared accounts, interactive accounts, service accounts, command elevation, account onboarding, vaulting, credential lifecycle management, and privileged-role membership. Testing & Code Quality: Karate or comparable API-testing frameworks, automated end-to-end testing, SonarQube, GitHub CodeQL, Mend, and GitHub Advanced Security. DevSecOps & Operations: GitHub, Docker, CI/CD pipelines, infrastructure and configuration automation, ARM templates, Chef, Groovy, Datadog, Prometheus, and observability practices. Infrastructure: AKS, AVI GSLB, secure application integration, secrets handling, and automated deployment across controlled environments. Risk & Governance: Secure software development, change management, production-readiness controls, and regulated financial-services environments. Preferred Certifications Relevant Microsoft Azure, Java, Kubernetes, cybersecurity, DevSecOps, CyberArk, Delinea, or HashiCorp certifications are preferred. What You'll Bring A strong software-engineering and delivery mindset with the ability to build secure, resilient, and maintainable privileged-access solutions. You will help automate PAM workflows, reduce manual effort, improve request turnaround times, and deliver reliable integrations across applications, cloud services, identity platforms, and privileged-access technologies. Differentiator : Experience combining Java and Spring Boot development with Azure Service Bus, API- and event-driven architecture, automated testing, CI/CD, and hands-on integration with CyberArk, Delinea Server Suite, or HashiCorp Vault is highly desirable.
