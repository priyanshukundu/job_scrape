Grow Your Skills, Grow Your Potential Responsibilities Join State Farm's Enterprise Technology (ET) Claims – TPAR team as a Software Engineer and help modernize critical claims applications and transition the Enterprise Claims System (ECS) to AWS. You'll work with a collaborative engineering team to build and enhance applications, APIs, and database solutions that support essential claims operations. What You'll Do: Design, develop, and maintain applications and APIs using Java, Spring Boot, and Angular. Support the modernization of legacy applications and migration of services and data to AWS. Build and maintain DevOps pipelines using GitLab , supporting CI/CD, automated testing, and reliable deployments. Develop and optimize SQL queries and database integrations, including DB2 and AWS database technologies. Troubleshoot application, database, and performance issues to deliver reliable solutions. Collaborate with engineers and business partners to design, test, and implement modernization initiatives. Contribute to a collaborative Agile team through daily standups, knowledge sharing, and continuous improvement. Qualifications Required Qualifications DevOps: Hands-on experience with GitLab, CI/CD pipelines, automated deployments, and Git. AWS & Databases: Experience with AWS cloud services, SQL, relational databases, and database development or integration. Angular: Experience developing and maintaining web applications using Angular. Backend Development: Strong Java and Spring Boot experience, including REST APIs and microservices. Experience with automated testing, debugging, and application performance optimization. Strong problem-solving, communication, and collaboration skills. Preferred Qualifications Experience with DB2, Amazon Aurora PostgreSQL, or database modernization. Familiarity with AWS services such as API Gateway, Lambda, S3, and Secrets Manager. Experience with Docker, JUnit, Python, and secure API integrations. Experience modernizing legacy enterprise applications or migrating systems to AWS. Familiarity with claims systems or enterprise insurance applications. Experience leveraging GitHub Copilot or other AI-assisted development tools. Work Locations : Bloomington, IL-Corporate, Dunwoody, GA-Park Center Hub, Richardson, TX-CityLine Hub or Tempe, AZ-Marina Heights Hub locations.
