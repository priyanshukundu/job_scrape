We're hiring a Senior Software Engineer, Mobile QA to join the App Infra team within the Consumer & Business group. The team is leading the greenfield native rewrite of Coinbase's retail mobile app in Swift and Kotlin, replacing the existing React Native codebase to deliver a significantly faster experience for millions of customers. You'll own the test infrastructure and processes that ensure every native release meets an uncompromising quality bar. You’ll build automated regression frameworks directly into the AI-assisted code generation loop so defects are caught at commit time, not after. What you'll do: Own the design and implementation of automated regression test suites for native iOS and Android builds, setting the project-level quality bar through code reviews, test standards, and trade-off analysis that teammates and partners trust. Build test infrastructure integrated into the AI code generation cycle, enforcing automated test and performance verification at commit time and defaulting to automation where manual steps currently slow the team. Partner with mobile engineers to close coverage gaps, eliminate flaky tests, and fix the slow debugging workflows the team has learned to tolerate. Architect the QA strategy for the greenfield rollout, solving high-complexity problems around catching regressions while supporting urgent last-minute changes from product teams. Establish quality dashboards and SLOs that give the team real-time visibility into app stability, dropped frames, stall counts, and cold start times — turning release-by-release firefighting into durable, ever-increasing quality. Required Skills and Experience: 5+ years of software engineering experience with a focus on mobile test automation, including hands-on experience with XCTest, Espresso, or equivalent native testing frameworks for iOS and Android. Proven track record building automated regression infrastructure integrated into CI/CD pipelines (Buildkite, CircleCI, or similar), with measurable impact on release quality and cycle time. Proficiency in Swift and Kotlin sufficient to read, debug, and write test code against native mobile codebases, with demonstrated ability to architect robust technical solutions through trade-off analysis. Uses generative AI responsibly, maintaining human oversight to deliver business-ready outputs and measurable gains in workflow efficiency, cost, and quality.
