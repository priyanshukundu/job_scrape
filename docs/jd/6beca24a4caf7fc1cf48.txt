Job Description U.S. Bank is seeking an experienced software engineer to design, develop, and operationalize our enterprise architecture operations and technology intelligence capability. As a member of the Enterprise Architecture team, this role closely partners with architecture and technology stakeholders to streamline architecture and IT processes and enable capabilities to provide meaningful technology intelligence that facilitates technology strategy, planning and efficient IT operations. This position combines deep hands-on expertise in AI, programming languages (e.g. Python), data modeling and ETL, Architecture Tooling (SaaS), Cloud (AWS), and process automation. The ideal candidate will have a blend of strategic and practical design thinking, solving complex enterprise technology problems with enterprise grade solutions. Key Responsibilities Process Engineering Redesign architecture operational processes and build automations using AI, process tooling and code Build automations to collect business process data and enable an enterprise process intelligence repository Build and deploy process automation solutions on the cloud and with SaaS products Data and Meta Model Engineering Design and implement an enterprise meta model graph that acts as a “digital twin” of U.S. Bank’s IT operations Leverage data transformation tool (e.g. VaultSpeed) to transform data into consumable data products (e.g. gold and silver layers) Integrate and leverage with data analytics capabilities such as Data Bricks and Snowflake Architecture Tooling and Intelligence Implement, configure, and augment Enterprise Architecture and Process Mining tooling Analyze and redesign architecture processes Software Engineering & Architecture Develop scalable, maintainable applications using Python and microservices-based architectures Apply secure coding standards and robust data handling practices for regulated environments Build and manage CI/CD pipelines supporting automated testing, deployment, and release management Enforce engineering best practices including code reviews, testing, and documentation Technical Leadership & Influence Drive critical design decisions for large-scale IT operations solutions Translate business requirements into scalable, secure, and resilient technical solutions Partner with stakeholders across product, business, risk, and security functions Basic Qualifications Bachelor’s degree, or equivalent work experience Six to eight years of relevant experience Skills/Experience Hands-on experience with Artificial Intelligence (AI) technologies, including Claude Code, Generative AI, LLMs, and modern programming languages. Experience with Cloud Platforms, including Microsoft Azure and/or Amazon Web Services (AWS). Strong expertise in Data Modeling, Data Engineering, Data Pipelines, ETL/ELT Processes, and Analytics Platforms. Deep understanding of Distributed Systems, Scalable Architectures, High-Availability Solutions, and Performance Optimization. Proficiency in Python, Microservices Architecture, API Development, and Backend Engineering. Experience with Docker, Kubernetes, Container Orchestration, and Infrastructure as Code (IaC) tools such as Terraform or CloudFormation. Demonstrated Technical Leadership, Team Mentorship, Engineering Best Practices, and Cross-Functional Collaboration. Experience with Architecture Modeling, Process Modeling, Enterprise Architecture, and related design frameworks and tools. Background in Financial Services, Banking, FinTech, or other Highly Regulated Industries with strong knowledge of Risk, Compliance, and Security Standards.
