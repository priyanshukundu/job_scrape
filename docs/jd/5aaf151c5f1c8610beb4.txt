About the role: As a Software Engineer II on the storeLink engineering team, you will design, develop, and support key features for our cloud-native retail management platform. storeLink empowers grocery and drug retailers across three core operational capabilities: in-store price tag printing, Electronic Shelf Label (ESL) device management, and digital video screen display management. Operating within an Azure-hosted microservices architecture, you will work closely with dedicated feature sprint teams, our Principal Architect, and L2 Technical Support Engineers to deliver reliable, high-performance web applications and API integrations. This is a hybrid position that requires 2 days/week in-office. Currently we are only considering candidates within a commutable distance to our offices in Little Rock, AR; Dallas, TX; Mentor, OH; Miamisburg, OH; and New Century, KS. Key Responsibilities: Full-Stack Feature Development: Design, build, test, and maintain scalable microservices using .NET Core for backend web APIs and modern Angular for front-end web interfaces. Database & Cloud Infrastructure: Maintain and optimize MS SQL data structures, leverage Azure AI Search, and support applications hosted on Azure Kubernetes Service (AKS), Azure Service Bus, Blob Storage, Azure Front Door, and Application Insights. API Integration & Services: Integrate storeLink microservices with external systems via REST APIs, including custom rendering engines (such as UE2) for PDF and PNG media generation. CI/CD & Production Support: Manage GitHub version control, build/release pipelines using GitHub Actions, and partner with L2 support to triage and resolve escalated production issues. Quality, Compliance & Agile Methods: Implement unit/automated integration tests, adhere to internal security and SOX 404 controls, and participate in Agile code reviews and task estimation. BS in Computer Science, Engineering, or related technical field with 4+ years of software development experience (or MS with 1+ years). Proven experience building enterprise web applications using .NET Core, C#, Angular, and RESTful Web APIs within a microservices architecture. Strong proficiency in MS SQL / T-SQL development, schema design, query optimization, and working with managed database instances. Practical experience with Azure cloud components (AKS, Azure Service Bus, Blob Storage, Application Insights) and continuous integration/deployment using GitHub Actions. Strong debugging, analytical, and communication skills to resolve complex technical issues escalated from support teams and articulate designs to engineering leadership.
