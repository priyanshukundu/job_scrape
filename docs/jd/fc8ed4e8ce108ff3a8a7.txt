About the Role We are seeking a motivated Software Engineer II to support the design, development, testing, and maintenance of applications within the Field Rewards technology portfolio. This role will contribute to building modern web applications, APIs, and cloud-based solutions while working closely with senior engineers and business partners. The ideal candidate has a solid foundation in software engineering, enjoys solving technical problems, and is eager to grow expertise in cloud technologies, automation, DevOps practices, and full-stack development. What You'll Do Software Development Develop, test, and maintain web applications, APIs, and backend services using established engineering standards. Build and enhance application features under the guidance of senior engineers and technical leads. Participate in the design and implementation of reusable components and services. Write clean, maintainable, and well-documented code that meets quality and security standards. Support integration of applications with enterprise systems and third-party services. Cloud & DevOps Contribute to application deployments using CI/CD pipelines and automated deployment processes. Assist with containerizing applications using Docker and deploying solutions to cloud environments. Support implementation of infrastructure automation and configuration management practices. Monitor application health using established monitoring and alerting tools. Data & Integration Develop and maintain SQL queries, stored procedures, and data integration processes. Support batch processing and data movement workflows. Assist with troubleshooting data quality and integration issues. Work with relational databases and cloud-based data services. Quality & Engineering Excellence Participate in code reviews and testing activities to ensure high-quality software delivery. Follow established Agile development processes and engineering best practices. Collaborate with team members to identify opportunities for automation and process improvements. Contribute to technical documentation and knowledge sharing. Operational Support Assist with production support activities and incident resolution. Troubleshoot and resolve application issues in development, testing, and production environments. Participate in on-call rotations when required. Support release validation and post-deployment monitoring activities. Collaboration Work closely with engineers, product owners, architects, and business stakeholders. Participate in sprint planning, backlog refinement, retrospectives, and team ceremonies. Communicate technical concepts clearly to both technical and non-technical audiences. Seek feedback and continuously improve technical and professional skills. What You'll Bring to the Role Bachelor's degree in Computer Science, Engineering, Information Technology, or a related field (or equivalent experience). 2-4 years of professional software development experience. Experience developing applications using JavaScript or TypeScript. Familiarity with modern front-end frameworks such as React. Experience developing REST APIs or backend services using Node.js, Java, Python, or similar technologies. Experience working with relational databases and SQL. Understanding of software development lifecycle (SDLC) practices. Familiarity with Git-based source control and collaborative development workflows. Basic understanding of cloud computing concepts and public cloud platforms (AWS preferred). Familiarity with containerization technologies such as Docker. Strong analytical and problem-solving skills. Effective communication and teamwork skills. Preferred Qualifications Experience working in AWS cloud environments. Experience with CI/CD tools such as GitHub Actions, Jenkins, GitLab CI, or Azure DevOps. Familiarity with Kubernetes or container orchestration platforms. Experience supporting production applications. Experience with monitoring and logging tools. Knowledge of microservices architecture concepts. Exposure to application modernization initiatives. Experience working in Agile/Scrum teams. Insurance or financial services domain experience. Exposure to AI-assisted or agentic development tools.
