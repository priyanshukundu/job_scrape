Job Description: Job Title: Associate Location: Cary, NC Overview DB Global Technology, Inc. seeks an Associate in Cary, NC to analyze user requirements and design appropriate solutions. Requires a Bachelor’s degree in Computer Science, Computer Engineering, or related field or equivalent and two (2) years of experience building, maintaining, and implementing tests for automated testing frameworks; performing unit testing and integration testing across components using Junit and Spring Test; ensuring centralized dependency management across microservices on Maven platforms; designing and implementing new features and endpoints in Java-based microservices using Spring Boot, Java, and Oracle Database; utilizing Junit and Spring Boot test cases to ensure code quality across applications; and performing business requirement gathering sessions and collaborating with stakeholders to create technical designs and solutions using BigQuery, GCP PubSub, Java, Splunk, Spring Boot, TeamCity, GitHub, Kubernetes, Junit, Spring Test, Impala, Hive, Oracle Database, Flute Framework, Maven dependencies, and Confluence.
