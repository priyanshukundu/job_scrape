Job Summary: Clearwater Analytics is building its Generative AI engineering team, and this role sits at the center of that effort. You will design, implement, and ship LLM-powered agent tools, MCP integrations, and retrieval-augmented generation (RAG) systems that are already in production use and you will do it using AI-assisted development tools, including Claude Code, as a core part of your daily workflow. This is not exploratory AI work , it is applied engineering on real systems serving institutional investors globally. Fluency with coding assistants is not a perk here; it is a job requirement. Responsibilities Build and maintain LLM agent pipelines, MCP integrations, and retrieval-augmented generation (RAG) systems using Python (FastAPI, LangChain) and TypeScript/React. Use AI-assisted development tools, including Claude Code, as a primary part of your engineering workflow for code generation, debugging, and iteration. Collaborate with team members to optimize and improve existing AI-powered software applications. Participate actively in code reviews, giving and receiving clear, constructive feedback. Perform root-cause analyses for software issues and identify effective solutions. Translate loosely defined requirements into functioning, production-ready code. Assist in the creation of user stories and estimation of work for project planning. Suggest design improvements demonstrating a solid understanding of system architecture. Ensure software applications are scalable, reliable, and secure. Document software usage, implementation, architecture, design, and APIs. Write broad unit and integration tests consistently. Required Skills Fluency with AI-assisted development tools, Claude Code specifically ,as a daily engineering practice, not an occasional experiment. Hands-on experience building LLM agent tools, agentic workflows, MCP integrations, or retrieval-augmented generation (RAG) systems in a production environment. Production proficiency in Python 3.11 (FastAPI, LangChain) and TypeScript/React , these are the core languages of this role. Java-only backgrounds are not a fit. Solid fundamentals in data structures, algorithms, and object-oriented design. Enthusiasm for building in a fast-moving, AI-native SaaS environment. Strong teamwork and communication skills , written and verbal. Ability to manage own time and deliver results on time. Commitment to continuous learning and improvement. Exceptional analytical and problem-solving abilities. Strong attention to detail and documentation skills. Education & Experience Bachelor's degree in Computer Science or a related field. 2+ years of production software development experience At least 1 year of hands-on experience with LLM, agentic, or AI/ML systems in a production or near-production environment. Access to cutting-edge AI tools and infrastructure as part of your day-to-day work. A collaborative, high-trust engineering culture that values craft, speed, and continuous learning.
