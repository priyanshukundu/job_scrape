About the Opportunity Leidos is seeking a Junior Software Engineer to join a team developing, maintaining, and enhancing software systems supporting critical mission needs. This is an opportunity for an early-career software engineer to contribute to real-world software development while working individually and as part of an engineering team. You'll analyze requirements, design and modify software, debug defects, integrate software into operating environments, and help test software components against documented requirements. No demonstrated professional software engineering experience is required for this position. Why This Role Matters Mission software must continue to evolve as requirements, technologies, and operational needs change. As a Junior Software Engineer, you'll contribute directly to the development and improvement of software capabilities while building experience across the software engineering lifecycle. What You'll Do Software Development & Integration Analyze user requirements to derive software design and performance requirements. Design and code new software or modify existing software to add new features. Debug existing software and correct defects. Integrate existing software into new or modified systems and operating environments. Develop simple data queries for existing or proposed databases and data repositories. Software Quality & Engineering Practices Review and test software components for adherence to design requirements and document test results. Help resolve software problem reports. Apply software development and design methodologies appropriate to the development environment. Provide recommendations for improving documentation and software development process standards. Contribute to software-related system design considerations, including hardware/software tradeoffs, software reuse, COTS/GOTS alternatives, and requirements analysis from the system level to individual software components.
