Senior Software Engineer – Java/Python/Automation Position Overview Guardian is seeking a Senior Software Engineer to design and deliver scalable enterprise applications within our Group Operations Technology team. This role combines hands-on software development with technical leadership across the full Software Development Lifecycle. The engineer will collaborate with business, architecture, testing, release management, and global engineering teams to deliver modern, cloud-based solutions while improving development efficiency through automation and AI-assisted engineering practices. You Will (Primary Responsibilities) Translate business requirements into technical designs, user stories, and scalable solutions. Design, develop, and support Java/Spring Boot and Python-based APIs and microservices. Build and maintain automated API, UI, integration, and end-to-end tests. Integrate automated tests into CI/CD pipelines to support continuous quality validation. Collaborate with E2E testing and release management teams on non-production and production deployments. Troubleshoot application issues using logs and monitoring tools such as Splunk, CloudWatch, AppDynamics, and Argo CD. Participate in Agile ceremonies, code reviews, test planning, defect triage, and root cause analysis. Contribute to application modernization, cloud adoption, and proof-of-concepts; use GitHub Copilot and Claude for AI-assisted coding, test generation, and documentation, validating outputs for accuracy, security, and adherence to engineering standards. Provide technical guidance and collaborate effectively with onshore and offshore teams. You Have: Required Qualifications Bachelor’s degree in Computer Science, Engineering, or a related field, or equivalent professional experience. 5+ years of software development experience. Strong hands-on experience with Java, Spring Boot, Python, REST APIs, and microservices. Experience with relational and NoSQL technologies, including PostgreSQL and Redis. Experience with AWS, Docker, EKS, SNS/SQS, and cloud-native application development. Experience with Git, CI/CD pipelines, automated testing, and modern development workflows. Experience with API testing tools or frameworks such as Postman, PyTest, or REST Assured. Strong analytical, troubleshooting, communication, and problem-solving skills. Ability to review code and provide technical recommendations. Hands-on experience using GitHub Copilot and Claude for software development, with the ability to critically review AI-generated code and protect sensitive information. Preferred Qualifications Experience with LangGraph for building and orchestrating stateful, multi-step AI agent workflows. Experience integrating AI and large language models (LLMs) into enterprise applications through APIs, including prompt design, retrieval-augmented generation (RAG), and evaluation of model outputs. Experience with application monitoring tools such as Splunk, CloudWatch, AppDynamics, Argo CD, or Zenoss. Insurance or financial services domain experience. Group Insurance product platform knowledge.
