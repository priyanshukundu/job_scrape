Software Developer in Test
Stryker
Location: Portage, Michigan

Work Flexibility: Onsite Interested in a role where software meets real-world hardware? Join Stryker’s Acute Care team as a Software Developer in Test and use Python, CAN communication, and automated testing to help verify the performance of medical devices. You’ll write and debug test software, investigate hardware/software integration issues, participate in code reviews, and gain hands-on experience with HIL systems and laboratory test equipment. What You Will Do Develop Python-based automated test scripts to verify software and hardware integration. Develop and execute test cases to verify software and system requirements. Debug test software and investigate software/hardware integration issues to identify root causes and support resolution. Develop, maintain, and improve automated test frameworks and tools. Integrate automated tests into CI/CD pipelines using tools such as GitLab and Jenkins. Design, develop, and support Hardware-in-the-Loop (HIL) test systems and test fixtures. Work with CAN communication and other interfaces to test and troubleshoot embedded systems. Use laboratory equipment such as oscilloscopes and power supplies to support testing, debugging, and verification. Participate in code reviews, applying coding standards, design principles, and software development best practices. Collaborate with R&D, Quality, Regulatory, Manufacturing, Clinical, and other cross-functional partners to support software verification and medical device design controls. What You Need (Required Qualifications) Bachelor’s degree in Software Engineering, Computer Science, Computer Engineering, Electrical Engineering, or a related engineering discipline. 0+ years of work experience. Foundational programming skills, including Python, with exposure to software development, testing, and debugging. Foundational understanding of embedded systems and software/hardware integration. Familiarity with CAN communication through coursework, projects, internships, co-ops, or professional experience. Preferred Qualifications Experience with automated software testing, test script development, or test frameworks through coursework, projects, internships, co-ops, or professional experience. Familiarity with Git and CI/CD tools, such as GitLab or Jenkins. Exposure to Hardware-in-the-Loop (HIL) testing or test fixture development. Hands-on experience using laboratory equipment such as oscilloscopes, power supplies, or multimeters.
