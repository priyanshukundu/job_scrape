Job Description Summary Join the innovative Compute Science & Solutions (CSS) software platform team as a Software Developer. You will be part of a highly collaborative, global engineering organization working across multiple disciplines in a fast-paced environment. In this role, you will design, develop, optimize, and deliver compute platform software solutions spanning embedded, on-device, and edge computing technologies for cutting-edge medical devices. You will have the opportunity to work on advanced compute technologies that power next-generation medical devices, helping improve patient care around the world. Success in this role requires strong systems-level thinking, infrastructure software expertise, technical problem-solving capabilities, and a passion for delivering strong outcomes. The ideal candidate thrives in a team-oriented environment and can collaborate effectively with stakeholders both in person and remotely. Job Description Responsibilities In this role, you will: Lead the design, development, testing, and deployment of software applications, backend services, and platform tools using Python and modern software engineering practices. Provide technical support and guidance to junior and early-career software developers. Define and promote software development best practices, including code reviews, unit testing, automated quality checks, and CI/CD processes. Design and implement RESTful APIs, data services, and backend application components that support compute platform solutions. Collaborate with systems, hardware, infrastructure, cybersecurity, and product engineering teams to define technical requirements and deliver robust solutions. Drive software architecture decisions with a focus on scalability, maintainability, reliability, and performance. Develop and maintain automated test frameworks, ensuring high code quality and strong test coverage. Troubleshoot and resolve complex software issues across application, service, and infrastructure layers. Participate in Agile development activities, including technical planning, estimation, sprint execution, and continuous improvement. Evaluate emerging technologies, frameworks, and development tools to improve team productivity and solution quality. Required Qualifications Bachelor's degree in Computer Science, Computer Engineering, Software Engineering, or a related STEM discipline. 5+ years of professional software development experience. Strong proficiency in Python application development. Experience designing and developing RESTful APIs and backend services. Experience building production-quality software using modern Python frameworks and technologies, such as: FastAPI AsyncIO Pydantic SQLAlchemy Plotly Dash or similar web application frameworks Experience developing and maintaining automated unit, integration, and end-to-end tests. Strong understanding of software design patterns, object-oriented design, and application architecture principles. Experience performing code reviews and mentoring software developers. Experience working with relational databases including PostgreSQL and SQLite. Experience using Git-based source control workflows. Experience with CI/CD pipelines and DevOps practices. Experience developing software in Linux environments. Experience with Docker and containerized deployments. Strong communication skills and the ability to collaborate effectively across technical disciplines. Desired Qualifications Experience leading software development efforts or acting as a technical lead for small project teams. Experience mentoring junior developers and driving engineering excellence. Experience developing software in regulated industries such as medical devices, healthcare, aerospace, or industrial systems. Experience with software observability, monitoring, and performance analysis. Experience with edge computing, high-performance computing, or embedded systems. Familiarity with cybersecurity principles and secure software development practices. Experience working within Agile and Scrum development environments.
