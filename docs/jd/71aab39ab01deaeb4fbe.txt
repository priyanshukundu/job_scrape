Job Description The MES Software Engineer is responsible for the design, development, integration, deployment, and support of Manufacturing Execution System (MES) solutions within Automotive manufacturing environments. The role requires hands-on expertise in FactoryTalk ProductionCentre (FTPC), Modular Framework (MF), system integrations, database development, and production support across enterprise and shop-floor systems. This is an onsite position based in Alabama (Monday-Thursday, 7:00 AM-5:00 PM). Key Responsibilities; Design, configure, and implement MES solutions using FactoryTalk ProductionCentre (FTPC) and Modular Framework (MF). Develop and support MES functionality including production execution, traceability, genealogy, quality, and reporting. Design and implement integrations with ERP systems (SAP, Infor LN, custom ERP), PLCs, Kepware, FactoryTalk Live Data, databases, and web services. Develop custom applications, business logic, reports, interfaces, and database objects using Java, C#, .NET, SQL Server, REST/SOAP APIs, and related technologies. Perform system installation, configuration, testing, deployment, upgrades, and performance optimization. Troubleshoot application, integration, database, and production issues, providing Level 2/3 support. Create technical specifications, architecture documentation, and deployment procedures. Collaborate with project teams to estimate effort, define technical solutions, and support project delivery. Required Qualifications Bachelor's degree in Computer Science, Software Engineering, Electrical Engineering, Automation Engineering, or related field. Preferred Qualifications 5+ years of MES software engineering experience. Strong experience with: FactoryTalk ProductionCentre (FTPC) FactoryTalk Modular Framework (MF) MES implementation and customization Proficiency in: Java, C# .NET Framework/.NET Core SQL Server & T-SQL REST/SOAP Web Services Git/Azure DevOps Experience integrating MES with: SAP, Infor LN, or other ERP systems Kepware, FactoryTalk Live Data OPC DA/UA, PLCs, and industrial automation systems Knowledge of ISA-95, manufacturing operations management, traceability, genealogy, and Automotive manufacturing processes. Experience with performance tuning, troubleshooting, and production support of enterprise MES applications. Preferred Industry Experience: Automotive Manufacturing, Smart Manufacturing, Industry 4.0, Manufacturing Operations Management (MOM), and Digital Transformation initiatives.
