Job Description This position will be responsible for the analysis, design, testing, development and maintenance of best in class software experiences. The candidate is a self-motivated individual who can collaborate with a team and across the organization. The candidate takes responsibility of the software artifacts produced adhering to U.S. Bank standards in order to ensure minimal impact to the customer experience. The candidate will be adept with the agile software development lifecycle and DevOps principles. Essential Responsibilities: Design, develop, test, deploy, and maintain scalable software solutions using .NET, C#, Java, and Spring Boot technologies. Build and enhance RESTful APIs, microservices, and event-driven applications that support high-volume enterprise platforms. Develop cloud-native solutions in AWS , leveraging services such as EC2, Lambda, ECS/EKS, S3, RDS, and API Gateway. Collaborate with architects, product owners, and engineering teams to define technical requirements and deliver business solutions. Implement CI/CD pipelines and DevOps practices to automate build, testing, deployment, and monitoring processes. Perform code reviews, troubleshoot production issues, and optimize application performance, scalability, and reliability. Ensure compliance with security, risk, and coding standards through secure development practices and automated testing. Contribute to technology modernization initiatives , driving innovation, automation, and continuous improvement across engineering teams. Basic Qualifications - Bachelor’s degree, or equivalent work experience - Three to five years of relevant experience Preferred Skills/Experience Strong proficiency in C#, .NET Core/.NET 8, ASP.NET, and Java Spring Boot development. Experience building microservices, REST APIs, and distributed systems in enterprise environments. Hands-on AWS experience including services such as EC2, Lambda, ECS/EKS, S3, RDS, DynamoDB, CloudWatch, and API Gateway. Knowledge of containerization and orchestration technologies including Docker and Kubernetes. Experience with CI/CD tools and DevOps practices using GitHub Actions, Jenkins, Azure DevOps, or AWS CodePipeline. Strong database development skills with SQL Server, PostgreSQL, MySQL, or Oracle, including data modeling and performance tuning. Experience implementing secure application development practices , authentication, authorization, and cloud security controls. Strong analytical, problem-solving, and communication skills with the ability to work effectively in Agile Scrum environments. Nice to have: Experience leveraging AI-powered productivity and development tools, such as Microsoft Copilot, Claude, ChatGPT, or similar generative AI platforms, to improve efficiency, research, documentation, analysis, or problem-solving.
