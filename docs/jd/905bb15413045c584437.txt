Role Overview – Senior Full Stack Software Engineer We are hiring a Senior Full Stack Engineer to design, build, and ship production-grade systems end-to-end from data modeling and backend APIs through user interfaces and cloud deployment. You will build and own complete features across the entire stack and also specialize in building AI-powered agentic systems where intelligent agents plan, act, and integrate seamlessly into user workflows (PDLC). You'll work across six disciplines backend, frontend, cloud infrastructure, quality automation, data modeling, and data engineering to deliver observable, scalable, responsible and safe AI applications. Key Responsibilities Full Stack Ownership & Architecture Own features end-to-end: from database schema and backend service design to frontend interface and cloud deployment. Design scalable, distributed systems using microservices, event-driven architecture, and domain-driven design principles. Make architectural decisions balancing performance, reliability, and maintainability across all layers. Partner with product, design, and ML teams to translate requirements into deployable, well-tested solutions. Design and build secure-by-default applications following Zero Trust principles: verify explicitly, enforce least privilege, and assume breach across every layer from UI to data. Backend Engineering & APIs Design and build scalable APIs and services in Java (Spring Boot), Python, or TypeScript/Node.js: REST, GraphQL, gRPC, and streaming/WebSocket protocols or equivalent Event-driven and asynchronous systems for long-running agentic tasks using queues and workflow engines. Integrate LLM APIs and agentic frameworks: LangGraph, LlamaIndex, OpenAI, Anthropic SDKs, and Model Context Protocol or equivalent Multi-agent orchestration, memory management, and human-in-the-loop approval flows. Secure and scale backend systems: Authentication, authorization, rate limiting, and secrets management. RAG pipeline backends: embeddings generation, vector search, re-ranking, and guardrails. Prompt management, cost controls, and evaluation harnesses for agent behavior. Frontend Engineering Build responsive, accessible web applications using React JS and/or Angular with TypeScript. Create AI-native user interfaces: Streaming chat, agent activity timelines, approval workflows, and result visualizations. Real-time state management and responsive feedback for long-running AI tasks. Own frontend performance and developer experience: component libraries, state management, and shared design systems. Data Engineering & Analytics Design and build batch and streaming data pipelines (ETL/ELT) for AI and analytics: Tools: Spark, Kafka, Airflow, dbt, Snowflake, Databricks, BigQuery or equivalent Ingest, clean, and transform data for AI model inputs and system observability Manage embedding generation and refresh pipelines for vector stores and RAG systems Ensure data quality, lineage, and compliance: GDPR, SOC 2, and privacy controls. Cloud Infrastructure & DevOps Design and operate AWS infrastructure end-to-end: account structure, networking (VPC, security groups, NACLs), IAM (roles, policies, cross-account access), and multi-region strategies. Define infrastructure as code using Terraform or CloudFormation; maintain environment parity across dev, staging, and production with modular, reusable components. Deploy and manage runtimes: Kubernetes (ECS/EKS) for complex AI workloads, Lambda and Fargate for serverless event-driven tasks, and service mesh patterns for observability and resilience. Implement security and compliance as code: enforce least-privilege access, encryption, audit logging, SOC 2 / GDPR compliance, and automated remediation. Build observability and cost management: centralized logging, distributed tracing (CloudWatch, X-Ray), cost optimization (tagging, reserved capacity, spot instances), and dashboards for incident investigation. Operate reliably at scale: design disaster recovery, auto-scaling policies tuned for variable LLM latency, and capacity planning. Quality & Reliability Design and implement automated testing across all layers: unit, integration, end-to-end, and performance tests. Participate in on-call rotation and lead incident postmortems for owned services. Build monitoring and safety guardrails for AI agents: cost tracking, behavior validation, and anomaly detection. Collaboration & Leadership Mentor other engineers and contribute to technical architecture decisions. Lead design reviews, write clear technical documentation, and communicate trade-offs to stakeholders. Collaborate across teams (product, design, ML, data science) from conception through production.
