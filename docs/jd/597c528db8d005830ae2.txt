Job Description As a Staff/Senior Software Engineer - Networking in the AV (Autonomous Vehicle) Core Infrastructure organization, you will build and maintain software systems that automate, manage, and operate the secure hybrid network fabric supporting the global AV development pipeline. You will combine strong networking expertise with production software engineering skills to enable reliable, high-performance movement of sensor and validation data between on-premises environments and Google Cloud Platform (GCP). This is primarily a software development role, not a network operations role focused on scripting or manual device configuration. You will design, build, test, deploy, and operate production network services in Go and Python. You will apply software engineering, distributed systems, and Site Reliability Engineering (SRE) practices to reduce configuration drift and manual operations across the network supporting GM's Vehicle Autonomy mission. Key Responsibilities Network Software Systems Design, build, test, deploy, and maintain production network services and automation using Go, Python, and modern software engineering practices. Develop APIs, controllers, integrations, and tools that automate network provisioning, configuration, validation, and lifecycle management. Apply distributed systems principles, API design, concurrency, automated testing, and safe rollout strategies to network infrastructure. Advance Network as Code practices by ensuring network changes are version-controlled, peer-reviewed, tested, and deployed through CI/CD workflows. Define, monitor, and improve Service Level Objectives (SLOs) for network services, including availability, latency, throughput, and change reliability. Apply SRE principles to reduce operational toil, configuration drift, and recurring failure modes. Build telemetry and observability capabilities that provide actionable insight into hybrid connectivity and network-service health. Hybrid Network Architecture & Strategy Contribute to the design and evolution of the network connecting on-premises data centers, validation environments, test facilities, and GCP. Design secure, scalable, and multi-tenant network solutions that protect sensitive AV data while enabling high-performance access for developer tools, automated build systems, and compute workloads. Develop reusable Infrastructure as Code modules and self-service capabilities for engineers and researchers. Partner with network, cloud, security, and platform teams to translate architectural requirements into reliable software and automated workflows. Provide technical leadership on complex projects and mentor other engineers while remaining a hands-on individual contributor. Data Ingestion & On-Prem Connectivity Optimize end-to-end network paths from hardware ingestion points through secure hybrid connectivity and into cloud storage and compute environments. Support the low-latency, high-throughput, and highly available connectivity required by validation environments and hardware-in-the-loop (HIL) simulations. Collaborate with hardware systems, cloud infrastructure, and platform engineering teams to integrate validation worker pools with cloud-native infrastructure and services. Build automation and operational safeguards that make high-volume data movement reliable, observable, and recoverable. Security, Performance & Reliability Implement secure network-service patterns, including least-privilege access, segmentation, encryption in transit, and automated policy enforcement. Use performance testing, telemetry, and capacity planning to maintain the throughput and reliability required by AV development workloads. Participate in an on-call rotation and incident response for network services and hybrid connectivity. Diagnose complex failures using logs, metrics, traces, packet captures, and network telemetry across application, host, network, and cloud layers. Lead or contribute to blameless incident reviews and implement corrective actions that prevent recurrence. Manage error budgets and balance delivery velocity with service reliability. Technical Domain Knowledge Strong software development experience building and operating production services in Go, Python, or comparable modern programming languages. Experience with distributed systems, software design, APIs, concurrency, automated testing, code review, CI/CD, debugging, and production operations. Strong Linux systems knowledge and an understanding of how applications interact with host and network resources. Strong networking fundamentals, including routing, switching, TCP/IP, DNS, data center networking, and BGP. Hands-on experience with GCP networking, such as VPCs, Shared VPCs, routing, firewall policies, load balancing, and hybrid connectivity. Experience with infrastructure automation and configuration management using tools such as Terraform or Ansible. Experience with cloud-native platforms such as Kubernetes and with continuous or GitOps-based delivery workflows. Familiarity with observability and telemetry technologies such as Prometheus, Grafana, Telegraf, or centralized logging platforms. Qualifications Proven experience building and operating production network software and automation. Strong networking, software engineering, Linux, and cloud infrastructure skills. Experience with on-call support and incident response. Ability to lead projects and mentor engineers as a senior individual contributor. Bachelor's degree in a related field, or equivalent practical experience, preferred. 6+ years of relevant software, networking, or SRE experience preferred. Professional networking or cloud certification preferred. Experience with large-scale networks, SRE practices, high-throughput data systems, EVPN, or VXLAN is a plus.
