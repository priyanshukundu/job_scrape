ABOUT LEGAL ENGINEERING The Legal Division advances and protects the interests of the firm by providing high-quality legal advice and helping identify and address legal, regulatory and reputational risk. Legal Engineering supports this mission by designing, building and operating user-facing, workflow, data and AI-enabled platforms that help legal professionals work effectively and make well-informed decisions. Our engineers work directly with business partners and cross-functional teams. We combine modern software engineering, cloud platforms, data capabilities and responsible artificial intelligence to solve complex problems in a controlled environment. YOUR IMPACT As an Analyst or Associate Software Engineer, you will contribute across the full software development lifecycle. You will turn business needs and written specifications into tested, maintainable solutions, while using AI-assisted development tools thoughtfully and remaining accountable for the quality, security and correctness of the resulting code. HOW YOU WILL FULFILL YOUR POTENTIAL Design, develop, test, deploy and support full-stack applications, APIs, workflows and data-processing services used by Legal Division stakeholders. Provide ongoing application support and work directly with users to understand and resolve day-to-day needs, questions and production issues; troubleshoot problems, communicate status clearly and implement sustainable fixes that improve reliability and the user experience. Partner with legal professionals, product managers, designers and engineers to understand problems, clarify requirements and deliver practical end-to-end solutions. Participate in a spec-driven design process by helping convert business objectives into clear functional requirements, technical specifications, acceptance criteria, interfaces and test scenarios before implementation. Write clean, maintainable and well-tested code grounded in strong software engineering fundamentals, while effectively leveraging AI-assisted development tools such as Devin, GitHub Copilot and Claude Code to accelerate delivery. Exercise sound engineering judgment by critically evaluating, validating and refining AI-generated solutions to ensure they are correct, secure, scalable and appropriate for the problem being solved. Build intuitive user experiences and reliable backend services using technologies appropriate to the product, including TypeScript, React, Python, Java and API frameworks. Work with structured and unstructured data, including data mapping, transformation, search and integration patterns. Operate collaboratively in an agile environment, communicate trade-offs clearly and continuously learn new technologies and domain concepts. BASIC QUALIFICATIONS Bachelor's or Master's degree in Computer Science, Computer Engineering, Software Engineering, Mathematics, Statistics, Engineering or a closely related technical field. Foundational knowledge of computer science concepts, including data structures, algorithms, object-oriented or functional design, databases, networking and software testing. Hands-on programming experience in one or more modern languages. Experience with TypeScript / JavaScript, Python and Java is especially relevant to this role. Experience building or contributing to web applications, backend services or APIs Understanding of software development lifecycle practices, version control, automated testing, continuous integration and deployment concepts. Comfort using AI-assisted development tools such as Devin, GitHub Copilot or Claude Code, together with the judgment to independently inspect, test and challenge generated code rather than accept it without review. Strong analytical and problem-solving skills, attention to detail and the ability to communicate clearly with both technical and non-technical stakeholders. Intellectual curiosity, sound judgment and a willingness to learn the legal domain, new technologies and emerging AI engineering practices. PREFERRED QUALIFICATIONS Experience with relational or NoSQL databases, data modeling, data manipulation or data mapping. Exposure to cloud platforms, containers and orchestration technologies such as Kubernetes. Knowledge of API design, event-driven architectures, search platforms or real-time processing. Experience with modern AI / machine learning ecosystems, including retrieval-augmented generation, agent frameworks, model evaluation or prompt and context engineering. Experience with Microsoft 365 extensibility, including Office.js, is a plus. Interest in financial services, legal technology, compliance, risk or other highly controlled business environments. WHAT SUCCESS LOOKS LIKE You deliver working software that meets its specification and acceptance criteria, with appropriate tests and documentation. You use AI-assisted tools to improve development effectiveness without lowering engineering, security or review standards. You identify uncertainty early, ask precise questions and make technical trade-offs visible to stakeholders. You contribute constructively to design discussions, code reviews, operational support and continuous improvement of the team’s engineering practices.
