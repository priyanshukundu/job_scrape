Key responsibilities Are you a Java expert who enjoys solving complex technical challenges in elegant ways? Are you excited by modern frameworks, tools and engineering practices? Do you want to build scalable technology that improves loan execution and processing? We are looking for a Java Developer to: • design, develop and enhance digital products and technology services, delivering technical analysis, specifications, component designs, code, tests, documentation and other engineering artifacts • build scalable service-layer and API solutions in collaboration with business analysts, engineers, database developers and quality assurance professionals • apply software engineering practices including automated testing, CI/CD and DevOps, and manage CI/CD and release cycles to continuously improve our products and services • build observability into solutions, monitor production health, resolve incidents and address the root causes of risks and issues to maintain secure, reliable and compliant solutions • troubleshoot, debug and upgrade existing software and APIs, while evaluating new technologies and reusing strategic platforms and standards with long-term sustainability in mind • work in agile, multidisciplinary teams, advocate for client needs, share technical knowledge, support hiring and mentor junior team members The team You’ll join the Global Banking Loans team, focused on building loan execution and processing capabilities across UBS and the industry. You’ll work with colleagues across disciplines and locations, contributing to our engineering culture while delivering high-quality technology solutions. The role is based in Weehawken, New Jersey. Your skills and experience • ideally 8+ years of relevant Java development experience, including Spring Framework, REST API development and the ability to write clean, efficient code based on specifications • experience with software design and development in a test-driven environment, including CI/CD workflows and tools such as Maven or Ant, Eclipse, GitLab, Jira, TeamCity and Nexus • proficiency in relational database concepts and technologies including JDBC, SQL and RDBMS, plus object-relational mapping (ORM) frameworks such as Hibernate • strong computer science fundamentals, including object-oriented programming (OOP), UML, SOLID principles, data structures and design patterns • experience with Agile development practices such as Scrum, Extreme Programming (XP) and Kanban, and working effectively with global teams • experience troubleshooting, debugging and upgrading software, as well as managing security vulnerabilities using tools such as SonarQube and Fortify • exposure to microservices, messaging technologies such as TIBCO and Apache Kafka, and web technologies including React, JavaScript, Apache HTTP Server and Apache Tomcat • exposure to Microsoft Azure services, including Azure Kubernetes Service (AKS) and CI/CD, plus caching and monitoring technologies; knowledge of syndicated loans and strong English communication skills are an advantage • you’re curious to explore how AI can improve how we build, deliver, and optimize workflows. You do this with sound judgment – validating outputs and aligning with policies, risk standards, and ethical use.
