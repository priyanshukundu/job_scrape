Become a part of our caring community We are seeking a Software Engineer with experience developing, testing, and supporting production applications. The preferred candidate will have exposure to Epic or a similar healthcare technology platform and experience using Claude or comparable AI-assisted development tools to support coding, debugging, testing, documentation, and technical analysis. Working closely with cross-functional partners, this individual will help deliver secure, scalable, and maintainable solutions while contributing to application reliability, software quality, and engineering efficiency. The ideal candidate will bring strong problem-solving skills, responsible technical judgment, and demonstrated achievements such as reducing defects, improving performance, automating processes, increasing test coverage, or accelerating software delivery. Key Responsibilities Design, develop, test, deploy, and maintain reliable software applications based on business requirements and technical specifications. Use Claude and other AI-assisted development tools to support coding, debugging, documentation, test creation, code analysis, and solution design while following established security and quality standards. Translate functional and non-functional requirements into scalable, maintainable, secure, and supportable technical solutions. Support the development, integration, or enhancement of solutions within Epic or a comparable healthcare technology platform. Troubleshoot complex application issues, research production incidents, identify root causes, and implement sustainable fixes. Participate in code reviews and contribute clean, maintainable, reusable, and well-documented code. Strengthen software quality through unit testing, integration testing, automated testing, defect resolution, and continuous improvement of quality assurance practices. Collaborate with product owners, business partners, architects, analysts, quality engineers, and other cross-functional stakeholders to understand priorities, dependencies, and desired outcomes. Contribute to continuous integration and continuous delivery practices, including automated build, testing, deployment, and release processes. Identify opportunities to use AI-assisted development responsibly to improve developer productivity, accelerate delivery, and enhance code quality. Follow established engineering, data privacy, security, documentation, and software development lifecycle standards. Work with moderate independence in an evolving and sometimes ambiguous environment, taking ownership of assigned work while seeking guidance when appropriate. Share technical knowledge, lessons learned, reusable solutions, and development best practices with the broader team. Contribute to improvements in developer experience, team efficiency, application reliability, and consumer-facing outcomes. Required Qualifications Bachelor’s degree in computer science, Information Systems, Software Engineering, or a related technical field. 3 to 5 years of professional experience in software engineering, application development, systems analysis, or a related technical discipline. Hands-on experience designing, coding, testing, debugging, and maintaining software applications in a production environment. Practical experience using Claude or a comparable generative AI development assistant to support activities such as code generation, refactoring, debugging, technical documentation, test creation, or solution analysis. Ability to evaluate, validate, and improve AI-generated code rather than relying on generated output without appropriate technical review. Experience with source control, pull requests, code reviews, branching strategies, and standard software development lifecycle practices. Experience working in Agile, Scrum, or another iterative development environment. Experience troubleshooting production issues and translating findings into reliable technical solutions. Strong analytical, problem-solving, technical documentation, and communication skills. Demonstrated ability to contribute meaningful technical results, such as improving application performance, reducing defects, accelerating delivery, automating manual processes, or strengthening system reliability. Preferred Qualifications Experience developing, configuring, integrating, or supporting solutions within Epic or a similar healthcare technology platform. Experience working with healthcare applications, clinical workflows, healthcare data, interoperability, or regulated technology environments. Epic certification or relevant Epic training is beneficial but not required. Experience integrating applications through APIs, web services, messaging frameworks, or healthcare interoperability standards. Experience creating effective prompts, reusable workflows, or development standards for Claude or other approved AI-assisted engineering tools. Experience with CI/CD pipelines, build automation, deployment automation, and release management. Experience with automated testing frameworks, code quality tools, application monitoring, or secure software development practices. Experience working in cloud-based, distributed, or highly integrated application environments. Experience improving developer workflows, engineering efficiency, operational reliability, or application support processes. Previous achievements such as delivering a significant application enhancement, reducing production defects, increasing test coverage, automating a manual workflow, or improving development cycle time. Master’s degree in computer science, Information Systems, Software Engineering, or a related field.
