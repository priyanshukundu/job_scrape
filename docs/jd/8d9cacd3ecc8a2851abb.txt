Title and Summary Software Engineer II Overview Mastercard’s Fraud Products team develops capabilities for the Decision Management Platform, which supports solutions designed to combat fraud and validate cardholder identity. This Java-based platform processes billions of transactions each month using a distributed, message-oriented architecture built for high performance and availability. As a Software Engineer II, you will develop, test, deploy, and support applications and services within this platform. You will independently apply core software engineering skills in routine and moderately complex situations, partnering with technical leads and other team members when addressing unfamiliar or highly complex challenges. What You’ll Do Software Development •Design, build, test, deploy, and maintain Java-based applications and services. •Translate business and technical requirements into maintainable software solutions. •Apply data structures and programming concepts to support efficient system performance. •Integrate vendor and open-source technologies into existing systems. •Contribute to Agile discovery, planning, development, and delivery activities. Design & Architecture •Develop software designs that address functional, performance, security, and operational requirements. •Apply established architectural patterns and standards when building distributed applications. •Partner with technical leads to understand system interactions, dependencies, and design decisions. •Support high-performance, highly available transaction-processing solutions. Quality & Secure Engineering •Create and maintain unit, functional, and integration tests. •Apply secure coding practices throughout the software development lifecycle. •Participate in code reviews to improve readability, maintainability, and adherence to engineering standards. •Identify and resolve defects before they affect production systems. Performance & Operational Excellence •Analyze and optimize application performance, scalability, and reliability. •Troubleshoot technical issues and support the resolution of production incidents and problem tickets. •Contribute to monitoring, observability, alerting, and operational readiness. •Develop an understanding of application runtime behavior, dependencies, infrastructure, and support requirements. Collaboration •Partner with engineers, technical leads, Product, Architecture, and other cross-functional teams. •Communicate effectively within a globally distributed environment. •Share technical knowledge and contribute to continuous improvement. •Demonstrate ownership, initiative, and accountability for assigned work. Required Qualifications •Bachelor’s degree in Computer Science, Engineering, Information Technology, Information Systems, or a related field, or equivalent practical experience. •Software development experience using Core Java, including multithreading. •Knowledge of Java/J2EE, Spring Framework, and Spring Boot. •Experience writing unit, functional, and integration tests. •Understanding of software design principles, architectural patterns, and distributed systems. •Ability to apply secure coding practices and participate in code reviews. •Knowledge of data structures and their application to software development. •Experience troubleshooting applications and supporting production issues. •Familiarity with performance testing, monitoring, analysis, or system optimization. •Understanding of observability and operational support practices. •Experience with Oracle, PL/SQL, and advanced SQL scripting. •Knowledge of Agile development practices and test-driven development. •Ability to work independently on routine and moderately complex assignments, seeking guidance when addressing unfamiliar or highly complex situations. •Strong communication, collaboration, organizational, and problem-solving skills. Preferred Qualifications •Experience with high-performance, high-availability transaction-processing systems. •Knowledge of distributed computing technologies such as GemFire, Apache Spark, Redis, Hazelcast, GridGain, or similar platforms. •Familiarity with messaging technologies such as MQ and JMS. •Experience using Splunk to create dashboards, alerts, or monitors. •Knowledge of Linux and shell scripting. •Experience integrating vendor and open-source products into enterprise systems. •Familiarity with development environments such as IntelliJ IDEA or JBoss Developer Studio. •Experience within payments, fraud prevention, financial services, or another regulated industry. Success Measures A successful Software Engineer II will: •Independently deliver assigned software features from development through production support. •Produce maintainable code that follows established design, testing, and security standards. •Apply software architecture and data structure concepts to routine and moderately complex solutions. •Effectively troubleshoot defects, incidents, and performance concerns. •Strengthen application reliability through testing, monitoring, and operational readiness. •Participate constructively in code reviews and technical discussions. •Demonstrate growing ownership and consistency across the software development lifecycle.
