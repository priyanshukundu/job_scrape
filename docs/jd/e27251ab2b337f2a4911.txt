Skills and Competencies Strong software engineering fundamentals with experience designing, building and operating scalable full-stack applications and services Strong hands-on experience with React and TypeScript, including building modern user-facing applications and interfaces Typically, around 5+ years of software engineering experience, although demonstrated technical expertise and relevant engineering capability are more important than a strict years-of-experience requirement Experience designing and developing application programming interfaces (APIs) and integrations that connect front-end applications with backend services and systems Familiarity with AI agents, agentic workflows and workflow orchestration tools, with an understanding of how applications interact with AI models and agent services Understanding of modern software architecture, including service boundaries, asynchronous processing, integration patterns, automated testing, continuous integration and continuous delivery Strong problem-solving skills with the ability to break down ambiguous technical problems, evaluate solutions and communicate technical decisions clearly Experience with Node.js is beneficial, particularly for contributing across full-stack engineering teams, while experience with Rust is an advantage but not required Experience with Model Context Protocol, AI agent tooling, retrieval-augmented generation, AI evaluation, observability or related technologies would be advantageous Education Bachelor's degree in Computer Science, Software Engineering or a related technical field, or equivalent practical experience Responsibilities Build the applications, interfaces and integrations that enable users and systems to interact effectively with AI agents across Moody's compliance platform. Design, build and maintain front-end applications using React and TypeScript that allow users to interact effectively with AI-powered agents and workflows Develop and maintain APIs, services and integrations that connect user-facing applications, AI agent models and wider platform capabilities Build applications around agentic AI workflows, leveraging agent and workflow orchestration frameworks Develop and maintain AI agent capabilities, including tool integrations, Model Context Protocol integrations, prompts, skills and the application services that interact with them Work closely with full-stack, machine learning and AI engineers to take features from initial design through development, testing and production Contribute across the technology stack where needed, including integration and backend development using technologies such as Node.js and, where appropriate, Rust Design reliable and secure service-to-service integrations, considering authentication, application programming interface contracts, resilience and appropriate access controls Develop thorough unit, integration and end-to-end tests, and contribute to healthy continuous integration, dependency security and code-quality practices Break down ambiguous technical problems, write clear implementation plans and tickets, review teammates' code and contribute to engineering design decisions Own features through the full software development lifecycle, including deployment, observability, monitoring and ongoing production support About the Team The Agents Team builds AI-powered agents and the supporting applications and services for Moody's compliance platform. The team brings together full-stack, machine learning and AI engineers to develop agent-based capabilities that help users interact with complex data, workflows and compliance processes. As a Senior Software Engineer, you will focus particularly on the application and interaction layer around these AI agents, building the front-end experiences, APIs and integrations that connect users and systems to underlying agent models. The team works with technologies and frameworks including React, TypeScript and a range of agentic AI and orchestration tooling, with opportunities to contribute across the wider technology stack. You will work in an environment where AI is both part of the products we build and a tool used thoughtfully to improve engineering productivity.
