Job Description: The Role Develops enterprise software solutions and performs end-to-end functional and non-functional testing within an Agile environment. Designs, develops, and maintains full-stack applications using Java/Spring MVC, Spring Core, Spring Boot, Angular, and Node.js. Implements interactive User Interface (UI) designs using Bootstrap5, CSS, AG Grid, and Angular Material. Tests and writes automated unit, integration, and end-to-end tests with tools -- cypress, junit, cucumber and karate. Maintains highly available, multi-region Kubernetes (AWS EKS environments), supporting mission-critical workloads. Writes SQL queries and debugs stored procedures within an Oracle environment. Provides business solutions by developing complex or multiple software applications. The Expertise and Skills you Bring Design, develop, and maintain scalable, high-performance web applications across both front-end and back-end technologies. Architect and implement end-to-end solutions using modern frameworks, APIs, databases, and cloud-native services. Collaborate with product managers, architects, UX designers, and engineering teams to translate business requirements into technical solutions. Lead the development of responsive, accessible, and user-friendly interfaces while ensuring seamless integration with backend services. Build and maintain RESTful APIs, microservices, and event-driven architectures that support enterprise-scale applications. Develop, deploy, and support solutions on cloud platforms such as AWS and Azure. Drive adoption of DevOps practices, including CI/CD pipelines, infrastructure automation, monitoring, and observability Ensure application security, reliability, scalability, and performance through best practices in coding, testing, and architecture. Perform code reviews, provide technical mentorship, and promote engineering excellence across the development team. Troubleshoot complex production issues and implement solutions to improve system stability and operational efficiency. Partner with cross-functional teams to ensure compliance with organizational, security, and regulatory requirements. Performs independent and complex technical and functional analysis for multiple projects supporting several initiatives. Bachelor’s degree in Computer Science, Engineering Science, Engineering, Information Technology, Information Systems, or a closely related field (or foreign education equivalent) and three (3) years of experience as a Senior Full Stack Engineer (or closely related occupation) designing, developing, testing, and maintaining software for UIs, middle-tier (Java), and back-end (PLSQL), according to Agile or Scrum methodologies. Or, alternatively, Master’s degree in Computer Science, Engineering Science, Engineering, Information Technology, Information Systems, or a closely related field (or foreign education equivalent) and one (1) year of experience as a Senior Full Stack Engineer (or closely related occupation) designing, developing, testing, and maintaining software for UIs, middle-tier (Java), and back-end (PLSQL), according to Agile or Scrum methodologies. Demonstrated expertise ('DE') in designing, developing, and maintaining enterprise-scale web applications using modern front-end technologies (Angular, React, JavaScript/TypeScript, HTML5, CSS3, AG-Grid, Angular Material) and back-end technologies (Java, Node.js, or similar frameworks); Implementing front end unit tests using Junit, Jest, Cy-press, and Playwright; DE implementing and coordinating Continuous Integration and Continuous Deployment (CI/CD) pipelines using Jenkins, Git or GitHub, Kubernetes, Bitbucket, and Artifactory; monitoring code quality using SonarQube and Veracode; performing infrastructure automation using Python and PowerShell; performing and automating load testing using JMeter, Selenium, Cypress, and TestNG; and building Jenkins pipelines for Docker containers and deploying applications in a Cloud environment. DE designing and developing RESTful APIs using Java17, Spring Boot, OAuth, and Python; building scalable messaging applications using Kafka; developing secure, Cloud-native applications using AWS core services (EC2, S3 and lambda); coordinating infrastructure automation using DevOps scripting, Python, and PowerShell; and Datadog (for real-time monitoring). DE developing and coordinating database systems using Oracle; performing database normalization and tuning Oracle queries.
