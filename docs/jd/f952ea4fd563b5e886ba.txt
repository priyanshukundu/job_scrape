About The Opportunity Wonder's Model Platform team builds the systems that take machine learning models from prototype to production and keeps them running well once they're there. Our models rank restaurants and dishes, predict delivery times, price orders, and dispatch couriers for millions of diners across Grubhub and Wonder. Most of those predictions are served to high-traffic Java services. How well a model works with those services matters as much as how good the model is. We're hiring a Staff Machine Learning Engineer with deep Java backend experience to set the technical direction for how our models and services work together. You'll define how every team calls our models. You'll set the standards for load testing and performance across the services that use them. You'll also lead complex ML work that spans multiple teams and systems. This is a hands-on technical leadership role. You'll write code, design models, and take on the hardest production problems yourself. You'll be the main technical link between Model Platform and our software engineering teams, and you'll partner with Applied Scientists, our data and infrastructure platform teams, and senior engineering leadership. Our interview process includes the same Java coding interview our software engineers take. The Impact You Will Make Define the standard architecture for how Java services call ML models, including client libraries, API contracts, latency budgets, and fallbacks. Set the standards for load testing, performance benchmarking, and capacity planning for every service that calls our models, and build them into the release process. Drive performance work such as profiling, JVM tuning, caching, request batching, and concurrency for our highest-traffic model integrations. Lead the design and delivery of complex ML solutions that span multiple teams or systems, and make the architecture decisions that cross team boundaries. Build reusable ML architectures, pipelines, and deployment patterns that get Applied Science work into production faster. Set the standards for ML reliability, scalability, monitoring, and lifecycle management, including model scorecards, reproducible training, safe rollout, and SLOs for tier-1 models. Own model architecture and tuning for our most demanding deployments, balancing accuracy against latency, scalability, and cost. Run design and code reviews across ML and software engineering teams, and push back on technical decisions when the evidence supports it. Own the platform's technical roadmap with engineering leadership, sequence work across teams, and raise risks early. Mentor senior and mid-level engineers, take part in hiring, and build depth on the team so no critical system depends on one person. Explain technical trade-offs in business terms to product and executive stakeholders, and write down key decisions and the reasons behind them.
