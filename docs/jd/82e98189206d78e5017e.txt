The Crown Is Yours As a Senior Machine Learning Engineer on our ML Platform Team, you’ll build the cloud infrastructure and systems that power machine learning across DraftKings. You’ll design scalable platforms, automate deployments, and strengthen the reliability of the tools that help our teams bring machine learning models into production. Working alongside Data Scientists and Machine Learning Engineers, you’ll solve complex engineering challenges using Python, Terraform, and modern cloud technologies. Your work will shape how we scale machine learning capabilities across the organization while creating opportunities to expand your expertise in production machine learning systems. What you’ll do Design, build, and maintain scalable cloud infrastructure that supports machine learning workloads, including compute, storage, networking, and access management using Terraform. Develop continuous integration and continuous deployment (CI/CD) pipelines, automation, and self-service tools that streamline infrastructure provisioning and application deployments. Own the design, deployment, and ongoing performance of production systems, driving improvements in reliability, monitoring, and cost efficiency. Build and optimize data infrastructure to support high-volume batch and streaming workloads, including real-time data ingestion using Kafka and lakehouse technologies. Strengthen platform security and governance through access controls, infrastructure policies, and resource management across shared cloud environments. Collaborate with Data Scientists, Machine Learning Engineers, and Infrastructure Teams to develop reusable solutions that support model training, deployment, and monitoring. Lead technical design discussions, review code, and mentor engineers while advancing engineering standards and best practices across the team. Evaluate emerging cloud and infrastructure technologies to identify opportunities to improve platform scalability, performance, and operational efficiency. What you’ll bring A Bachelor’s Degree in Computer Science, Engineering, or a related field, or equivalent practical experience. At least 3 years of professional software engineering experience focused on cloud infrastructure, platform engineering, site reliability engineering, or data platforms. Strong proficiency in Python, including experience developing, testing, and maintaining production-level applications and automation tools. Hands-on experience with infrastructure as code tools such as Terraform or Pulumi, including developing reusable modules and managing cloud resources. Experience designing and supporting distributed systems in cloud environments, preferably Amazon Web Services (AWS), with knowledge of networking, identity and access management, and security best practices. Experience with CI/CD pipelines, workflow orchestration, and containerization technologies such as GitHub Actions, Jenkins, Argo, Airflow, or Docker; Kubernetes experience is a plus. Familiarity with distributed data processing technologies such as Databricks, Spark, or Kafka, along with experience supporting batch or streaming data workloads. A strong sense of ownership, experience supporting production systems, and the ability to lead complex technical initiatives while communicating effectively across teams.
