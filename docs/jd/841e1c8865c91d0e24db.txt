Job Description The .NET Software Engineer is responsible for the analysis, design, testing, development, deployment, and maintenance of best-in-class software experiences. The Software Engineer - Full Stack builds and supports web applications, ASP .NET, APIs, business-tier components, and database solutions using Microsoft platform technologies and modern web development practices. The successful candidate is a self-motivated collaborator who works effectively within a team and across the organization, takes ownership of software deliverables, and applies U.S. Bank standards to protect reliability, security, and the customer experience. The role requires proficiency with the agile software development lifecycle and DevOps principles. U.S. Bank is looking for a skilled .NET Software Engineer who is comfortable with both front and back-end programming to develop and support existing and new applications. The main scope of work will include back-end and client-side code using appropriate technologies and frameworks. Required skills include problem solving and solution design skills to create high-quality code as part of an agile team. Using Microsoft platform technologies (ASP.NET Web API) and Azure, design, build, test, implement and modify existing business-tier components, Web applications, and database objects Design user interactions and back-end website applications. Design, develop effective APIs and consume existing APIs Create and execute test scenarios in line with test plans. Code and test computer programs of varying complexity and scope, utilizing standard procedures and techniques. Assists technical team to investigate, analyze, and resolve technical problems related to system functions, programming, and procedures. Write documentation of procedures used in the system. Develop detailed flowcharts to show processing logic for programs. Participate in some application architecture functions.
