As a Software Engineer at Applied Materials, you’ll dive deep into ground-breaking technologies—like machine learning and AI—to craft novel software solutions that solve our customers’ high-value problems. Our Software Engineers are responsible for designing, prototyping, developing, and debugging software solutions for semiconductor equipment components and devices to ensure quality and functionality. You'll develop software documentation and test procedures, troubleshoot software problems, and communicate with internal customers to understand project requirements. As part of our team, you'll contribute your expertise in intricate systems, deciphering code, and anticipating software behaviors to ensure Applied remains the leader in the semiconductor and display sectors. Key Responsibilities Design, develop, test, and maintain software for semiconductor manufacturing equipment. Develop machine control applications utilizing object-oriented design principles and modern software architectures. Implement control software for: Motion control systems Robotics and automation Laser processing modules Vision and metrology systems Factory automation interfaces Collaborate with systems, electrical, and mechanical engineers to define equipment requirements and software architecture. Develop software interfaces to PLCs, motion controllers, sensors, and process hardware. Support equipment integration, debugging, and validation activities. Participate in design reviews, code reviews, and software verification testing. Investigate field issues and implement corrective actions. Generate technical documentation and support software release processes. Support customer installations and factory acceptance testing as required. Required Qualifications Education Bachelor's degree in: Computer Engineering Computer Science Electrical Engineering Software Engineering Mechatronics Engineering Related Engineering Discipline Experience 5+ years of software development experience. Experience developing software in C# or C++. Experience with object-oriented design and software architecture. Experience working with source control systems (Git, Azure DevOps, SVN, or equivalent). Experience troubleshooting complex electromechanical systems. Strong debugging and problem-solving skills. Ability to work effectively in a cross-functional engineering environment. Preferred Qualifications One or more of the following: Semiconductor equipment experience. Beckhoff TwinCAT development. EtherCAT industrial networking. PLC programming and automation systems. Motion control platforms such as: Aerotech Beckhoff Delta Tau ACS Siemens Vision systems integration. SECS/GEM factory automation. OPC-UA communications. Real-time control systems. Robotics and precision automation. Laser processing equipment. Advanced packaging or photonics manufacturing experience. Agile software development methodologies.
