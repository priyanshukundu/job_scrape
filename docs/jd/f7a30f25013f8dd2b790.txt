Position Summary We are seeking a motivated Software Engineer to design, develop, test, debug, and maintain software supporting our game development initiatives. This role focuses on development centered around specific tasks. It includes responsibility for implementing features and maintaining code quality. Delivering reliable software according to project requirements and timelines is also part of the role. The Software Engineer is an active contributor to a collaborative development team and takes ownership of assigned software components and features throughout the development lifecycle. Working with Software Architects, Product Managers, game developers, domain experts, and other engineering team members, this individual translates technical specifications and product requirements into effective software solutions. As our development environment evolves to incorporate Unity, this role will contribute to the development and integration of game software using modern development tools, programming languages, and engineering practices. The ideal candidate is a strong problem solver who takes pride in writing clean, maintainable code and delivering high-quality results. Key Responsibilities Software Development: Design, implement, test, debug, and maintain software features and components in accordance with project requirements, technical specifications, and established coding standards. Code Ownership: Take responsibility for assigned code and features throughout development, testing, integration, release, and ongoing maintenance. Ensure implementations are reliable, maintainable, and meet functional requirements. Project Execution: Work with the development team to estimate tasks, plan implementation efforts, communicate progress, and deliver assigned work within established timelines. Technical Collaboration: Work with Software Architects and other developers to understand design requirements, implement software components, and integrate changes with existing systems. Testing and Quality: Develop and maintain unit tests and integration tests to verify functionality, identify defects, and prevent regressions. Resolve issues promptly while minimizing unintended side effects. Debugging and Resolving: Investigate software defects, analyze existing code, identify root causes, and implement appropriate solutions for issues discovered during development, testing, or in the field. Code Reviews: Participate in peer reviews of software designs and code to improve quality, consistency, readability, and maintainability. Documentation: Create and maintain documentation for developed or modified software, including implementation details and relevant testing procedures. Multi-functional Development: Collaborate with game developers, creative team members, domain experts, and other contributors to clarify requirements and ensure software meets product expectations. Development Tools and Technologies: Contribute to the adoption and effective use of development tools, frameworks, and technologies, including Unity and associated programming languages, as appropriate for project needs. Continuous Improvement: Follow established software engineering practices and contribute ideas to improve development processes, testing, automation, and software quality. Three or more years of professional software development experience, with proven experience contributing to team-based software projects. Proficiency in C# and/or C++, with a strong understanding of object-oriented programming and software design principles. Experience developing, testing, debugging, and maintaining production-quality software. Understanding of software engineering methodologies, including code reviews, version control, automated testing, debugging, and code documentation. Experience estimating development tasks and delivering assigned work against project schedules and requirements. Strong analytical, problem-solving, and debugging skills. Excellent written and verbal communication skills, with the ability to work effectively with technical and nontechnical team members. Strong attention to detail and a commitment to producing accurate, reliable, and maintainable code. Ability to work independently on feature development while collaborating effectively with a development team. Willingness to learn new technologies, follow established architectural guidance, and adapt to evolving project requirements. Preferred Qualifications Experience developing software for casino gaming, video games, or other interactive applications. Experience with Unity and C# development. Experience with C++ in game development, native libraries, performance-sensitive systems, or software integration. Familiarity with game engines, real-time applications, graphics, or game development workflows. Experience working within an iterative or Agile software development environment. Experience with automated testing, continuous integration, and collaborative source control workflows.
