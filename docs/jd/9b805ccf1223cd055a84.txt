Software Engineer The Opportunity: As a Front-End Software Engineer for AI Applications, you will design and build intuitive, high‑performance user interfaces that interact with artificial intelligence models and data-driven systems. This role focuses on creating responsive, accessible, and reliable front-end experiences that help users visualize complex data, interact with AI-powered features, and work with real-time insights. The engineer will collaborate closely with AI/ML engineers, product teams, and UX designers to translate advanced technical concepts into user-friendly interfaces. What You’ll Work On: Develop front-end features for AI-driven applications using modern JavaScript frameworks. Build interactive dashboards, visualizations, and interfaces that display model outputs and analytics. Work with back-end and AI engineering teams to integrate APIs, inference services, and model pipelines. Ensure UI performance when handling real-time or high-volume data. Implement responsive, accessible, and user-centered front-end designs. Troubleshoot front-end issues within applications that rely on AI or data services. Participate in code reviews and contribute to front-end best practices and design system consistency. Join us. The world can’t wait. You Have: 8+ years of experience with software development, including front-end application development Experience in HTML, CSS, JavaScript, and TypeScript Experience building production applications with React and modern JavaScript or TypeScript Experience with React state management and data-fetching libraries such as Redux Toolkit Experience with consuming RESTful or GraphQL APIs Knowledge of responsive design principles and accessibility standards Public Trust Bachelor's degree in Computer Science, Software Engineering, or Information Systems Nice If You Have: Experience with Large Language Models (LLMs), AI Agents, Retrieval-Augmented Generation (RAG), or enterprise search platforms Experience with containerized environments using Docker and Kubernetes Experience with CI/CD pipelines and DevSecOps practices Experience supporting federal government programs Knowledge of cloud platforms, including AWS, Azure, or GCP, and AI services Vetting: Applicants selected will be subject to a government investigation and may need to meet eligibility requirements of the U.S. government client; Public Trust determination is required.
