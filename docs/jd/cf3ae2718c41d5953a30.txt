Job Description Data Engineers in this role support the design, implementation, and maintenance of data pipelines and processing jobs to enable secure, scalable, and high-quality technology solutions. They work hands-on with code, data, and modern tools, collaborating with cross-functional teams to translate business requirements into robust technical solutions. Responsibilities include adhering to best practices, security standards, and regulatory requirements, and contributing to the innovation process by applying knowledge of market trends and industry dynamics. All roles require digital fluency, including the ability to work with emerging technologies such as Generative AI tools (e.g. ChatGPT, Microsoft Copilot) to support everyday work. Key Responsibilities Attend meetings with stakeholders to learn about requirements and understand data ecosystem, security, privacy, and retention needs. Interpret technical requirements and execute component designs provided by senior engineers. Create and implement code across assigned components, applying coding patterns, guidelines, and best practices. Participate in code review processes, gather feedback, and apply changes to owned aspects of code or design. Conduct unit testing and support testing code for one component in a common testing environment. Contribute to the development of tools and automation processes for transforming, managing, accessing, deploying, and monitoring data processes. Collaborate with team members to create queries, extract and compile raw data, and apply basic modification techniques to transform data. Review and escalate alerts to maintain a data pipeline, assist with investigations, and implement basic solutions to minimize failures. Follow troubleshooting guidance for reviewing, addressing, and fixing basic problems flagged by testing, and escalate complex issues as needed.
