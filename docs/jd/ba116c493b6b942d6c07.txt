About the Role We are seeking an enthusiastic and motivated Junior Software Engineer to join our API Engineering team. In this role, you will help design, develop, test, document, and support REST APIs that power business applications, partner integrations, and client-facing services. You will work closely with senior engineers, architects, product managers, quality engineers, and platform teams to learn and apply modern software engineering practices while contributing to secure, scalable, and reliable APIs. This position is ideal for an early-career engineer who is eager to grow in backend development, systems integration, and API design, and who enjoys solving technical problems in a collaborative, mentorship-driven environment. Key Responsibilities API Development Assist in designing, developing, and maintaining RESTful APIs and backend services under the guidance of senior engineers. Build and maintain reusable components, libraries, and integration services. Help ensure APIs meet performance, reliability, and security requirements. Learn and apply API versioning and lifecycle management practices. Troubleshoot and help resolve API and integration issues across development and testing environments, escalating complex issues as needed. Documentation & Knowledge Sharing Create and maintain clear API and integration documentation, including API specifications, developer guides, and usage examples. Document technical work, implementation notes, and lessons learned. Contribute to team knowledge repositories and engineering best practices. Integration & Architecture Support the development of integrations between internal systems, external partners, and cloud services. Follow enterprise architecture standards when implementing API solutions. Learn and contribute to microservices and event-driven integration patterns. Assist with API gateway onboarding and basic policy implementation tasks. Quality Engineering Write unit, integration, and automated API tests with guidance from senior team members. Participate in peer code reviews and design reviews to learn team standards. Support CI/CD pipeline usage and basic deployment automation tasks. Help identify reliability, performance, and maintainability issues. Security & Compliance Learn and apply secure authentication and authorization mechanisms such as OAuth 2.0 and JWT. Follow secure coding practices and enterprise security requirements. Support vulnerability remediation activities as directed. Help ensure appropriate logging and monitoring is implemented in the services you build. Collaboration Actively participate in Agile/Scrum ceremonies and engineering planning activities. Collaborate with product, architecture, security, and operations teams. Communicate progress, questions, and technical ideas clearly to teammates and mentors. Seek feedback and apply it to continuously improve technical skills. Required Qualifications Education Bachelor's degree in Computer Science, Software Engineering, Information Technology, or a related field (or equivalent practical experience, including internships, bootcamps, or personal projects). Experience 0-2 years of professional software development experience (internships, co-ops, and academic projects are valued). Some exposure to building or consuming REST APIs, through coursework, internships, or personal projects. Familiarity with at least one backend language/framework such as Java, C#, .NET, or Spring Boot. Basic experience with Git-based source control. Technical Skills Basic understanding of REST API principles and HTTP protocols. Familiarity with JSON and API integration concepts. Basic understanding of relational databases and SQL. Foundational knowledge of software design patterns and object-oriented programming. Willingness to learn API security concepts, including OAuth 2.0 and JWT. Exposure to automated testing frameworks (unit testing) is a plus. Interest in or coursework experience with cloud platforms such as Microsoft Azure. Curiosity about containerization technologies such as Docker and Kubernetes. Eagerness to learn CI/CD pipelines and DevOps practices. Preferred Qualifications Coursework, certifications, or personal projects involving Microsoft Azure. Exposure to messaging or event-driven concepts (e.g., Kafka, RabbitMQ, Azure Service Bus). Experience writing basic technical documentation. Familiarity with monitoring/logging concepts. Internship or academic experience in financial services, fintech, or other regulated industries. What We Value Strong desire to learn and grow as a software engineer. Analytical and problem-solving mindset. Attention to detail and commitment to writing quality code. Strong written and verbal communication skills. Ability to collaborate effectively and accept mentorship in a team environment. Growth mindset and willingness to adopt new technologies. Ownership mindset with the ability to drive assigned tasks to completion with support.
