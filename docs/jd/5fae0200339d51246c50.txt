Try new things, learn new skills and discover what you excel at—all from Day One. Job Description U.S. Bank is seeking a full-time Software Engineer (Multiple openings) in Irving, TX. Essential Responsibilities: Leading end-to-end delivery of enterprise banking applications including feature ownership, sprint execution, delivery, production deployment, and post-production validation. Designing and developing scalable banking domain products using Full Stack technologies including React.js, Node.js, Express.js, GraphQL, MongoDB, and Cassandra. Working extensively on Azure Cloud ecosystem for application hosting, deployment validation, monitoring, and release activities. Managing CI/CD pipelines and release orchestration using Jenkins, GitHub Actions, Azure Pipelines, Azure DevOps, Rancher, Docker, Terraform, and Git-based workflows. Leading monthly enterprise release management activities, including change request (CR) management, CAB meeting participation, production rollout coordination, release validation, and hotfix deployments. Performing production environment validation, cluster health checks, Kubernetes version validation, deployment monitoring, and operational governance using Rancher and containerized cloud infrastructure. Implementing DevOps and Infrastructure-as-Code practices using Docker and Terraform for automated deployments, environment provisioning, operational validation, and cloud governance. Utilizing Kibana and Quantum Metrics for application monitoring, issue analysis, production troubleshooting, and performance insights. Applying security and compliance governance using BlackDuck, Fortify, and AEGIS to resolve security vulnerabilities, licensing risks, and operational concerns. Designing and implementing Agentic AI bots and AI-assisted engineering workflows using ChatGPT, Claude, Gemini, and GitHub Copilot for development acceleration, automated release validation, security remediation, debugging, and productivity optimization. Delivering scalable enterprise automation capabilities to reduce manual remediation efforts, improve security compliance posture, and accelerate vulnerability resolution timelines. Work with the following tools and technologies: React.js, Node.js, Express.js, GraphQL, MongoDB, Cassandra, Azure Cloud ecosystem, Jenkins, GitHub Actions, Azure Pipelines, Azure DevOps, Rancher, Docker, Terraform, Git-based workflows, Kubernetes, Terraform, Kibana, Quantum Metrics, BlackDuck, Fortify, AEGIS, ChatGPT, Claude, Gemini, and GitHub Copilot. Basic Qualifications: This position requires a Bachelor’s degree or equivalent in Computer Science or Computer Engineering and 5 years (progressive, post-baccalaureate) software development experience. Required Skills/Experience: Must also have 24 months of experience with each of the following: 1) Designing and developing scalable products using Full Stack technologies including React.js, Node.js, Express.js, GraphQL, MongoDB, and Cassandra. 2) Working on Cloud ecosystem for application hosting, deployment validation, monitoring, and release activities. 3) Managing CI/CD pipelines and release orchestration using Jenkins, GitHub, Rancher, Docker, Terraform, and Git-based workflows. 4) Performing production environment validation, cluster health checks, Kubernetes version validation, deployment monitoring, and operational governance using Rancher and containerized cloud infrastructure.
