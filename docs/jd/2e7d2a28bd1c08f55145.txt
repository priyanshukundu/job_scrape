Senior Software Engineer - CNCS Platform - 21502 - Bloomberg Senior Software Engineer - CNCS Platform Location New York Business Area Engineering and CTO Ref # 10053296 Description & Requirements ENG Cloud Native Compute Services (CNCS) Platform owns an ecosystem of shared components and services that are used to build managed multi-tenant platforms on Kubernetes. These components are known as Managed Compute and collectively they provide the foundation to build self-service platforms such as the Data Science Platform (AI workloads), Spark, Streaming (Flink), Workflows (Argo) and other platform-as-a-service products. Our infrastructure is built in Go, runs on Kubernetes and empowers such core capabilities like setting up tenant environments, authentication & access control, resource deployment and consistent user experience through a shared set of cloud native infrastructure design patterns. Our services are built entirely on open source (e.g. Kubernetes, Karmada, Docker, Istio, OPA Agent) and we are deeply involved in building Cloud Native solutions that power runtime platforms that are collectively known as the Bloomberg Data Science Platform. While working on the platform, the backbone for many of Bloomberg's up and coming AI products, you will have the opportunity to collaborate with engineers across Cloud Native Compute Systems (CNCS) and AI organizations and also contribute to open source. If you are a software engineer who is passionate about building resilient, highly available infrastructure and the control plane behind it, we'd like to talk to you about an opening on our team. Examples of recent and upcoming projects: Managed Karmada multi-cluster orchestration and federation for CNCS Runtimes based on CNCF Karmada Platform Capabilities API which provides discovery into user's capabilities in Kubernetes Compute Runtime environments Self-service tenancy and namespace management APIs for thousands of users across CNCS Runtimes Platform-to-platform authentication and authorization, and migration of access control to enterprise IAM Platform Resource Metrics API which provides insights into current capacity and usage of Runtime Cloud environments We are developing and scaling the product quickly and have interesting challenges to solve while building infrastructure across Kubernetes APIs, resource management as well as security and observability stack. We'll trust you to: Own our authentication and authorization pipeline end to end, from design through production Implement infrastructure features using Go, Kubernetes controllers and APIs, and other open source technologies Find and fix the root causes of production problems, not only restore service Review code and designs, and raise the technical bar of the team Iterate quickly as we grow the product Collaborate extensively with other engineering teams and the CTO office Foster a technically outstanding, welcoming and collaborative working environment Treat security and automation as first-class features You'll need to have: 4+ years building production software Experience building Kubernetes control-plane software in Go, such as controllers and operators, API extensions (custom resources, admission webhooks, aggregated API servers), multi-cluster or infrastructure control planes (Cluster API, Karmada, Crossplane, schedulers), platform APIs that create and manage Kubernetes resources for users (for example tenancy or deployment APIs), or storage and network drivers (CSI, CNI) Hands-on experience building infrastructure software, not only operating it Experience designing and debugging distributed systems running in production A track record of taking loosely scoped problems to production on your own The ability to explain designs and trade-offs clearly to engineers inside and outside your team A Degree in Computer Science, Engineering, Mathematics, similar field of study or equivalent work experience (keep only if required for the level) We'd love to see: Experience with authentication, authorization and IAM Experience building and operating Software as a Service (SaaS) or Platform as a Service (PaaS) products Experience with multi-cluster Kubernetes (for example Karmada or cluster federation) Contributions to open source projects in the Kubernetes ecosystem Salary Range = 160,000 -
