Senior Software Engineer - CNCS Platform - 21502 - Bloomberg Senior Software Engineer - CNCS Platform Location New York Business Area Engineering and CTO Ref # 10053296 Description & Requirements ENG Cloud Native Compute Services Platform owns an ecosystem of shared components and services that are used to build managed multi-tenant platforms on Kubernetes. These components are known as Managed Compute and collectively they provide the foundation to build self-service platforms such as the Data Science Platform (AI workloads), Spark, Streaming (Flink), Workflows (Argo) and soon Bloomberg's Platform as a Service. Our infrastructure is built in Go, runs on Kubernetes and empowers such core capabilities like setting up tenant environments, authentication & access control, resource deployment and consistent user experience through a shared set of cloud native infrastructure design patterns. Our services are built entirely on open source (e.g. Kubernetes, Karmada, Docker, Istio, OPA Agent) and we are deeply involved in building Cloud Native solutions that power runtime platforms that are collectively known as the Bloomberg Data Science Platform. While working on the platform, the backbone for many of Bloomberg's up and coming AI products, you will have the opportunity to collaborate with engineers across Cloud Native Compute Systems (CNCS) and AI organizations and also contribute to open source. If you are a software engineer who is passionate about building resilient, highly available infrastructure and seamless, usable full stack solutions, we'd like to talk to you about an opening on our team. Examples of recent and upcoming projects: Managed Karmada multi-cluster orchestration and federation for CNCS Runtimes based on CNCF Karmada Unified UI for all of our Cloud Native Compute Services runtimes including BPaaS (Stateless BAS and HTTP containers), SPaaS (Apache Flink), Workflows (Argo), Spark, DSP and more. This UI will allow our 1000s of users to onboard, configure, deploy, operate and debug applications across all CNCS Runtimes Platform Capabilities API which provides discovery into user’s capabilities in Kubernetes Compute Runtime environments BDGT integration and Self Service UI that performs allocation of quota into Kubernetes Runtime Clusters Platform Resource Metrics API which provides insights into current capacity and usage of Runtime Cloud environments We are developing and scaling the product quickly and have interesting challenges to solve while building infrastructure across Kubernetes APIs, resource management as well as security and observability stack.
