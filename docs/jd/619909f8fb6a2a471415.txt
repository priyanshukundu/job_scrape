Job Description: Job Family Definition: Designs, develops, troubleshoots and debugs software programs for software enhancements and new products. Develops software including operating systems, compilers, routers, networks, utilities, databases and Internet-related tools. Determines hardware compatibility and/or influences hardware design. Management Level Definition: Contributions include applying intermediate level of subject matter expertise to solve common technical problems. Acts as an informed team member providing analysis of information and recommendations for appropriate action. Works independently within an established framework and with moderate supervision. Responsibilities: Design, implement, and maintain backend services and APIs, primarily in Python and Go Apply appropriate algorithms, data structures, and techniques to write efficient and maintainable code Own features and fixes throughout their lifecycle, from design and implementation through code review, automated testing, deployment, and operational support Collaborate with product management, QA, DevOps, and device engineering teams Use approved AI development tools for coding, testing, debugging, and code exploration, while retaining responsibility for correctness, security, and maintainability Required qualification/experience: Experience in developing production software in Python and/or Go Strong foundations in data structures, algorithms, complexity analysis, concurrency, and modular software design Experience building backend APIs and asynchronous services, including error handling, timeouts, retries, and failure recovery Knowledge of SQL, data modeling, and relational databases,( familiarity with caching or NoSQL systems a plus) Experience with Git, code reviews, unit and integration testing, CI/CD Education and Experience Required: Bachelor's or Master's degree in Computer Science, Information Systems, or equivalent. Typically 3+ years experience. Knowledge and Skills: Using software systems design tools and languages. Ability to apply analytical and problem solving skills. Designing software systems running on multiple platform types. Software systems testing methodology, including execution of test plans, debugging, and testing scripts and tools. Strong written and verbal communication skills; mastery in English and local language. Ability to effectively communicate design proposals and negotiate options. Good to have experience: Familiarity with cloud services and containerized applications, such as AWS and Docker Problem-solving and communication skills, with the ability to investigate unfamiliar systems and follow work through to completion Cloud and distributed platforms: AWS services such as S3, DynamoDB, RDS/Aurora, SQS, IAM; Kubernetes and Helm; Kafka, Redis, OpenSearch AI-assisted development: GitHub Copilot or comparable coding assistants, including reviewing generated code, verifying behavior through tests, and protecting sensitive information Understanding of microservices architecture, API contracts, sync/async service-to-service communication Accessibility HPE is committed to creating an inclusive and accessible workplace and encourages applications from all qualified individuals, including those with disabilities.
