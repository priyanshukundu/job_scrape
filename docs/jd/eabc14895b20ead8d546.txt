About the Opportunity Leidos is seeking a Principal Software Engineer to provide advanced software engineering and technical leadership for complex mission software systems. You will develop, maintain, integrate, and enhance software while helping establish the technical approaches, development processes, and quality standards used across software-development efforts. At this level, you will serve as a technical lead across multiple software-development teams, coordinate closely with customers and systems engineering, evaluate new technologies and processes, and help ensure developed and modified software meets demanding functional, performance, interface, and operational requirements. Depending on assignment, the technical environment may emphasize Linux and Splunk platforms, cloud and distributed data technologies, full-stack application development, Python/C++ development, or Linux-based mission data-processing systems. Why This Role Matters Complex mission software requires more than strong individual development skills. It requires experienced technical leadership capable of making sound engineering decisions across teams while maintaining quality, performance, integration, and mission alignment. As a Principal Software Engineer, you will apply deep technical expertise while helping guide how software is designed, developed, tested, integrated, and delivered across complex engineering efforts. What You'll Do Advanced Software Design & Development Analyze user requirements to derive software design and performance requirements. Design and code new software and modify existing software to add capabilities. Debug software, correct defects, adapt applications to new hardware, and improve performance. Develop and implement algorithms that meet or exceed system functional and performance standards. Design or implement complex algorithms subject to strict timing, system-resource, or interface constraints. Design, develop, and modify software systems using scientific analysis and mathematical models to evaluate design outcomes and consequences. Integration, Data & Systems Engineering Integrate existing software into new or modified systems and operating environments. Develop data queries for existing or proposed databases and data repositories. Design and implement complex database and data-repository interfaces and queries. Develop software solutions by analyzing system performance standards, system flows, data usage, work processes, and technical problem areas. Confer with systems engineers and hardware engineers to derive software requirements and understand project limitations, capabilities, performance requirements, and interfaces. Contribute to system-design decisions involving hardware/software tradeoffs, software reuse, COTS/GOTS alternatives, and requirements allocation. Coordinate software-system installation and monitor equipment functioning to ensure operational specifications are met. Testing, Quality & Engineering Practices Review and test software components for adherence to design requirements and document test results. Develop and execute test procedures for software components. Resolve software problem reports. Perform quality control on team products and ensure quality control of developed and modified software. Write and review software and system documentation. Recommend and implement improvements to documentation and software-development process standards. Apply software-development and design methodologies appropriate to the development environment. Technical Leadership & Engineering Direction Serve as technical lead for multiple software-development teams. Oversee software-development teams and ensure work is completed within the constraints of the development process being used. Recommend new technologies and processes for complex software projects. Select the software-development process in coordination with the customer and systems engineering. Delegate programming and testing responsibilities to one or more teams and monitor team performance. Provide technical leadership appropriate to the software-development process and project environment. Coordinate engineering activities with customers, users, systems engineers, hardware engineers, and other technical stakeholders.
