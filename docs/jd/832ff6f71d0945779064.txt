About the Role As a Frontend Engineer, you'll own the client-side experience of the platform — the interfaces through which financial services users configure integrations, build and execute transformations, monitor workflows, and review results. Our product's promise is that business users can operate it without writing a ticket. That promise lives or dies in the UI you build. This is a design-collaborative, full-stack-adjacent role. You'll work directly from Figma, own features from Angular component to Python API endpoint, and build data-dense, enterprise-grade interfaces that financial services users trust. The bar for craft is high — our users are experienced, demanding, and will notice if something is ambiguous or slow. Angular is our framework. TypeScript is how we think. Python is how we reach the backend when a feature needs it. maintain confidence through the CI pipeline Optimize for Core Web Vitals and application performance — lazy loading, OnPush change detection, virtual scrolling for large datasets Apply Angular's built-in security patterns and implement RBAC-aware UI rendering for permission-scoped features Build to WCAG 2.1 AA accessibility standards — enterprise customers have compliance requirements Requirements Experience 4+ years professional frontend engineering Has built and shipped features in production SaaS environments Technical Skills Angular — deep proficiency required: components, services, RxJS, reactive forms, lazy loading, standalone components, Angular CDK TypeScript — strong TypeScript skills;
