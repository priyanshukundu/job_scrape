Title and Summary Senior Software Engineer Overview Mastercard’s Network & Digital Payments group creates meaningful digital payment experiences for consumers, merchants, issuers, and partners at global scale. The Global Product Engineering team builds foundational payment solutions that are secure, resilient, scalable, and operationally reliable. This role is for a Senior Software Engineer who will contribute to the design, development, validation, automation, and operability of high-quality software solutions. The ideal candidate brings strong software engineering fundamentals, hands-on Java development experience, and a quality-first mindset, with the ability to build automation frameworks, contribute to application design, improve engineering practices, and support production readiness. Role As a Senior Software Engineer, you will independently execute key elements of software engineering projects and processes by applying strong technical knowledge, engineering best practices, and problem-solving skills. You will contribute to building and maintaining scalable software solutions, with a focus on testability, automation, performance, security, resiliency, and operational excellence. Key Responsibilities • Design, develop, and maintain high-quality software components, automation frameworks, and engineering tools that improve software delivery confidence. • Build and enhance automated solutions for unit, functional, integration, API, UI, regression, and end-to-end validation. • Contribute to software design and architecture discussions with a focus on scalability, testability, reliability, performance, security, and maintainability. • Develop robust test automation using Java, Spring, JUnit, Rest Assured, JBehave, Cucumber, or similar frameworks. • Participate in code reviews and provide actionable feedback to improve code quality, security, maintainability, and adherence to engineering standards. • Collaborate with software engineers, architects, DevOps engineers, product owners, and program teams to understand requirements and deliver business-aligned solutions. • Create and maintain technical artifacts such as design notes, test strategies, automation plans, integration specifications, and operational readiness documentation. • Support CI/CD adoption by integrating automated checks into Jenkins, Bamboo, Git-based workflows, code coverage tools, and static analysis platforms. • Identify gaps across unit, functional, integration, regression, performance, and exploratory validation, and work with engineering teams to address them. • Contribute to performance engineering by identifying bottlenecks, validating system behavior under load, and supporting tuning efforts. • Apply secure coding practices and support vulnerability identification using tools such as Sonar, Checkmarx, Fortify, or similar platforms. • Support production readiness through logging, monitoring, troubleshooting, incident analysis, root cause analysis, and problem resolution. • Participate in defect triage, release readiness reviews, environment validation, and risk assessment across delivery cycles. • Evaluate emerging tools, frameworks, and engineering practices; support Proof of Concept efforts and continuous improvement initiatives. • Contribute to solution and technology roadmaps by providing inputs on automation, quality engineering, observability, performance, and operability improvements. • Work in an Agile environment, actively participating in sprint planning, daily stand-ups, demos, retrospectives, and release planning. All About You The ideal candidate will have hands-on software engineering experience with strong technical depth across development, automation, testing, and delivery practices. Required Skills and Experience • 6–9 years of software engineering experience with strong hands-on Java development skills. • Strong understanding of software development lifecycle, software design principles, data structures, and object-oriented programming. • Experience designing and developing automation frameworks, reusable test utilities, test harnesses, and engineering productivity tools. • Hands-on experience with Java, Spring, JUnit, Rest Assured, JBehave, Cucumber, or similar frameworks. • Strong experience validating APIs, microservices, web services, web applications, databases, and integration flows. • Good understanding of unit testing, functional testing, integration testing, regression testing, exploratory testing, and acceptance testing. • Experience integrating automated checks into CI/CD pipelines using Jenkins, Bamboo, Git, Maven, or similar tools. • Familiarity with code quality, code coverage, and vulnerability scanning tools such as Sonar, Clover, Checkmarx, Fortify, or similar platforms. • Good understanding of secure coding practices, code review practices, and engineering quality standards. • Working knowledge of performance engineering concepts, including load testing, bottleneck identification, and system behavior analysis. • Experience with Linux/Unix environments, shell commands, logs, troubleshooting, and environment validation. • Strong understanding of REST/SOAP APIs, databases, service integrations, and distributed application behavior. • Ability to troubleshoot complex technical issues across application, integration, environment, and data layers. • Strong communication, collaboration, and documentation skills. • Ability to work independently, manage ambiguity, and deliver under pressure in a fast-paced Agile environment. • Passion for engineering excellence, continuous improvement, automation, and building reliable software at scale. Preferred Skills • Experience with cloud-native applications, containers, Kubernetes, or platform engineering concepts. • Experience with observability tools such as Splunk, Dynatrace, Grafana, Prometheus, or similar platforms. • Experience supporting production systems through incident management, root cause analysis, and operational readiness reviews. • Exposure to payment systems, digital payments, authentication, security, or financial technology platforms. • Experience contributing to engineering standards, reusable frameworks, shared libraries, or developer productivity platforms.
