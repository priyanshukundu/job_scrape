The Opportunity SmartCash is Ally Financial's dealer money movement and wholesale settlement platform, responsible for processing approximately $500 million per day in ACH transactions across Ally's national auto dealer network. The platform serves a critical operational function and operates under strict daily processing windows with no tolerance for failure. The platform is currently undergoing a full migration to AWS. Architecture design and proof of concept work has been completed across all major workstreams, and the team is moving into execution. The Senior Software Engineer joining this team will contribute to a well-defined migration program while maintaining a production platform that runs seven days a week. The role carries technical depth across cloud infrastructure, Java application development, database migration, and batch processing — supported by modern tooling including enterprise access to generative AI development tools. The Work Itself Cloud Migration: Migrate SmartCash's application and data tiers to AWS. This includes re-platforming Spring Batch jobs from OpenShift to AWS Batch on ECS Fargate, migrating WebLogic and JBoss online applications to ECS Fargate containers, moving the Oracle 19c database to Aurora PostgreSQL, archiving to S3 Glacier, and deploying the React SPA to S3 with CloudFront distribution. Infrastructure is managed via Terraform through the Ally PCE GitLab pipeline. Database Migration: Convert Oracle PL/SQL packages, procedures, and sequences to PostgreSQL compatible equivalents. This work requires applied knowledge of both Oracle and Aurora PostgreSQL behavior under financial transaction load. Batch Processing: Maintain and extend the Spring Batch processing chain that runs nightly Monday through Friday, generating ACH files, GL extracts, retail and wholesale feeds, and CBA reports. Own incident response within this chain and eventually re-platform these jobs to AWS Batch without interrupting production operations. Feature Development: Contribute to high impact, innovative capabilities that advance the platform alongside migration work. SmartCash is an active product — new features ship regularly and engineers are expected to contribute meaningfully to both the modernization effort and the ongoing business roadmap.
