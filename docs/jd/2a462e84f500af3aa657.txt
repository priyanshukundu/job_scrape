About this role We are seeking a Senior Software Engineer to design, build, and maintain mission-critical software solutions for our Building Automation Systems (BAS), with a dedicated focus on building automation controllers. You will drive full-stack development across the software lifecycle using core Java to build scalable, high-performance solutions. The ideal engineer pairs strong problem-solving skills with clean code principles to innovate new products while sustaining existing systems. This is a hybrid position that requires three days in the office and two days remote per week. Key Responsibilities Developing software solutions using Agile methodologies and approaches Participate in project planning by investigating solutions to problems and giving the best estimates. Apply new technologies that help move the company’s product offerings forward. Use test-driven development (TDD) methodologies to write unit and functional tests, ensuring quality and reliability. Debug and resolve software / hardware / firmware interaction issues using diagnostic tools and methodologies. Ability to evaluate problems, identify solutions, and translate findings into clear implementation of tasks and plans. Assist in sustaining efforts by providing product knowledge and consultation. Minimum Qualifications Bachelor’s degree in Computer Science or Software Engineering. 5 + years of software engineering. Preferred Qualifications Master’s degree in Computer Science or Software Engineering. Strong software engineering experience. Strong Java and object-oriented programming skills. JavaScript, HTML5, CSS3, jQuery, Angular, Ajax, JSP, Java servlets, React and other web-based technologies. Experience working in an Agile/Scrum development process. Experience with software lifecycle management including version control, build processes, release management. Experience using AI-assisted development tools to accelerate coding, testing, and documentation while critically reviewing and validating generated solutions. Test-Driven Development (TDD). Unit and Functional testing. Analytical & logical reasoning. Problem-solving skills and attention to detail. Ability to multi-task and stay organized in a dynamic environment.
