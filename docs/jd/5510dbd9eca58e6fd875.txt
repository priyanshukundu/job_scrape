Senior Software Engineer, AI Engineering (Citizen AI) - CHICAGO About the Role JLL's Citizen AI team builds the AI products that JLL employees use every day, such as JLL GPT. You will join the team in Boston as a hands-on engineer. You will write production code every day, use AI tools as your main way of working, and ship features that reach many users. What You'll Do - Build and ship features for Citizen AI products, from design to production and monitoring. - Build on the JLL AI platform: LLM gateway, shared RAG services and MCP tools. - Use AI coding tools (Claude Code, Cursor or similar) for design, code, tests and review. - Work with product and design partners to turn requests into working software. - Fix defects quickly. Improve tests, observability and developer tools. - Follow the AI ecosystem and bring useful ideas back to the team. Must Have - Production software experience in Python or TypeScript/Node. - Experience building features with LLMs (prompts, RAG or agent workflows). - Experience with REST APIs, cloud services and CI/CD. - Daily use of AI coding tools as a core part of your workflow. - Clear written English. You work well across time zones. Nice to Have - Experience with the Claude Agent SDK, MCP or LLM observability. - React experience. Why This Role - A global company with serious AI investment, and products used at enterprise scale. - A small team where your code matters, with a clear path to grow. - This seat gives the team a second engineer in a US time zone. This position does not provide visa sponsorship. Candidates must be authorized to work in the United States without sponsorship.
