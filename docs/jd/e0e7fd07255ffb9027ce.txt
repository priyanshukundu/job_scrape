What You’ll Do 

 - Lambda, Inc seeks a Senior Software Engineer in San Francisco, CA to be responsible for developing and scaling our cloud offering. This will include developing and scaling the Lambda website, cloud application programming interfaces and systems, and internal software tooling for system deployment, management, and maintenance. 

 - Gather technical requirements and then develop high-quality software solutions with high feature velocity in collaboration with cross-functional teams (Design, Product, Engineering, Marketing). 

 - Work with backend engineers to design application programming interfaces, shape data contracts, and improve performance of application programming interfaces for frontend use cases. 

 - Perform code reviews and contribute to frontend architecture decisions. 

 - Code review is a crucial step in the software development process where developers systematically examine code to identify software defects and improve code quality. 

 - Develop responsive, feature-rich React software applications that enable customers to manage their AI computing resources. 

 - Modify existing software applications to optimize performance for speed, efficiency and usability. 

 - Translate software designs into delightful, interactive user interfaces (UIs). UIs are the visual elements and interactive features of software that enable users to interact with systems. 

 - Develop and maintain complex React-based SPA architectures using modern software features and patterns (e.g., Context Hooks). SPAs (Single-Page Applications) provide seamless navigation of software applications and create dynamic interfaces with real-time updates. 

 - Work across the full frontend software stack including state management, routing, server-driven UI, and API orchestration. 

 - Enhance our internal design system (e.g., component library, tokens, and accessibility standards). 

 - Drive front-end performance engineering which includes bundle optimization, lazy loading, code splitting, memory profiling, and Chrome DevTools performance investigations. 

 - Create robust communication architectures to interface with internal and third-party services/APIs. 

 - Build software integrations with marketing tools for user analytics and tracking. Telecommuting allowed for this position.
