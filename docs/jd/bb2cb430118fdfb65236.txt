Job Description Job Description You'll join the Platforms Engineering team that builds the shared AI capabilities behind Rockwell's software portfolio, including FactoryTalk Design Studio, FTOptix, and Studio 5000 Logix Designer. You'll build the services, SDKs, and tool interfaces that let product teams ship assistants, content generation, and diagnostics into software that customers run in production. You'll do it in an AI-first engineering environment: coding agents running inside a harness we own, evals gating AI-generated changes, GitHub Copilot Enterprise and Claude in the daily loop, and MCP-based tooling that lets agents reach real build, test, and telemetry systems under human-in-the-loop review. Key Responsibilities: Design and build platform services, SDKs, and APIs that product teams use to embed AI capabilities in FactoryTalk Design Studio, FTOptix, and Logix Designer. Build and maintain MCP servers and tool interfaces that give agents governed access to product, build, and test systems. Develop evaluation suites and regression gates that measure AI feature quality, safety, latency, and cost before release. Own subsystem design through implementation, test, and production operation, including observability and performance budgets. Work with product teams, architects, and security to apply OT/ICS constraints such as IP protection, binary signing, and data boundaries to every AI feature. Prototype and evaluate new models and agent patterns, and turn the ones that work into supported platform capabilities. Improve the team's own AI-assisted development loop and share what works across engineering teams.
