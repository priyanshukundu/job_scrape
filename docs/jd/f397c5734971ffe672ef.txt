Job Description This position will be responsible for the analysis, design, testing, development and maintenance of best in class software experiences. The candidate is a self-motivated individual who can collaborate with a team and across the organization. The candidate takes responsibility of the software artifacts produced adhering to U.S. Bank standards in order to ensure minimal impact to the customer experience. The candidate will be adept with the agile software development lifecycle and DevOps principles. Core Responsibilitie s -Web Development: Build and scale web applications using C# and the Model-View-Controller (MVC) architectural pattern. -- Modernization & Maintenance: Maintain legacy enterprise web applications in ASP.NET4.8 while actively developing new features and microservices in .NET 9 . - Database & Data Integration: Design, optimize, and maintain complex databases in SQL Server . Develop, deploy, and troubleshoot SSIS (SQL Server Integration Services) packages for ETL processing. - Tooling & Best Practices: Utilize Visual Studio 2022 to write clean, secure, and maintainable Object-Oriented code adhering to SOLID principles. - Collaboration: Partner with our software architecture team to translate system designs into functional code, participating in code reviews and mentoring junior developers. Basic Qualifications - Bachelor's degree, or equivalent work experience - Three to five years of relevant experience Preferred Skills/Experience Technical Requirements -Languages & Frameworks: Strong proficiency in C#, ASP.NET MVC, and ASP.NET 4.8. -Modern .NET Ecosystem: Professional hands-on experience or deep technical familiarity with .NET 9and modern ASP.NET Core web patterns. -Database & ETL Tools: Advanced knowledge of SQL Server (stored procedures, indexing, query optimization) and hands-on experience building/maintaining SSIS packages. -IDE & Tools: Fluent in Visual Studio 2022 and version control systems (GitLab). -Architecture: Strong understanding of standard design patterns, web security best practices, and dependency injection -Experience with Azure Cloud, Jenkins, JFrog/Artifactory a plus Location expectations This role requires working from a U.S. Bank location three (3) or more days per week.
