About the Role The Mastercard Authentication Program owns how consumer authentication works for both in-store and e-commerce transactional use cases. The primary purpose of this role is to develop and deliver best-of-breed authentication products for e-commerce transactional use cases that will drive uptake and penetration for the products and revenue for Mastercard. The authentication products that fall within this role’s responsibilities are ID Check, Token Authentication Service and Token Authentication Framework. If you want a challenging project that is changing the way people make payments, this is the role for you!
