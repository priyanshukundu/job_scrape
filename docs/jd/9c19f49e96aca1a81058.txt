Job Description Seeking a Senior Database Engineer to architect, optimize, and modernize enterprise SQL Server platforms supporting high-volume transactional systems. This role focuses on database performance engineering, automation, cloud integration, and scalable data architecture rather than traditional DBA administration. Key Responsibilities Design and develop SQL Server databases, stored procedures, functions, views, and ETL solutions . Optimize database performance through query tuning, indexing, execution plan analysis, and workload optimization . Troubleshoot and resolve locking, blocking, deadlocks, concurrency, and performance bottlenecks . Design scalable data models and database architectures for large-scale OLTP environments. Collaborate with application teams on database design, data access patterns, and performance best practices . Implement modern SQL Server capabilities including Query Store, Columnstore Indexes, CDC, Temporal Tables, and In-Memory OLTP . Drive database automation, CI/CD deployments, and modernization initiatives using DevOps tools. Lead production issue resolution, root cause analysis, and establish database engineering standards. Basic Qualifications - Bachelor’s degree, or equivalent work experience - Five to six years of relevant experience Required Skills Strong financial-services background, preferably ETF, mutual funds, fund accounting, custody, or asset servicing, or larger organization Advanced SQL Server / Azure SQL and database design Azure Data Factory (ADF) Data warehouse architecture and dimensional/data modeling High-volume data processing and performance tuning ETL/data pipeline modernization Data reconciliation, lineage, auditability, and historical data management Azure cloud data architecture Experience modernizing legacy data/SSIS workloads Ability to translate financial business rules into data models and pipelines Role focus: Own the modern data architecture, data pipelines, database performance, reconciliation, and migration of legacy processing into the Azure data platform.
