AECOM is currently seeking a Networks Specialist IV to support the Chicago Department of Water’s multi-billion Capital Improvement Program (CIP). This is a key position will assist with the day-to-day administration, monitoring, and maintenance of enterprise network infrastructure. is intended to develop into a broader Network Engineer/Administrator position as the individual's technical skills and experience grow. Network Operations & Administration Configure, troubleshoot, and maintain switches, routers, firewalls, wireless access points, and other network devices. Monitor network performance, availability, capacity, and connectivity using network management and monitoring tools. Troubleshoot LAN/WAN connectivity issues and resolve network-related incidents in a timely manner. Assist with VLAN, subnet, IP address, DHCP, DNS, and routing configuration and troubleshooting. Perform network device configuration changes, firmware upgrades, and routine maintenance under established procedures. Assist with network installations, expansions, equipment replacements, and infrastructure upgrades. Maintain accurate network diagrams, device inventories, IP address documentation, configuration records, and other technical documentation. Support network connectivity for servers, workstations, security systems, cameras, access-control systems, and other enterprise technologies. Assist with network cabling, patching, port configuration, and troubleshooting of physical connectivity issues. Security Assist with the implementation and maintenance of network security controls and best practices. Monitor network security alerts and assist with investigation and remediation of network related security events. Assist with firewall rule reviews, VPN configuration, access controls, and network segmentation. Support implementation of security improvements such as network segmentation, MFA, secure remote access, and device hardening. Ensure network devices are maintained in accordance with applicable security and configuration standards. Assist with vulnerability remediation, patching, and security-related network upgrades. Infrastructure & Support Provide Tier 1/Tier 2 technical support for network-related incidents and service requests. Collaborate with systems, cybersecurity, GIS, EAM, application, desktop support, and infrastructure teams to resolve issues involving interconnected systems. Participate in troubleshooting outages and performance issues across servers, applications, network devices, and end-user systems. Assist with network-related support for data centers, remote facilities, and field locations. Participate in scheduled maintenance, after-hours upgrades, and emergency troubleshooting when required. Work with vendors and contractors on network equipment installation, troubleshooting, and maintenance. Field & Facility Network Support Support network connectivity across multiple operational and administrative facilities. Assist with troubleshooting network connectivity for cameras, access-control systems, building systems, and other connected devices. Coordinate with field personnel and vendors to troubleshoot physical and network connectivity issues. Data Center / Infrastructure Assist with network infrastructure supporting servers, virtualization platforms, storage systems, and enterprise applications. Support network changes associated with server deployments, migrations, upgrades, and decommissioning. Assist with data center network documentation, equipment inventory, port mapping, and cable management. Monitoring & Incident Response Monitor network infrastructure and respond to network alerts and outages. Investigate recurring connectivity and performance issues and document root causes and corrective actions. Escalate major or security-related incidents according to established procedures. Participate in incident reviews and recommend improvements to reduce recurring network issues. Change Management Prepare and execute network changes following established change-management procedures. Perform pre-change validation, implementation, testing, and post-change verification. Maintain accurate records of network configuration changes. Projects & Continuous Improvement Participate in network infrastructure upgrade and modernization projects. Assist with network assessments, capacity planning, technology evaluations, and infrastructure improvement initiatives. Help identify opportunities to improve network reliability, performance, security, and resiliency. Support implementation and testing of network changes in development, staging, and production environments. Assist with disaster recovery, business continuity, and network resiliency activities. Develop and maintain standard operating procedures, troubleshooting guides, and knowledge-base documentation. Participate in network testing, change management, and post-implementation validation. Minimum Requirements: BA/BS + 6 years of related experience or demonstrated equivalency of experience and/or education Preferred Qualifications: Educational & Technical capabilities: Bachelor's degree in information technology, Computer Science, and / or Network Engineering. 6 + years of experience supporting enterprise network infrastructure, or equivalent academic/laboratory experience. Experience troubleshooting network connectivity issues in an enterprise or multi-site environment. Basic understanding of TCP/IP networking and common network protocols. Technically adept with TCP/IP, UDP, ICMP 0 DNS and DHCP o IPv4 and basic IPv6 VLANs and subnetting. Proven capability with routing and switching concepts, network ports and protocols & LAN/WAN technologies. Wireless networking skill sets reflecting: Familiarity with network monitoring and management tools. Basic understanding of firewalls, VPNs, network security, and access controls. Ability to troubleshoot network connectivity using tools such as ping, traceroute/tracert, nslookup, ipconfig/ifconfig, and packet/network monitoring tools. Familiarity with network cabling, patch panels, switches, and physical network infrastructure. Professional Skills including: Strong analytical and troubleshooting skills. Ability to diagnose problems systematically and identify root causes. Good written and verbal communication skills. Ability to document technical issues, configurations, procedures, and resolutions. Ability to work independently while knowing when to escalate complex issues. Strong customer-service orientation and ability to work effectively with technical and nontechnical users. Ability to manage multiple priorities in a fast-paced environment. Willingness to learn new technologies and take on increasing technical responsibilities.
