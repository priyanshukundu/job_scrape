Role Summary We are looking for an AI Quality Engineer to modernize and accelerate software quality engineering through AI-assisted testing and intelligent automation. The ideal candidate will bring strong hands-on QA automation experience and demonstrated expertise in Playwright, GitHub Copilot, and Tricentis Tosca, including Tosca AI capabilities. The engineer will use AI-assisted development and automation techniques to improve test generation, automation development, execution, maintenance, defect analysis, and overall QA productivity. This role will also support the development and adoption of reusable AI-powered QA agents and automation frameworks across multiple application teams. Key Responsibilities AI-Assisted Quality Engineering Use GitHub Copilot to accelerate the development of automated test cases, utilities, test data solutions, API tests, and QA frameworks. Apply Generative AI to requirements analysis, test scenario identification, test case generation, automation generation, and defect analysis. Develop reusable prompts, instructions, skills, and engineering patterns that improve the consistency and accuracy of AI-generated QA assets. Evaluate AI-generated tests for accuracy, stability, coverage, maintainability, and security rather than accepting generated output without engineering validation. Contribute to the development and enhancement of AI QA agents for requirements analysis, test design, automation generation, traceability, and defect triage. Playwright Automation Engineering Design, develop, and maintain scalable automated test frameworks using Playwright. Hands-on Playwright experience is mandatory for this role. Build and maintain Playwright tests for modern web applications using JavaScript or TypeScript. Develop reusable fixtures, page objects, utilities, reporting, test data, and environment configuration to support enterprise-scale automation. Implement reliable cross-browser, API, integration, regression, and end-to-end testing with Playwright. Integrate Playwright automation into GitHub Actions, Azure DevOps, Jenkins, or equivalent CI/CD and Continuous Testing pipelines. Analyze failed automation and determine whether failures are caused by application defects, test data, environment, or automation issues. Tricentis Tosca & Tosca AI Design, develop, and maintain automated tests using Tricentis Tosca. Apply Tosca AI-assisted capabilities to increase automation productivity and improve test maintenance. Build reusable Tosca components and automation assets that can be shared across applications. Support GUI, API, integration, regression, and end-to-end testing. Integrate Tosca automation into CI/CD and Continuous Testing pipelines. QA Transformation & Adoption Partner with application QA and development teams to identify opportunities for AI-assisted testing and automation. Help application teams adopt Playwright, GitHub Copilot, Tosca, and AI QA capabilities. Build reusable examples, templates, prompts, standards, and best practices. Conduct demonstrations, knowledge-sharing sessions, and technical enablement for QA engineers. Measure improvements in automation coverage, development effort, execution time, maintenance effort, and defect detection. Required Skills and Qualifications 5+ years of experience in Quality Engineering or QA Automation. Mandatory: Strong hands-on experience designing, developing, and maintaining automated tests and frameworks using Playwright. Strong JavaScript or TypeScript experience for Playwright automation development. Strong hands-on experience with GitHub Copilot. Strong experience with Tricentis Tosca. Experience applying Generative AI or large language models (LLMs) to software testing or engineering workflows. Strong understanding of test automation architecture, functional and regression testing, API testing, UI/web automation, test data management, CI/CD, Continuous Testing, defect analysis, and debugging. Programming or scripting experience with Java, JavaScript/TypeScript, Python, or C#. Experience with Git/GitHub and modern development workflows. Preferred Skills Tosca API and enterprise application automation. GitHub Actions, Jenkins, or Azure DevOps. Jira and Xray. AI agent development or agentic workflows. Prompt engineering and reusable AI instruction or skill development. Retrieval-Augmented Generation (RAG) and enterprise knowledge-base integration. Requirements-to-test traceability. AI-generated automation validation and governance. Performance or data testing experience.
