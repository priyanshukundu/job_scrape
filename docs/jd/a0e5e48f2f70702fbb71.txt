Your Impact Build the frontend platforms and frameworks that help engineering teams across Lowe’s build better products, faster. You’ll take meaningful features from idea to delivery, solve real engineering problems, and help make the development experience better for teams across Lowe’s. What You Will Do Build and enhance frontend frameworks, developer platforms, and tooling used by engineering teams across Lowe’s. Develop React-based components and capabilities using modern JavaScript and frontend engineering practices. Contribute to framework capabilities, micro-frontend architecture, developer tooling, performance improvements, and platform modernization. Own medium-sized features and enhancements end-to-end, from understanding requirements through implementation, testing, and delivery. Troubleshoot production and framework issues, identify root causes, and implement reliable solutions. Write clean, maintainable code and automated tests while participating in code reviews and established engineering practices. Work with CI/CD, observability, and other enterprise development tools and practices as part of the software delivery lifecycle. Collaborate with engineers and cross-functional partners to understand problems, evaluate solutions, and deliver improvements. Research and learn new technologies and approaches while contributing to a modern frontend engineering environment.
