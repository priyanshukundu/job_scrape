Your role at Baxter The Principal Software Developer (Mobile) is a hands‑on technical leader responsible for the design, development, and evolution of mobile applications supporting both iOS and Android platforms using React Native with a background insecure voice calling. What you will be doing: Lead the architecture, development, and enhancement of Mercury mobile applications using React Native for iOS and Android. Design and implement secure voice calling capabilities across iOS and Android. Integrate Mercury mobile applications with real-time communications services . Address mobile voice concerns including call signaling , session lifecycle, audio routing, connectivity changes, permissions, notifications, background behavior, and call reliability. Ensure functional parity and a consistent user experience across both mobile platforms. Collaborate with backend, web, UX, QA, cybersecurity, regulatory, and product stakeholders. Design and implement integrations using REST APIs, WebSockets, SignalR, and real-time voice communication technologies. Apply HIPAA-aligned security practices for data handling, authentication, voice communications, messaging, and notifications. Participate in Agile development ceremonies and work tracking using JIRA and Confluence. Contribute to design controls, requirements traceability, verification, and validation documentation using JAMA. Perform rigorous code reviews and champion mobile engineering best practices. Mentor engineers and raise the overall quality and consistency of mobile development. Support production readiness, monitoring, troubleshooting, and issue resolution in live healthcare environments. What you will bring: Bachelor’s degree in Computer Science, Software Engineering, or a related discipline and 5+ years of professional software engineering experience, including significant mobile application development experience. Proven expertise with React Native and modern JavaScript/TypeScript development. Strong experience developing for both iOS and Android platforms. Strong experience integrating mobile applications with backend systems using REST APIs and real-time communication technologies . Experience designing or supporting mobile voice calling, VoIP, WebRTC, or comparable real-time communications functionality . Experience with mobile audio behavior, call state management, operating-system permissions, push notifications, and background execution . Experience working in regulated environments, preferably healthcare or life sciences. Proficiency with GitHub, PostgreSQL at the application consumption or interaction layer, and collaborative development workflows. Preferred Hands-on experience integrating mobile applications with real-time communications platforms. Experience with WebRTC, SIP, VoIP, media sessions, call signaling, or voice gateway integrations. Experience building secure communication, clinical communication, messaging, or alerting applications. Familiarity with iOS and Android native audio, telephony, push notification, and background-processing APIs . Experience troubleshooting real-time voice quality, connectivity, latency, reconnection, and device compatibility issues. Familiarity with mobile deployment pipelines, release management, and mobile application lifecycle management. Understanding of healthcare workflows, clinical environments, nurse call, patient-care communications, or medical-device integrations. Experience collaborating with UX design using Figma.
