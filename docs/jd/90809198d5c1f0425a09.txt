We are looking for a senior engineer to improve GPU system software and the way that software is built. You will work on firmware, a real-time operating system, driver interfaces, and the build, test, and execution infrastructure that supports them. What you'll be doing: Improve the product and the process used to build, test, and run it. Design and implement firmware and real-time operating system changes, and the driver interface that connects them with the rest of the system. Use current development tools, including tools that generate and check code, and make those tools part of how the team develops and validates software. Work with hardware and software partners in other locations to resolve issues and deliver the result. What we need to see: Proven experience in system software, embedded software, or a related field Bachelor's degree in Computer Science, Computer Engineering, or a related field (or equivalent experience). 5+ years of meaningful experience.
