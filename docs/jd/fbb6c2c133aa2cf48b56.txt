Job Description: Senior Engineering Manager, Security Management Software HPE Networking, powered by the Aruba Networks, Juniper Networks, and Axis Security portfolios, delivers secure, AI-driven networking solutions that connect users, devices, applications, and data across campus, branch, data center, WAN, and cloud environments. HPE Networking enables organizations to modernize infrastructure through on-premises, hybrid, and cloud-native management, automation, AIOps-driven operations, and high-performance wired, wireless, routing, switching, and security solutions. Our technologies support seamless hybrid work experiences while providing scalability, resiliency, and operational simplicity. Within HPE Networking, the SASE and Security Group develops solutions that provide a unified, cloud-delivered architecture combining networking and security capabilities for the modern edge-to-cloud enterprise. The portfolio includes: SD-WAN Secure Service Edge (SSE) Zero Trust Network Access (ZTNA) Next-Generation Firewall (NGFW) Cloud Access Security Broker (CASB) Secure Routing Unified Endpoint Client AI-Native Network Operations Together, these solutions help enterprises reduce complexity, improve operational efficiency, strengthen cyber resilience, and accelerate digital transformation.
