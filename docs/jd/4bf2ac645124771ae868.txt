We are hiring a Product Engineer  for our Mobile Team. In this role, you will build the mobile experiences that bring agentic AI to users wherever they work, spanning the full product lifecycle from conception through deployment.




AS AN ENGINEER AT SNOWFLAKE, YOU WILL:

 - Build and ship polished, production-quality mobile features for Snowflake's agentic AI products, taking ideas from design concepts through App Store / Play Store releases.

 - Write clean, performant, and maintainable TypeScript and React Native code while adhering to engineering best practices.

 - Actively participate in mobile and frontend architecture discussions, design reviews, and peer code reviews to ensure code quality and system scalability.

 - Collaborate closely with product managers and UX/UI designers to convert user requirements into detailed technical tasks and robust mobile UI components.

 - Partner with backend and cross-functional teams to integrate APIs and support backend services that power AI inference and data retrieval.

 - Contribute to the web frontend where needed — this team works across mobile, web, and the broader agentic ecosystem.

 - Use AI coding assistants (such as Claude Code, Cursor, Codex, or similar tools) as an integral component of your day-to-day software development workflow.


OUR IDEAL ENGINEER WILL HAVE:

 - 2+ years of professional experience designing and building production mobile applications with React Native.

 - Strong product mindset — you care deeply about user experience and can be trusted to own features end-to-end, from ambiguous problem to shipped outcome.

 - Strong hands-on proficiency in JavaScript/TypeScript and the modern React ecosystem.

 - Solid understanding of core computer science fundamentals, including algorithms, data structures, UI design patterns, and state management.

 - Proven ability to turn design mocks and product specs into production-quality code.

 - Experience with mobile app fundamentals: navigation, gesture handling, offline behavior, push notifications, and app store release processes.

 - Strong verbal and written communication skills for cross-functional collaboration across engineering, product, and design.

 - BS/MS/PhD in Computer Science, Engineering, or a related field (or equivalent practical experience).
