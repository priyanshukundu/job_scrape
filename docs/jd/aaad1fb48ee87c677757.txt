JPMorgan Chase
Location: Wilmington, DE, United States
Link: https://jpmc.fa.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001/job/210772012

As a Lead Data Engineer at JPMorgan Chase, you are an integral part of an agile team that works to enhance, build, and deliver data collection, storage, access, and analytics solutions in a secure, stable, and scalable way. As a core technical contributor, you are responsible for maintaining critical data pipelines, data models, and application infrastructure across multiple programs in support of the firm's business objectives. Responsibilities include building and maintaining Python-based ETL pipelines and data transformations sourcing from cloud data platforms, owning the deployment and release pipeline for cloud-hosted web applications including CI/CD onboarding and repository management, designing and maintaining SQL views and data models powering executive-facing dashboards and LOB reporting, building lightweight HTML/JavaScript front-ends served through Python web frameworks, serving as Application Owner responsible for compliance posture and platform health, and driving the migration of existing reporting workflows off legacy tools toward scripted, version-controlled equivalents. Qualifications: hands-on Python data engineering experience at scale, experience deploying applications on Cloud Foundry or equivalent PaaS platforms, proficiency in SQL and cloud data warehouse platforms, experience with enterprise CI/CD tooling and application governance, and comfort building front-end interfaces through Python web frameworks. Strong communicator comfortable working with senior stakeholders to translate business requirements into scalable data products.
