Title and Summary Senior Software Engineer - Java Overview: Mastercard’s Enterprise Credit Risk (ECR) team is seeking a talented Senior Software Engineer – Java Full Stack to design, build, and modernize applications that power credit decisioning, portfolio risk management, lender workflows, customer experiences, and analytics across Mastercard’s lending and risk ecosystem. This role is ideal for an experienced software engineer who enjoys solving complex business problems through technology and working across the full application stack. The successful candidate will partner closely with Product, Engineering, Risk, Architecture, and Data teams to deliver secure, scalable, and high-performing applications that improve operational efficiency, simplify lending decisions, and create exceptional user experiences. The ideal candidate brings strong hands-on Java backend expertise combined with modern frontend development experience, a passion for engineering excellence, and the ability to contribute to technical design and delivery across the application lifecycle. This is a hybrid role based in O’Fallon, MO, requiring three days per week onsite. Role: • Design, develop, test, deploy, and maintain scalable full-stack applications supporting Enterprise Credit Risk products and services. • Build secure, resilient, and highly available backend services using Java, Spring Boot, and Spring Framework. • Develop modern, responsive user interfaces using React, Angular, TypeScript, JavaScript, or similar technologies. • Design and implement RESTful APIs, microservices, and event-driven integrations to enable scalable application architectures. • Collaborate with Product Managers, Business Analysts, Risk SMEs, Architects, and Data teams to translate business needs into effective technical solutions. • Participate in architecture and technical design discussions, evaluating technologies and recommending solutions that improve application capabilities and maintainability. • Develop reusable services, components, and frameworks that promote engineering consistency, scalability, and developer productivity. • Apply strong software engineering practices, including object-oriented design, design patterns, automated testing, code reviews, and secure coding standards. • Diagnose and resolve complex application and production issues, performing root cause analysis and implementing sustainable solutions. • Continuously improve application performance, scalability, reliability, observability, and security. • Contribute to cloud-native development, containerization, and CI/CD and DevSecOps practices that enable reliable and efficient software delivery. • Mentor junior and mid-level engineers, share technical knowledge, and contribute to a culture of engineering excellence. • Participate in Agile planning, estimation, prioritization, and delivery activities while taking ownership of assigned technical outcomes. All About You: • Extensive experience as a Software Engineer, Senior Software Engineer, Full-Stack Engineer, or similar role developing enterprise-scale applications. • Strong hands-on experience with Java and modern Java development practices, with a deep understanding of object-oriented programming, design principles, and software design patterns. • Proven experience building RESTful APIs, microservices, and distributed applications using Spring Boot and the Spring Framework. • Experience developing modern, responsive web applications using React, Angular, TypeScript, JavaScript, or comparable frontend technologies. • Strong experience working with relational databases and SQL, including technologies such as PostgreSQL, Oracle, or SQL Server. • Experience designing and integrating applications using event-driven architectures, messaging platforms such as Kafka, and JSON/XML-based APIs. • Experience with cloud-native application development, Docker, Kubernetes, and cloud platforms such as Azure or AWS. • Strong understanding of software quality practices, including automated testing, code reviews, CI/CD, source control, and secure software development. • Demonstrated ability to troubleshoot complex technical issues, analyze system behavior, and optimize application performance and scalability. • Demonstrated technical leadership through complex projects, platform initiatives, architectural improvements, or cross-team engineering efforts. • Strong analytical and problem-solving skills, with the ability to navigate ambiguity, evaluate tradeoffs, and drive solutions from concept through delivery. • Excellent written and verbal communication skills, with the ability to explain technical concepts and collaborate effectively with both technical and non-technical stakeholders. • Bachelor’s degree in Computer Science, Engineering, Information Systems, or a related STEM discipline.
