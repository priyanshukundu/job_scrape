Senior Software Engineer - Vault - 45234 - Bloomberg Senior Software Engineer - Vault Location New York Business Area Engineering and CTO Ref # 10054501 Description & Requirements About Us Financial markets depend on secure, immutable, and regulatory-compliant systems for preserving, searching, and surveilling global client communications across instant messaging, social media, email, file sharing, voice, and video channels. Bloomberg Vault is building a next generation green-field platform for communications data, spanning high-throughput storage, low-latency search and retrieval, and real-time and retrospective surveillance. Key Responsibilities Design, build, test, and operate high-quality software across different parts of the technology stack. Participate in design and code reviews and contribute to shared engineering practices and standards. Collaborate effectively with engineers, product managers and partner teams. Mentor less-experienced engineers and contribute to the technical growth of the team. Practical experience using modern AI coding assistants or agentic development tools as part of software engineering workflows. Ability to critically evaluate AI-generated code for correctness, maintainability, performance, security, and alignment with requirements. Strong understanding of software engineering fundamentals, including system design, data structures and algorithms. Experience with automated testing, CI/CD, observability, and modern software delivery practices. Excellent written and verbal communication skills.
