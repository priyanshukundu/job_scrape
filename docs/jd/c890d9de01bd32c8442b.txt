Regular or Temporary: Regular Language Fluency: English (Required) Work Shift: 1st shift (United States of America) Please review the following job description: ROLE PURPOSE Design, build and operate governed workflow, low-code, Python and ontology-based solutions that represent Wealth Brokerage and Trust business objects, decisions and work processes accurately and securely. Job profile summary This Software Engineer independently designs, develops, tests and maintains workflow and data-centric applications for Wealth Brokerage and Trust. The role combines professional software-engineering discipline with low-code delivery, Python development, process automation and ontology modelling. The engineer translates business concepts such as clients, accounts, households, assets, transactions, cases, requests, approvals and items requiring attention into governed data objects, relationships, actions and workflows. Solutions must support explainable decisions, auditable processing and controlled human intervention. The role is not ungoverned citizen development. It requires deliberate architecture, reusable components, source control, testing, deployment discipline, access controls, monitoring, support readiness and clear ownership. Scope of responsibility • Brokerage and Trust workflow applications supporting client and account servicing, operations, review, approval, exception management and supervisory processes. • Low-code user experiences, forms, work queues, rules and automation integrated with enterprise applications, Azure services, SQL Server and approved data platforms. • Python services and utilities for data preparation, validation, enrichment, workflow logic, controls and operational automation. • Ontology models representing governed business concepts, relationships, states, actions and permissions used by applications, workflows and analytics. • Production support, controls, audit history, data lineage, observability, resilience and lifecycle management for the complete solution. ESSENTIAL DUTIES AND RESPONSIBILITIES Following is a summary of the essential functions for this job. Other duties may be performed, both major and minor, which are not mentioned below. Specific activities may change from time to time. 1. Design and develop governed low-code applications, workflow components, forms, work queues, business rules, notifications and operational dashboards for Brokerage and Trust. 2. Model end-to-end workflows covering intake, validation, classification, routing, prioritization, assignment, service levels, approvals, exception handling, escalation, completion and closure. 3. Design ontology objects, properties, relationships, actions and lifecycle states that accurately reflect Wealth business concepts and remain reusable across applications and analytics. 4. Use Python to implement data transformation, validation, enrichment, rule execution, reconciliation, automation, test utilities and supporting services where code is the appropriate mechanism. 5. Integrate workflow and ontology solutions with .NET/C# services, SQL Server, Azure PaaS, APIs, messaging, SFTP or managed file transfer, vendor platforms and enterprise data sources. 6. Implement fine-grained access, entitlements, segregation of duties, data masking, approval authority and action permissions appropriate to sensitive Wealth data and regulated processes. 7. Create auditable processing with clear state transitions, decision rationale, timestamps, ownership, source references, evidence and immutable history where required. 8. Build reusable components, ontology patterns, workflow templates and engineering standards that reduce duplication without creating a single enormous low-code contraption nobody can safely change. 9. Develop automated tests for Python code, workflow rules, permissions, data transformations, ontology actions and integration contracts. Support repeatable deployment and environment promotion. 10. Instrument applications and workflows with logging, metrics, queue ageing, throughput, exception, service-level and control-breach monitoring. Create operational runbooks and support documentation. 11. Partner with product, operations, data owners, risk partners and subject-matter experts to validate terminology, process states, business rules, authoritative sources and control evidence. 12. Assess when low code is appropriate and when complexity, scale, performance or supportability requires professionally coded services in .NET/C#, Python or Azure. 13. Troubleshoot production issues spanning user experience, workflow orchestration, ontology, Python, permissions, data quality, integrations and dependent platforms. Complete root-cause analysis and corrective action. 14. Lead design and code reviews, mentor junior engineers and contribute to governance for low-code, workflow, Python and ontology delivery across Wealth Technology.
