About This Job This role is onsite, located at our HQ in San Diego, CA. or Las Vegas, NV office locations. Remote is not available. Axos Bank is seeking a Databricks Data Engineer. We are moving the bank's Enterprise Data Warehouse from a SQL Server / SSIS-centric stack onto a Databricks lakehouse. This role owns design and delivery of production pipelines on Databricks: ingest (Lakeflow Connect and custom Spark), Bronze/Silver/Gold modeling, Unity Catalog governance, and operational reliability. You will not be a notebooks-only engineer. You will work with existing source systems (SQL Server, Salesforce, Workday, files/SFTP, APIs), current EDW patterns (Data Vault, staging, downstream consumers such as Tableau), and bank controls (PII, secrets, auditability). Fivetran remains in the estate where it already lands data; new modernization is Databricks-first. Responsibilities Design and build Databricks pipelines with Lakeflow (Connect, Jobs, Declarative Pipelines), Auto Loader, Delta Lake, and Spark (PySpark and Spark SQL). Implement Bronze/Silver/Gold medallion models that replace or sit alongside legacy SSIS and SQL Server loads. Use Lakeflow Connect for supported sources, and write custom Python/PySpark jobs where connectors don't exist (REST APIs, file formats, irregular extracts). Schedule, monitor, and tune jobs, covering clusters, Photon, partitioning, liquid clustering/Z-ORDER, CDC vs. full refresh, and DBU cost. Build alerts and runbooks for failed syncs, schema drift, and late-arriving data. Integrate Databricks with GitHub (branching, PRs, GitHub Actions) and work in Azure DevOps for PBIs, code review, deployment notes, and production support. Partner with platform/security on Unity Catalog, Entra identity, secret scopes/vault, and network access. Validate row counts, keys, and SCD/CDC behavior against current EDW outputs before cutover. Follow PII and data-classification standards, and never put secrets in notebooks or repos. Support downstream consumers (reporting, analytics, application feeds) with stable Gold tables and documented contracts. Use AI development tools (Cursor, Claude, Copilot, or equivalent) to write, review, test, and document pipelines. Review all generated code, and keep secrets and PII out of prompts. Contribute to AI/ML or generative-AI capabilities on governed data (Mosaic AI, MLflow, Vector Search, RAG, model serving) where the work calls for it. Upskill the EDW team through pairing, design reviews, and reusable patterns. Document architecture, runbooks, and rollback/cutover plans for each migrated source or domain. Requirements Bachelor's degree 4+ years building production data pipelines (warehouse, lake, or lakehouse). Hands-on production Databricks experience: Spark (PySpark and/or Spark SQL), Delta Lake, Jobs/Workflows. AI development: professional use of AI coding assistants (Cursor, Claude, GitHub Copilot, ChatGPT) on production data engineering work, and/or hands-on AI/ML or generative-AI development (MLflow, model serving, RAG/vector search, Mosaic AI). Strong SQL, including reading and replacing T-SQL/stored-procedure logic with lakehouse equivalents. Experience with at least one cloud (Azure preferred) and object storage (ADLS/S3/GCS). Git-based delivery (PRs, code review). Ability to work with source systems: JDBC/SQL, APIs, and file/SFTP ingest. Clear written communication (runbooks, design notes, review comments) in a regulated environment. Bachelor's in Computer Science, Information Systems, Engineering, or equivalent experience. Preferred Lakeflow Connect, DLT/Declarative Pipelines, Auto Loader, Structured Streaming, or CDC. Unity Catalog (grants, row filters/column masks, lineage). Azure Entra, Key Vault, private networking, and monitoring. SQL Server, SSIS, Fivetran, Data Vault, Collibra, Tableau. dbt on Databricks or a similar framework. Financial services or other regulated data (GLBA, SOX, BSA/AML-adjacent). Databricks certifications, GitHub Actions CI, and Mosaic AI/Vector Search/Feature Store experience. These are helpful, not gates.
