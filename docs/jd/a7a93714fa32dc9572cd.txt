Department Overview The Embedded Software Team at Motorola Solutions, Inc. delivers firmware for embedded devices including in-car video systems and body cameras. The highly skilled engineers in this team utilize their diverse backgrounds and specializations to develop Linux-based applications in support of the customer solution. The team uses modern C++ to develop highly portable code, and utilize state-of-the-art tools and systems throughout the development life cycle. Job Description We are seeking an Embedded Software Engineer to join our team in developing robust, scalable software for Linux-based embedded systems. In this role, you will be responsible for the full software lifecycle from architecture and C++ development to unit testing, system maintenance, and code reusability across production hardware. Responsibilities Application Development: Architect, code, and maintain embedded software applications using modern C++. System Integration: Work with vendor-provided APIs/SDKs, define clean software interfaces, and debug complex system-level issues on production hardware. Agile Execution: Author and refine user stories, execute unit and system-level tests, and participate in sprint deliverables within an Agile environment. CI/CD Build Pipeline: Utilize multi-stage continuous integration processes to build, test, and release reliable embedded software loads. Qualifications Core Experience: 1+ years of experience in C++ development paired with hands-on exposure to Linux-based embedded systems Education: Bachelor’s degree in Computer Science, Electrical Engineering, Computer Engineering, or a related field (or equivalent practical experience). Preferred Qualifications: Experience with low-level systems including Bare Metal C development, Linux Kernel drivers, device trees, and Yocto implementations. Familiarity with real-time operating system (RTOS) considerations, networking protocols, and CI/CD pipeline management. Exposure to Linux UI development, Android development, Open Source tools, or embedded neural network applications.
