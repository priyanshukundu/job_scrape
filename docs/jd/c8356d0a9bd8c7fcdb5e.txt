ROLE:

SentiLink's Information Security team protects our systems, data, and customers while enabling the business to move quickly and securely. As software development accelerates across the company, we're investing in engineers who can both build security capabilities and improve the security of the products we deliver to customers.

We're looking for a Senior Software Engineer, Product Security who combines strong software engineering skills with a security mindset. You'll build and operate custom security applications, automation, and integrations; investigate vulnerabilities in our applications and cloud infrastructure; and help engineering teams develop, test, and deliver more secure software.

This role spans software development and hands-on product security. You'll work closely with other product security engineers and the broader Engineering and Infrastructure teams to uncover difficult security problems, develop practical solutions, and drive them through implementation. We're looking for someone who is curious about how systems fail, can navigate complex codebases and architectures, and has the technical range to move between building security tooling and validating the security of customer-facing products.




RESPONSIBILITIES:

 - Design, build, deploy, and maintain custom security applications and services that improve vulnerability discovery, attack-surface visibility, security testing, and remediation workflows.

 - Develop backend services, APIs, data-processing pipelines, integrations, and user interfaces that make security information useful and actionable for engineers.

 - Assess the security of SentiLink's customer-facing products and internal applications through code review, threat modeling, vulnerability research, and hands-on security testing.

 - Perform targeted penetration testing and validate potential vulnerabilities, including reproducing findings, assessing exploitability and impact, and verifying that fixes are effective.

 - Work directly with product engineering teams to investigate and remediate application vulnerabilities, strengthen security-sensitive designs, and implement durable fixes.

 - Develop and improve automated security testing within CI/CD and application delivery workflows, including static and dynamic analysis, dependency and container scanning, and security validation.

 - Build integrations with cloud services, source-control systems, scanners, and other engineering and security platforms; improve the quality and usefulness of vulnerability data and reduce manual operational work.

 - Use AI-assisted development and security analysis tools to accelerate delivery and expand testing coverage, while applying independent technical scrutiny to their output.

 - Take responsibility for the full lifecycle of the systems you build, including architecture, implementation, testing, deployment, observability, reliability, and ongoing improvement.

 - Collaborate with Security Engineering, Infrastructure, and product teams on security architecture, technical investigations, incident response, and remediation of identified risks.

 - Participate in the security on-call rotation and help improve the effectiveness of the team's technical security capabilities.
