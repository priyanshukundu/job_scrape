Job Description We are seeking a Senior Software Engineer specializing in enterprise API engineering and API management. This role will design, develop, secure, and support scalable API solutions using platforms such as Apigee, Apollo GraphQL, AWS API Gateway, and Azure API Management (APIM) . The engineer will partner with teams across the organization to deliver API products while supporting API governance, security, development standards, and operational excellence. Responsibilities Design, develop, test, deploy, and support enterprise REST and GraphQL APIs and API management solutions. Build and manage API proxies, policies, and products in Apigee , including security, validation, transformation, traffic management, and routing. Partner with business and technology teams to design and promote reusable, scalable API products and services . Develop and manage GraphQL services and subgraphs using Apollo GraphQL and Apollo Studio . Build and support API integrations using AWS API Gateway and Azure API Management (APIM) . Participate in API governance , ensuring solutions align with security, architecture, development, and platform standards. Analyze API and application failures, troubleshoot complex issues, and implement design and operational improvements that enhance reliability and customer experience. Automate API build, testing, deployment, and lifecycle processes using modern DevOps, CI/CD, container, and cloud technologies . Basic Qualifications - Bachelor’s degree, or equivalent work experience - Five to six years of relevant experience Preferred Skills/Experience Strong experience with API development, REST APIs, GraphQL, and microservices . Hands-on experience with Apigee , including API proxies, policies, security, validation, and routing. Strong knowledge of OpenAPI/Swagger, API security, governance, and API lifecycle management . Proficiency in Java and enterprise application development. Experience with Apollo GraphQL or similar GraphQL technologies. Experience with AWS API Gateway, Azure API Management (APIM), or comparable cloud API platforms . Experience with Git, Jenkins/GitLab, Maven, Kubernetes, and CI/CD or similar DevOps technologies. Experience with API development and testing tools such as Postman, IntelliJ/Eclipse, Cucumber, or similar tools .
