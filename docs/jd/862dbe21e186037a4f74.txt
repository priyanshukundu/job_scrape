Senior System Software Engineer, Workstation Performance
NVIDIA
Location: US, CA, Santa Clara
Link: https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite/job/US-CA-Santa-Clara/Senior-Graphics-Driver-Engineer_JR2025486

NVIDIA is seeking an engineer who enjoys developing software and uncovering why complex professional applications behave the way they do. You will develop and optimize graphics software, analyze real-world application workloads, design experiments to isolate bottlenecks, debug quality and performance regressions, and collaborate with driver teams to turn your findings into measurable improvements. You will work with leading professional applications used for design, engineering, digital content creation, and visualization. You will also contribute to the development and analysis of industry-standard workstation benchmarks. This role offers opportunities to solve challenging technical problems while learning about advanced graphics, GPU computing, AI-assisted engineering, and emerging workstation technologies. What you’ll be doing Develop, debug, and validate graphics software and optimizations that improve professional application performance on NVIDIA GPUs. Analyze professional workstation applications and identify opportunities to improve performance and user experience. Design experiments and develop analysis techniques to isolate complex application-performance bottlenecks. Profile application and graphics API workloads using traces, performance counters, and other analysis techniques. Create tools, scripts, and automated workflows, including AI-assisted techniques, for performance analysis, regression detection, and validation. Collaborate with application developers and NVIDIA driver, architecture, and hardware teams to evaluate and deliver performance improvements. Develop representative workstation benchmarks that capture meaningful real-world application behavior. What we need to see BS, MS, or PhD in Computer Science, Software Engineering, Computer Engineering, or a related field—or equivalent experience. Strong C/C++ programming skills. 5+ years experience with software performance analysis, profiling, optimization, or debugging. Understanding of computer architecture, operating systems, and how applications interact with graphics APIs and GPU hardware. Familiarity with source-control systems such as Perforce or Git. Experience with software development methodologies such as design reviews and code reviews. Ability to develop and debug software in a Windows OS environment. Strong analytical, problem-solving, communication, and collaboration skills. Experience using AI-assisted development tools and enthusiasm for learning new technologies. Ways to stand out from the crowd Knowledge of graphics APIs such as OpenGL, Direct3D, or Vulkan. Experience developing low-level systems, graphics, driver, or performance-analysis software. Experience with application benchmarks or automated performance testing. Knowledge of statistical techniques for analyzing variance, repeatability, and performance results. Scripting experience with Python, Perl, or similar languages. Are you an analytical and highly motivated engineer who enjoys developing graphics software, understanding complex application workloads, and finding effective ways to make them run faster? If you are passionate about workstation performance and solving challenging engineering problems, you may be a great fit for NVIDIA.
