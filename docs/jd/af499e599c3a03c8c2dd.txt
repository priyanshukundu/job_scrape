Our vision is to transform how the world uses information to enrich life for all . Micron Technology is a world leader in innovating memory and storage solutions that accelerate the transformation of information into intelligence, inspiring the world to learn, communicate and advance faster than ever. Work with area experts and automation developers to automate tools and implement host enhancements in a timely manner. Assist in the prioritization and requirement gathering for new hosts and host enhancements. Work with the automation developers and tool owners to schedule tool time for automation testing and upgrades. Provide expertise and assistance in GeRM, ET and Sigma setup as tool owners and automation developers design and test new hosts and enhancements. Participate in a wide variety of automation projects such as BiRD, RPA, and FDC. Strive for automation alignment of the 300mm Fabs. Actively work with AMHS representatives worldwide to implement the best know system. Maintain documentation around procedures and protocols. Weekly status reports to managers for all ongoing projects. Aid in debugging automation problems within a daily support role. Support software development teams in defining requirements for enhancements. Assist in the creation of training documentation for software enhancements. Provide testing of manufacturing applications for ECR and DAW software releases. Work with the Fab Software Support team to find and implement solutions to guarantee software resiliency. Demonstrate a thorough knowledge of the MES systems, Framework, MESC, Batch Stage Controller, ToolView, Sigma, associated data, and support tools through day-to-day problem-solving efforts. Develop and maintain automation software systems supporting manufacturing operations, including automated material handling systems.
