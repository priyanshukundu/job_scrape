Databricks Data Engineer and Scientist The Opportunity: As a Databricks Data Engineer and Scientist, you will design, build, and maintain robust data pipelines for a critical enterprise Lakehouse, applying your data science, AI, and analytics skills. You will develop and optimize end-to-end data flows, manage ETL processes, design data models, help ensure data security and compliance, collaborate with cross-functional teams, and improve performance and scalability. Your experience with Databricks and AWS, along with your SQL, Python, and AI-assisted coding skills, will help you analyze pipelines, support data modeling, and turn raw data into actionable insights across the business. Work with us to use data for good. Join us. The world can’t wait. writing Python and PySpark code for ETL scripts and custom transformations Experience using AI-assisted coding tools such as Claude Code or Cursor to support data engineering and data modeling tasks Experience with data modeling, including selecting dimensional or relational models, within a Bronze, Silver, and Gold medallion architecture Experience using AWS services, including AWS Glue, Amazon
