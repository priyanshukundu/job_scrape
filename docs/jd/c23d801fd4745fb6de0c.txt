As a Staff Software Engineer at JLL, you will lead the design and implementation of complete features spanning React frontend, C# backend services, database layer, and deployment pipeline, with a strong focus on scalable 3D geospatial solutions built on the ArcGIS platform. This senior technical role requires you to discover problems, determine their criticality, and drive your own projects to successful conclusions while mentoring junior engineers - across both GIS-specific systems and the broader full-stack platform. Key Responsibilities Technical Leadership & Architecture Lead the design and implementation of complete features spanning React frontend, C# backend services, spatial and relational database layers, and deployment pipeline - owning the full stack for geospatial and non-geospatial features alike. Discover problems, determine their criticality, and drive projects to a successful conclusion. Perform solution design and independently create solutions for ill-defined or complex problems that cross domains, considering interactions with other systems and future maintenance. Design and build scalable 3D geospatial solutions using the ArcGIS Maps SDK for JavaScript to surface enterprise data, optimizing spatial data workflows and query performance. Own the full stack for geospatial features — React/ArcGIS frontend, C# backend services, spatial database layer, and deployment — as well as non-geospatial features across the same stack. Set up end-to-end solution structure, DevSecOps tooling, and processes using Octopus Deploy and cloud technologies. Development & Implementation Work with product technical leads to design new products or enhancements and participate in system development, including analysis, coding, and testing. Leverage AI coding assistants and enterprise software agents to rapidly develop, test, and iterate on production-quality code. Provide robust implementations that follow best practices with minimal feedback during code reviews. Improve related or underlying code while implementing and overseeing best practices for the team. Quality Assurance & Problem Resolution Own quality assurance through comprehensive testing approaches, including unit testing, system integration testing, and user acceptance testing. Develop robust tests to cover all relevant cases for larger pieces of functionality and be comfortable modifying, improving, and creating test frameworks. Triage complicated failures and drive resolution independently, while helping others with troubleshooting and root cause analysis. Mentorship & Collaboration Work closely with Product Managers and business stakeholders in fast iteration cycles, understanding the product vision and how components fit within the overall product strategy. Mentor junior engineers on standards and techniques to improve accuracy and efficiency. Provide ongoing support for applications used within the organization. Qualifications Required 8+ years of professional software engineering experience. Hands-on experience with the ArcGIS Maps SDK for JavaScript (4.x), including 3D development and publishing and serving spatial data. Hands-on experience with modern LLM APIs across multiple providers, including prompt engineering, tool use/function calling, structured outputs, and context engineering, with demonstrated understanding of transferable patterns across evolving APIs. Strong ability to review, validate, and debug AI-generated code with strong engineering judgment to know when to trust AI output and when to intervene. Solid understanding of backend systems, microservice architectures, and distributed systems using C#, Python, or Node.js. Front-end experience with React (Angular or Vue.js also considered), across both product-facing applications and internal tools and dashboards. Experience designing and maintaining RESTful APIs. Solid experience with a major cloud platform Experience with relational databases (SQL Server, PostgreSQL, MySQL) and NoSQL databases Working knowledge of CI/CD, infrastructure as code, and containerization technologies Demonstrated ownership of testing strategy across unit, integration, and end-to-end layers, including building or improving test frameworks — not just writing tests within an existing one. Experience triaging production failures and driving root cause analysis to resolution independently. Preferred Experience building or deploying LLM-enabled systems, AI agents, or agent orchestration frameworks. Experience designing evaluation and testing frameworks for AI- or agent-generated outputs. Familiarity with enterprise AI/agent platforms and tool ecosystems. Experience in Commercial Real Estate, Research, Financial Services, or other data-intensive domains. Experience modernizing legacy systems or migrating platforms to cloud-native architectures.
