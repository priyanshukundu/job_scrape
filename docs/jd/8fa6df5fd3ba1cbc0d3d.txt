You will report to the Software Engineering Manager, and reside in or near Franklin, TN. The Tools Engineering team is modernizing legacy .NET applications into React, TypeScript, and modern .NET services. As a Lead Software Engineer, you will guide this transformation while contributing directly to architecture, development, and technical decisions. This is an AI-forward role, and you will help the team adopt responsible AI-assisted engineering practices and maintain the applications after modernization. You'll have the opportunity to: Lead the modernization of legacy ASP.NET applications using React, TypeScript, and modern .NET APIs. Develop applications using established React components, Material UI (MUI), and shared design standards. Use AI tools, including Cursor and Claude, to improve development, testing, and code modernization. Establish standards for secure, reliable AI-assisted development and code review. Guide architecture, development, troubleshooting, and mentoring while contributing production code. Define frontend and backend standards for APIs, security, performance, and automated testing. Partner with product, architecture, security, and engineering teams to deliver modernization initiatives. Oversee the reliability, maintenance, and continued development of applications and supporting services. Your background: 7+ years of professional software engineering experience with C# and the Microsoft .NET ecosystem. 2+ years of experience using AI-assisted software engineering tools, including Cursor and Claude, across software development workflows such as code generation, refactoring, testing, and code review. Experience developing and modernizing applications using legacy ASP.NET and modern .NET or ASP.NET Core. Hands-on experience developing React applications, including frontend architecture and API integration. Experience designing REST APIs, service-based applications, and incremental enterprise application modernization. Experience providing hands-on technical leadership through software design, coding, code reviews, and mentoring. Experience with automated testing, continuous integration and delivery, source control, and application security practices. Our uniqueness is that we celebrate yours.
