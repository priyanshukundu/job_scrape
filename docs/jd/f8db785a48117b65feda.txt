Try new things, learn new skills and discover what you excel at—all from Day One. Job Description U.S. Bank is seeking a full-time Senior Software Engineer (Multiple openings) in Columbus, OH. The professional Senior Software Engineer (multiple openings) will be responsible for the analysis, design, testing, development and maintenance of best-in-class software experiences. This role collaborates with a team and across the organization, and take responsibility of the software artifacts produced adhering to U.S. Bank standards in order to ensure minimal impact to the customer experience. Specific duties include the following:(1) taking full stack ownership by consistently writing production-ready and testable code; (2) designing and implementing scalable microservices using Java, Spring Boot, Spring Batch, Spring Data JPA, and REST APIs; (3) developing enterprise applications including application design, coding, testing, debugging, maintenance, and automation; (4) conducting code reviews and ensuring compliance with engineering standards, coding best practices, and development procedures; (5) working with microservices and API development using Java and Spring Boot; (6) working in Agile and Scrum environments with a strong grasp of SDLC and DevOps principles with ability to collaborate with cross-functional teams; (7) utilizing event-driven and streaming architectures, including Kafka and Spark; (8) implementing experience with Unit Testing and Integration Testing using JUnit and Spring Testing Frameworks to ensure application reliability and code quality; and (9) working with tools including Jenkins, CloudBees, as well as containerization and orchestration platforms, which include Docker, Kubernetes, and Rancher. Basic Qualifications: This position requires a Bachelor’s degree or equivalent in Computer Science, Computer Networking, or Computer Engineering and 5 years of post-baccalaureate experience designing and implementing scalable microservices. Required Skills/Experience: Must also have 24 months of experience with each of the following: (1) working with microservices and API development using Java and Spring Boot; (2) working in Agile and Scrum environments with a strong grasp of SDLC and DevOps principles with ability to collaborate with cross-functional teams; (3) utilizing event-driven and streaming architectures, including Kafka and Spark; (4) implementing experience with Unit Testing and Integration Testing using JUnit and Spring Testing Frameworks to ensure application reliability and code quality; and (5) working with tools including Jenkins, CloudBees, as well as containerization and orchestration platforms, which include Docker, Kubernetes, and Rancher.
