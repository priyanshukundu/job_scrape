Job Description We are seeking a Senior .NET Backend Engineer with deep expertise in Microsoft Azure , C#/.NET , and cloud-native architecture to design, build, and support highly scalable enterprise applications. This role will lead the development of modern backend services, microservices, and event-driven solutions while driving platform reliability, security, and performance. The ideal candidate is a hands-on senior engineer who can own solutions from architecture through production support, collaborate across teams, and solve complex technical challenges in large-scale cloud environments. Essential Responsibilities: Design, develop, and support backend applications using C#, .NET Core, and .NET 8/10+ on Microsoft Azure . Build scalable microservices , APIs, and event-driven architectures supporting enterprise-scale workloads. Develop cloud-native integrations using Azure Service Bus, Functions, API Management, Storage, and Azure SQL . Deploy and manage containerized applications using Docker and Azure Kubernetes Service (AKS) . Create and maintain automated CI/CD pipelines using Azure DevOps and GitHub Actions . Implement Infrastructure as Code (IaC) solutions using Terraform, Bicep, or ARM templates . Drive application reliability through observability, monitoring, resiliency, and performance optimization. Troubleshoot and resolve complex production issues while partnering across engineering, platform, architecture, and business teams. Basic Qualifications - Bachelor’s degree, or equivalent work experience - Six to eight years of relevant experience Required Qualifications C# / .NET 8+ and modern API/microservices development Azure cloud development, including Docker and AKS Kafka , event-driven architecture, and asynchronous processing SQL Server / Azure SQL Workflow/orchestration development, including sequential and parallel processing File and API integrations, including retry, recovery, idempotency, and exception handling CI/CD, Azure DevOps , and automated unit/integration testing Experience with GitHub Copilot, Claude Code, or similar AI development tools Experience building high-volume, transaction-processing applications Experience within financial services, wealth management, capital markets, asset management, custody, fund accounting, or asset servicing Location expectations This role requires working from a U.S. Bank location three (3) or more days per week.
