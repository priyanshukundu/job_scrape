You are: Curious and eager to learn new things, with a healthy disrespect for the status quo Excited to learn about new technologies and strive to reach new levels of efficiencies in the platform we provide. Passionate about technology, with personal ownership for the work you do Data-focused, with an eye for the details that matter to solve the problem Proficient in using AI for day-to-day engineering work. We are: Passionate about building quality software and scaling technology to meet the needs of tomorrow Building solutions for BlackRock and over 200 institutions that rely on our technology who use our technology The team behind Aladdin Graph—enabling API‑first engineering through a schema repository, governance, and production runtime infrastructure for APIs and events. Focused on API quality and consistency at scale, using governance and review standards to help teams ship better APIs faster. Building high quality software in Java, Python and Golang using technologies like highly available distributed NoSQL data storage platforms, scalable search and indexing platforms, Redis, distributed event streaming and messaging platforms, Enterprise-grade container orchestration platform supporting declarative infrastructure and horizontal scaling, and more. Investing in developer experience: clear standards, repeatable “golden paths,” and tooling that makes onboarding and adoption easier. You have (Must have): Minimum of 3+ years software engineering work experience on large-scale software development and deployment. BS/MS in Computer Science from an accredited university (or equivalent practical experience). Strong programming skills in Java, Python, or Golang (and willingness to learn). Experience in Linux shell and comfort troubleshooting production-style issues (logs, configs, basic networking). You have (Nice to have): Experience with event messaging systems like distributed event streaming and messaging platforms and event-driven architectures. Experience with API frameworks, Google API Improvement Proposals (AIPs), and protobuf. Experience with gRPC, including defining service contracts using Protocol Buffers and implementing gRPC clients and servers. Familiarity with API governance models and review expectations that keep APIs consistent and high quality.
