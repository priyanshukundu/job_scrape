AVP AI Software Engineer
Citi
Location: Tampa Florida United States
Link: https://citi.wd5.myworkdayjobs.com/2/job/Tampa-Florida-United-States/AVP-AI-Software-Engineer_261005811

As an AI Software Engineer, you will build and test agentic workflows and knowledge graph solutions that automate data processing for Citi's Corporate Tax Technology team. Based in Tampa, you will apply agentic frameworks and graph databases to accelerate how tax data is extracted, validated, and analyzed. This hands-on role puts emerging AI development practices directly into production use. Responsibilities Build and maintain multi-agent workflows using agentic frameworks such as ADK and LangGraph to automate data extraction and validation. Implement and maintain graph data models and queries in Neo4j to connect tax data relationships and documentation. Apply AI developer tools such as GitHub Copilot and Devin to accelerate coding, unit testing, and workflow automation. Build and maintain retrieval-augmented generation pipelines that connect tax data sources with internal AI services. Write and execute automated tests that evaluate agent accuracy and output validation. Apply security and data handling standards consistently across AI and agent implementations. Required Qualifications & Skills Expertise in Java-based frameworks such as Spring and Spring Boot. Hands-on experience building autonomous agent workflows and tool-calling systems using frameworks such as LangGraph or ADK, along with practical RAG and vector retrieval implementation. Demonstrated hands-on experience actively utilizing modern AI developer tooling (such as GitHub Copilot, Devin, or AI-assisted IDEs) for code generation, testing, and development acceleration Practical experience with unit testing, agent evaluation benchmarks, security/guardrail enforcement, and standard SDLC practices (Git, Docker, CI/CD) Beneficial Skills & Qualifications Practical experience with graph databases, knowledge graph concepts, and writing/optimizing queries in Neo4j . Exposure to querying or integrating modern data platforms (Apache Iceberg, Snowflake, Trino / Starburst, AWS S3) is advantageous. Exposure to Python (FastAPI, async, data manipulation), RESTful API development, and relational database / SQL querying is advantageous. Prior exposure to corporate tax, financial accounting data, or enterprise ledger structures is advantageous. What We Offer You will apply emerging agentic AI and graph technologies to real production use cases, with direct exposure to how AI tooling is scaled inside a global financial institution. Work in a hybrid model with 3 days in the office and 2 days working remotely each week. Build technical depth in agentic AI frameworks, knowledge graphs, and modern AI developer tooling. Take part in learning and development programs focused on emerging technology skills. Access wellbeing and work-life balance resources as part of your employee experience.
