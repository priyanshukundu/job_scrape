Senior Network Software Engineer
Leidos
Location: Shiloh, IL
Link: https://leidos.wd5.myworkdayjobs.com/External/job/Shiloh-IL/Senior-Network-Software-Engineer_R-00195242

Leidos’ Digital Sector/Global Solutions Management-Operations II (GSMO-II) contract has an opening for a Senior Network Software Engineer located in the Scott AFB, IL area. The Senior Network Software Engineer will support the development and release of new software tools using the Cisco Network Services Orchestrator (NSO) platform, Python, and other software languages to sustain and manage a Carrier-class Wide Area Network for the Defense Information Systems Agency under the Department of War. Additionally, the position will offer the candidate an opportunity to engage in network engineering using knowledge of routing and system fundamentals in an ISP level network environment. This position is ideal for a networking professional with software development experience looking to develop and expand their abilities and showcase their skills in a fast paced and technically challenging role. Primary Responsibilities- Design, develop, document, test and release software written in Python, XML, and other languages for use with the Cisco Network Services Orchestrator (NSO) platform. Integrate software with network devices, including Cisco ASR9K and Juniper MX series routers. Perform engineering tasks related to the design, implementation, and integration of network changes and sustainment of customer systems in a Wide Area Network environment. Conduct planning and performance of analytical research, design development, and other tasks to align with customer specifications. Ensure efficient delivery of contract capabilities using industry standards and repeatable processes. Mitigate risks, control costs and schedule variance, and effectively manage large scale, integrated projects. Perform a variety of analytical tasks which include hardware and software design and implementation. Proactively and independently identify, report, monitor, and mitigate technical risks. Frequently communicate and collaborate with other team members to ensure successful completion of project objectives. Provide mentorship and act as a technical resource for lower-level network engineers. Basic Qualifications- Currently possess an active DoD Secret clearance or higher Currently possess DoD 8750 certification at IAT level II, Security+ CE or equivalent to meet requirement. Python software development experience that includes REST api development, as well as the parsing, generation and validation of JSON. Experience with distributed version control software such as Git and Bitbucket. Experience developing software on a Linux platform. Experience troubleshooting and configuring IP networks using at least one of the following routing methods: BGP, ISIS, OSPF, and/or Static routing. Experience with either service provider or enterprise IP networks using an interface on Cisco (ESR and ASR) and/or Juniper routers. Strong communication skills that enable proactive and effective collaboration with a team. Knowledge of and ability to apply principles, theories, and concepts of Software Engineering. Preferred Qualifications- Proficient in Juniper and Cisco configuration, troubleshooting, and design. Experience with Cisco IOS XR, JUNOS, and Cisco IOS codes. Network configuration experience, specifically with Juniper or Cisco routers, to include protocols such as BGP, MPLS, VPLS, Pseudowires and QoS. Certifications with major network system vendors such as Cisco are a strong plus Experience developing XML and/or object-oriented programming. Experience developing software using SDN modeling languages and protocols such as YANG, NETCONF and RESTCONF. Full software lifecycle experience (design, development, test, deployment), including deployment to a production environment. Experience developing software including the ability to quickly learn new technologies. Experience creating software design artifacts, including the creation of functional, technical, and architectural design documentation as well as test cases and installation, deployment and configuration documentation. Software Defined Networking experience, particularly experience with Cisco NSO. Possessing project, technical, interpersonal, presentation and problem management skills.
