Job Description: Position Summary HPE Operations is seeking a Mid-Level Java/Spring Boot Developer to support the development, enhancement, and maintenance of critical Software Ops applications. The successful candidate will be responsible for designing, developing, testing, securing, and supporting enterprise Java applications and microservices. This role requires strong experience with Spring Boot technologies, modern software development practices, application security remediation, CI/CD automation, and containerized deployment environments. This position will play a critical role in supporting ongoing cybersecurity initiatives, application modernization efforts, and future Kubernetes-based platform improvements. Key Responsibilities Design, develop, and maintain enterprise Java applications using Spring Boot. Develop scalable and resilient microservices using Spring MVC and Spring Data JPA. Design and implement RESTful APIs and backend services. Create and maintain automated unit tests using JUnit 5 and Mockito. Troubleshoot, debug, and resolve application defects and performance issues. Manage database schema changes and migrations using industry-standard migration tools. Containerize applications and services using Docker. Participate in code reviews and enforce software engineering best practices. Address cybersecurity findings and vulnerability remediation activities identified through VTN, Quercus, and other security assessment platforms. Analyze and remediate CVEs affecting supported applications and dependencies. Improve code quality through SonarQube analysis and technical debt reduction. Support CI/CD automation using Jenkins and GitHub-based workflows. Collaborate with DevOps, Infrastructure, Security, and Product teams to deliver reliable solutions. Participate in deployment, operational support, and production issue resolution. Support modernization efforts, including Kubernetes proof-of-concept and cloud-native initiatives. Required Qualifications Bachelor's degree in Computer Science, Software Engineering, Information Systems, or related discipline. 3-5 years of professional Java development experience. Strong experience developing applications using: Spring Boot Spring MVC Spring Data JPA Experience building and maintaining microservices architectures. Experience developing RESTful APIs. Strong SQL and relational database experience. Experience writing unit and integration tests using: JUnit 5 Mockito Experience using Git-based source control systems. Experience working in Agile development environments. Strong troubleshooting and problem-solving skills. Excellent written and verbal communication skills. Preferred Qualifications Experience managing cybersecurity vulnerabilities and CVE remediation. Experience using SonarQube to improve code quality and reduce technical debt. Experience with Jenkins CI/CD pipelines. Experience using GitHub, GitHub Actions, and pull request workflows. Experience with Docker containerization and image management. Knowledge of Kubernetes or OpenShift platforms. General DevOps experience supporting software delivery pipelines. Experience supporting Linux-based environments. Familiarity with cloud platforms and cloud-native application development. Knowledge of observability, monitoring, and logging tools.
