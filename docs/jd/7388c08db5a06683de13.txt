Title and Summary Senior Software Engineer Overview: Mastercard’s Commercial Customer Experience team is seeking a Senior Software Engineer to help design, develop, and deliver scalable, secure, and high-performing software solutions that power critical customer experiences and business capabilities. This is a hands-on full-stack engineering role with a strong focus on backend development using Java and Spring Boot, while also contributing to modern web applications built with Angular. The ideal candidate will have experience building enterprise-scale applications, microservices, REST APIs, and event-driven systems using streaming technologies such as Apache Kafka. You will play a key role in developing cloud-native solutions, driving engineering excellence, and delivering resilient, customer-focused products in a collaborative Agile environment. You will work from Mastercard's technology hub in a collaborative, Agile environment alongside talented engineers, product managers, technical program managers, and test engineers. This is a hybrid role based in Arlington, VA, requiring three days per week onsite. Role: • Design, develop, and evolve secure, scalable Java/Spring Boot microservices and APIs. • Build and maintain full-stack applications, contributing to both Angular-based user interfaces and Java/Spring Boot backend services. • Design and implement event-driven architectures using Apache Kafka or similar streaming and messaging technologies. • Translate business and product requirements into reliable, maintainable technical solutions, contributing to system architecture and technical design. • Build and integrate services across Angular applications, databases, internal platforms, and third-party systems, including efficient SQL and database solutions for high-volume workloads. • Apply AI-assisted development tools to accelerate coding, testing, debugging, documentation, code reviews, and software quality improvements with appropriate human oversight. • Develop solutions that meet Mastercard standards for security, performance, scalability, reliability, and operational excellence, applying enterprise security patterns such as authentication, authorization, encryption, and secrets management. • Apply 12-factor application principles, cloud-native practices, and Mastercard engineering governance throughout the development lifecycle. • Participate in code reviews, pull requests, retrospectives, and technical discussions, contributing to high-quality engineering practices and continuous improvement. • Collaborate with Software Engineers, Test Engineers, Product Managers, Technical Program Managers, and other stakeholders to deliver customer-focused solutions. • Troubleshoot complex production and performance issues, improve system reliability, and mentor engineers by sharing technical knowledge and best practices.
