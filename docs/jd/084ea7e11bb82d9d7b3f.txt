About the Role Join a team building the backend services that power critical order management and omnichannel retail experiences. As a Software Engineer on the Order Management team, you’ll help design, build, test, and support scalable services that manage complex order workflows. You’ll work with technologies including Java, Spring Boot, Kafka, relational and NoSQL databases , while gaining exposure to distributed systems, event-driven architecture, production observability, and modern engineering practices. This is a hands-on engineering role for someone who enjoys solving problems, writing high-quality software, and taking ownership of the applications they help build—from development through production. What You’ll Do Design, develop, test, and maintain backend services using Java and Spring Boot . Build and support microservices and event-driven applications using technologies such as Kafka . Translate business requirements and functional specifications into technical solutions and production-ready code. Participate in technical design discussions and contribute to solutions that are scalable, maintainable, resilient, and aligned with engineering standards. Develop automated unit, integration, and behavior-driven tests using tools such as JUnit, Mockito, and Cucumber . Work with relational and NoSQL databases, including technologies such as Oracle, PostgreSQL, and MongoDB . Build observability into applications and use monitoring and logging tools such as Elasticsearch, Prometheus, and Grafana to understand application health and performance. Troubleshoot application and production issues, participate in root-cause analysis, and help implement solutions that improve reliability and prevent recurring problems. Use source control, build, and delivery tools such as Bitbucket, Maven, Gradle, and CI/CD pipelines as part of the software development lifecycle. Collaborate with engineers, product partners, and other cross-functional teams to deliver solutions supporting order management workflows. Participate in code reviews, technical documentation, knowledge sharing, and continuous improvement of team engineering practices. Evaluate new tools and technologies and contribute ideas that simplify development, testing, deployment, and operational processes. Minimum Qualifications Bachelor’s degree in Computer Science, Computer Information Systems, or a related field, or equivalent professional experience. 2+ years of software development experience with hands-on experience developing backend applications using Java or a comparable object-oriented programming language . Experience developing applications using Spring Boot, microservices, APIs, or similar backend technologies . Experience with one or more of the following: event-driven or messaging technologies, relational or NoSQL databases, automated testing, CI/CD, or DevOps practices . Experience working within an Agile software development lifecycle and using modern source-control practices. Preferred Qualifications Hands-on experience developing applications with Java and Spring Boot . Experience building or supporting microservices and event-driven systems using Kafka or a comparable messaging platform . Experience working with relational and NoSQL databases such as PostgreSQL, Oracle, MongoDB, Cassandra, or similar technologies . Experience with automated testing tools and practices, including technologies such as JUnit, Mockito, or Cucumber . Experience supporting applications in production, including troubleshooting, monitoring, incident response, or root-cause analysis using tools such as Elasticsearch, Prometheus, Grafana, or similar platforms . Experience with build, source-control, and delivery technologies such as Bitbucket, Maven, Gradle, and CI/CD pipelines .
