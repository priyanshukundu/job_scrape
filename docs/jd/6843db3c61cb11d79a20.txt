Our customers are at the center of everything we do and we’re looking for associates who are passionate about delivering extraordinary care. #LI-DNI Job Description Summary Job Description Data Engineer needed to design, implement, maintain, and support ETL, data warehousing, and enterprise data-integration workflows across relational databases, file systems, and service interfaces using Ab Initio, SQL, PL/SQL, Unix shell scripting, and Teradata, Oracle, and DB2 platforms, including mappings, metadata-driven transformation logic, and ETL performance tuning for high-volume data flows. Perform automated and manual testing of Data warehousing pipelines, analytics workloads, and application systems using Jira and HP Quality Center, including test scripts, test plans, test cases, traceability, regression support, and migration-readiness checkpoints across the full SDLC, including requirements analysis, design, development, testing, deployment coordination, issue tracking, defect management, sprint planning, and release coordination using Jira and post-implementation production support. Design and optimize physical and logical data models and SQL and PL/SQL based processing logic to support reporting, query performance, data consistency, dimensional modeling, schema design, and large-scale data processing. Develop and execute Unix shell scripts for automation, job orchestration, file transfer, and environment management, and engineer, schedule, and monitor enterprise data-processing workloads using Control-M and Autosys, including production support, ETL performance tuning, root-cause analysis, and production moves. Utilize C, XML and related technologies including HTML, for structured data handling, file- based interfaces, and ETL support across heterogeneous source and target systems.
