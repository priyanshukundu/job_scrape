Meet the team: As part of the Commercial Data Science & Revenue Operations team, you will join a data engineering group responsible for building and operating Dexcom’s commercial data platform on AWS. As a Staff Data Engineer, you will design and build data services that ingest from 12+ vendor sources, orchestrate transformation pipelines, and deliver analytics-ready datasets to data scientists, analysts, and 300+ field representatives. You will own AWS-native development workflows using Lambda, Glue, CDK, Step Functions, and Redshift, with a focus on reliability, automation, and scalable infrastructure. The ideal candidate will partner with data scientists and business stakeholders to build the platform that powers commercial analytics and AI/ML initiatives. Where you come in: Design and build data pipelines that ingest, transform, and deliver vendor data (SFTP, API, file-based sources) into S3 and Redshift, with validation checks and automated error handling at each stage. Own AWS-native development workflows leveraging Lambda, Glue, CDK, and Step Functions to create scalable, cost-aware data services that integrate cleanly with enterprise platforms and reduce manual operational overhead. Implement data quality assertion frameworks that validate completeness, freshness, and accuracy at pipeline boundaries before data reaches downstream consumers — data scientists, analysts, and commercial teams. Build alerting systems and reliability playbooks that enable the team to detect and respond to data platform issues before they impact downstream consumers, shortening mean time to detect/resolve. Model and evolve the data warehouse schema , designing dimensional models and orchestrating multi-source feeds into a unified analytical layer with documented lineage and managed schema evolution. Partner with Privacy, Security, and IT on data governance requirements, translating policy requirements into technical implementations that keep the platform compliant without slowing engineering velocity. Set technical direction for your area and mentor team members through code reviews, pairing sessions, and documentation of reusable patterns and architectural decisions. What makes you successful: Cloud: Hands-on proficiency with AWS-native architectures (Lambda, Glue, S3, Redshift, Step Functions, CDK) with cost optimization awareness and ability to make build-vs-buy trade-off recommendations. Active AWS certification (Solutions Architect - Associate, Data Engineer - Associate, or equivalent) preferred. Data Platform: Experience designing dimensional models and managing schema evolution in a growing data platform serving multiple stakeholder groups, with strong SQL skills including complex query optimization and debugging. Engineering: Proficiency in Python development in cloud environments, including CI/CD pipeline construction with GitHub Actions, Infrastructure as Code with AWS CDK, and common libraries for data processing and API integration. Operational Excellence: Track record building observability infrastructure (logging, metrics, alerting) for data-intensive applications, with experience writing runbooks and incident response procedures. Industry: Familiarity with healthcare data compliance requirements (HIPAA, data use agreements, vendor data handling) or experience in similarly regulated, quality-driven settings. Communication: Track record partnering with business leaders (director/VP level) to translate data capabilities into actionable strategies, with the ability to write executive-ready summaries. Leadership: Experience elevating team capabilities through code reviews, documentation, and knowledge sharing, with a track record of improving team standards and onboarding practices.
