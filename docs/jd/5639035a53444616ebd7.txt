The team develops cloud-native services, APIs, modern applications, and reusable platform capabilities using Azure, AWS, modern software engineering practices, CI/CD automation, and AI-assisted development. We partner with application development, infrastructure, security, data, governance, and AI teams to deliver enterprise-scale platform capabilities and integrations. How You Will Add Value Core Responsibilities You will develop and maintain modern web applications using React.js, JavaScript/TypeScript, HTML, and CSS. You will design, develop, test, and maintain scalable APIs and backend services using Java and Spring Boot. You will develop and manage APIs using Azure API Management (APIM) and follow enterprise API lifecycle and governance standards. You will build integrations across enterprise applications, third-party systems, and cloud platforms. You will support hybrid-cloud solutions spanning Azure and AWS. You will implement API security using technologies and standards such as OAuth 2.0, JWT, API keys, and mTLS. You will develop containerized services using Docker and support cloud-native deployment patterns. You will build and maintain automated deployment pipelines using GitLab CI/CD and modern DevOps practices. You will implement automated testing, monitoring, logging, and observability to improve application reliability. You will troubleshoot production issues, perform root-cause analysis, and contribute to continuous platform improvements. You will use AI-assisted development tools and coding agents to improve development, testing, debugging, and documentation productivity. You will collaborate effectively with engineers, architects, security teams, application teams, and business stakeholders to translate requirements into scalable technical solutions. You will communicate and present technical designs, architecture decisions, platform capabilities, and implementation approaches clearly to both technical and non-technical stakeholders. You will participate actively in design reviews, technical discussions, demonstrations, and knowledge-sharing sessions.
