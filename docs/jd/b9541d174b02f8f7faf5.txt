Senior Software Developer
Intercontinental Exchange
Location: Jacksonville, Florida
Link: https://careers.ice.com/jobs/13740

Job Purpose Designs, builds, and maintains full stack (.Net, Java, etc.) and Angular, React, Node, etc. applications for the organization. Work through the full software development life cycle (SDLC) and may have a focus in an Agile environment. Responsible for the development of enterprise applications. Responsibilities Designs, builds and maintains RESTful APIs in C# and .NET Core that power front-end applications and are used by internal and external partners. Designs data models and writes, reviews and tunes T-SQL, including stored procedures, indexes and query performance in SQL Server. Diagnoses and resolves performance issues using execution plans and application monitoring. Builds and maintains UI features in a modern framework such as Angular or React, working closely with the UX team. Writes technical specifications from business requirements and takes part in design reviews. Writes and reviews automated unit, component and scenario tests. Guides mid-level engineers through code reviews, pairing and design discussions, and sets the technical standard for the team. Completes documentation for installation, deployment and maintenance. Performs additional related duties as assigned. Knowledge and Experience A Bachelor’s degree in Computer Engineering, Computer Science, or other related discipline; or equivalent combination of education and experience that is required for the specific job level. Seven or more years of professional software engineering experience, including at least four years building backend services in C#/.NET. Hands-on SQL Server experience, including T-SQL, stored procedures, indexing and query performance tuning. Experience designing and building RESTful APIs and working with microservices. Full-stack experience, including production UI work in a modern front-end framework. Proficiency with automated testing, including unit, component and scenario tests. Experience with CI/CD pipelines and Agile delivery. Clear written and verbal communication with technical and nontechnical audiences. Preferred Qualifications Java and Spring Boot PostgreSQL Angular or React Cloud experience with AWS, Azure or OpenShift Experience leading or contributing to a legacy-to-modern migration Experience with AI-assisted development tools such as Claude Code or GitHub Copilot Schedule In office 5 days week.
