Salary Range $142,900.00 - $235,800.00 Target Openings 1 What Is the Opportunity? At Travelers, we're building the future of insurance — and Team Breeze is at the center of that work. This role puts you at the intersection of large language models (LLMs), cloud-native infrastructure, and real business impact. If you've shipped AI agent systems to production and want to do it again at scale, we'd like to talk. What Will You Do? Lead the design, configuration and development of complex, high-visibility AI applications on Team Breeze with a focus on LLM agents, retrieval pipelines and production reliability. Design and implement agent orchestration flows using AWS Bedrock AgentCore and/or frameworks such as LangGraph, including tool calling, routing and prompt strategies for Claude models on Bedrock. Own the retrieval-augmented generation (RAG) pipeline end to end — from document ingestion (SharePoint/LivePublish to S3), processing and embedding in Databricks, and serving from a vector store via Python retrieval APIs (FastAPI/Haystack) — including evaluation steps that measure retrieval and answer quality before each release. Architect and build services on AWS using Lambda, API Gateway, S3, CloudFront/Lambda@Edge, Route 53, Secrets Manager/Vault and Bedrock application inference profiles to track and manage cost. Develop and operate containerized retrieval and evaluation services on Amazon Elastic Kubernetes Service (EKS), deployed with Helm and ArgoCD, including OpenTelemetry collector integration exporting traces to Dynatrace, S3 and Braintrust. Implement and maintain infrastructure as code and CI/CD using Terraform (Terraform Enterprise), GitHub Actions and TEP pipelines to deliver reliable, repeatable deployments. Build and maintain the application layer across Python and TypeScript/Node 24 (Lambda xAPIs) and React 19/Vite for front-end UI experiences. Lead investigation and resolution of critical, high-impact production issues, including debugging across AWS services, Kubernetes workloads, data pipelines and observability tooling. Provide technical guidance and mentorship to teammates, fostering strong engineering practices around design documentation, testing, evaluations, code reviews and operational readiness. Continuously apply knowledge of current AI/LLM, cloud and observability trends to improve system design, developer productivity and business outcomes. Perform other duties as assigned.
