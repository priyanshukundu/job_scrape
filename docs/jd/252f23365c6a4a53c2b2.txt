The Role Key Responsibilities Frontend Engineering & Delivery Architect, build, and scale modern frontend interfaces using React or Angular designed to handle dynamic generative UI elements and real-time streaming outputs. Optimize application performance, reliable data flows, state management, authentication, and highly responsive rendering speeds. Agentic AI Development Practices Apply agentic AI development practices-using AI coding agents (such as GitHub Copilot) throughout the development lifecycle-to accelerate frontend design, coding, testing, and code review. Build frontend components that consume and render outputs from Retrieval-Augmented Generation (RAG) and multi-agent backend systems, including structured and unstructured data results delivered via streaming responses. Collaborate with backend and AI engineering teams to ensure frontend resilience when consuming LLM-powered APIs, gracefully handling latency, streaming, and error states in the UI. Customer Engagement & Solution Integrity Partner directly with subject matter experts to understand business challenges, helping to translate complex requirements into high-quality, fit-for-purpose technical architectures. Take part in end-to-end technical delivery from scoping and prototyping to production deployment, prioritizing sustainable, long-term outcomes over temporary fixes. Bridge engineering rigor with business value, communicating technical trade-offs and solution impact confidently to both technical teams and executive stakeholders. Field Intelligence & Platform Contribution Systematically capture deployment learnings, document best practices, and share insights to continuously enhance Kyndryl's core AI platforms and frameworks. Collaborate daily with engineering leads to improve deployment pipelines and cultivate an open, knowledge-sharing engineering culture. Contribute to CI/CD pipeline health for frontend build and release processes, including branching strategies, environment configuration, and deployment troubleshooting. Who You Are Required Skills and Experience 5+ years of professional software engineering experience with strong proficiency in HTML/CSS and JavaScript/TypeScript frontend development. Hands-on experience using AI coding agents and agentic development tools (such as GitHub Copilot, Cursor, or similar) as a core part of the software development lifecycle. Experience designing, building, and maintaining modern frontend applications (React or Angular), particularly handling streaming data or real-time query responses. Practical experience building frontend interfaces that consume and display outputs from Retrieval-Augmented Generation (RAG) and AI agent systems, including streaming and real-time data rendering. Solid grasp of the software delivery lifecycle, version control using Git and GitHub, and CI/CD pipelines. Experience partnering with enterprise customers and subject matter experts to translate business requirements into technical solutions and troubleshooting system performance, scalability, and reliability. Experience working on large, enterprise-scale applications with multiple integrations across business domains, not just small, standalone projects. Strong REST API integration experience, including authentication/authorization, error handling, versioning, and working with JSON across third-party and internal systems. Applies modern frontend architecture and design patterns - component-based architecture, separation of concerns, and maintainable state management - to keep codebases clean and scalable. Treats automated testing (unit, integration, and mocking) as a core part of development, not something owned solely by QA. Security-minded approach to frontend development, including secure handling of tokens and secrets, authentication/authorization flows, and awareness of common client-side vulnerabilities (such as XSS and CSRF). Comfortable diagnosing production issues - from console errors and performance bottlenecks to failed deployments and API integration problems - using logging, monitoring, and telemetry tools. Strong code quality mindset, including participating in code reviews, refactoring, managing technical debt, and following team coding standards. Degree-level qualification in Computer Science, Software Engineering, Informatics, Data Science, or a related technical field (or equivalent practical work experience). Preferred Skills and Experience Experience with frontend testing frameworks (such as Jest, Cypress, or Playwright) and component-driven design systems. Experience using AI agent tools for automated code review, test generation, or refactoring (such as Copilot Workspace, Cursor, or similar agentic coding assistants). Experience with frontend state management libraries (such as Redux, NgRx, or Zustand) and micro-frontend architectures. T-shaped technical profile with deep expertise in frontend engineering combined with broad understanding of agentic AI development practices and enterprise consulting. Active technical contributions or feedback provided to core AI platforms, open-source repositories, or internal frameworks. Experience modernizing or incrementally improving existing frontend codebases without assuming everything needs to be rewritten - particularly valuable in enterprise or public-sector environments. Active professional certifications in frontend frameworks, cloud platforms (AWS, Azure, or GCP), or AI-assisted development pathways. Advanced degree (Master's or higher) in Computer Science, Software Engineering, Data Science, or a closely related technical discipline.
