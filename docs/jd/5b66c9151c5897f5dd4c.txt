Software Engineer, Senior The Opportunity: As a full stack developer, you can resolve a problem with a complete end-to-end solution in a fast, agile environment. If you’re looking for the chance to not just develop software, but to create a system that will make a difference, we need you on our team. We’re looking for a seasoned developer like you with the expertise needed to build software and systems from vision to production ready. The ideal candidate will be responsible for designing, developing, testing, and maintaining scalable applications across both front-end and back-end systems. This role requires strong technical expertise, a collaborative mindset, and the ability to work in a fast-paced environment. What You’ll Work On: Design, develop, and maintain high-performance web applications using within Google and Amazon Cloud environments. Integrate AI and ML components and services into the application architecture to drive intelligent data processing and user-facing features. Design, develop, and maintain high-performance web applications using React for the front-end and Python for back-end services. Architect and implement efficient Extract, Transform, Load (ETL) pipelines to manage data ingestion and processing, ensuring data integrity and system performance. Collaborate with product managers and stakeholders to translate complex requirements into functional, technical solutions with a high sense of urgency. Build responsive, accessible, and intuitive user interfaces that meet the needs of our end-users. Develop robust server-side logic, APIs, and seamless integrations with external systems using Python. Participate in code reviews and continuous improvement initiatives to maintain high code quality. Troubleshoot, debug, and optimize applications for performance, specifically focusing on database interactions with MySQL. Stay up-to-date with emerging technologies and best practices in software engineering. Join us. The world can’t wait. You Have: 8+ years of experience with software development, including delivering full-stack solutions Experience with Python for back-end development and API creation Experience with modern front-end development, and writing clean, responsive HTML5 and CSS Experience designing and maintaining ETL pipelines for data-heavy applications Experience deploying and managing applications in cloud environments Experience with security best practices for web and cloud applications Knowledge of RESTful APIs, microservices, and web architecture supported by Git version control Ability to work collaboratively in a fast-paced, Agile environment Ability to obtain and maintain a Public Trust or Suitability/Fitness determination based on client requirements Bachelor's degree in Computer Science, Software Engineering, or Information Systems Nice If You Have: Experience building AI-driven features using Gemini or similar LLMs, including prompt engineering, managing frontend API state, and optimizing production applications for streaming responses and latency Ability to pay strict attention to detail and display a passion for learning new technologies Possession of excellent problem-solving skills Possession of excellent communication skills Vetting: Applicants selected will be subject to a government investigation and may need to meet eligibility requirements of the U.S. government client.
