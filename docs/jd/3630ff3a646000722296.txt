About the Role We are looking for a Senior Web Engineer to join our Post Purchase Experience (PPX) team. The PPX team owns critical post-purchase journeys for millions of diners and partners across our Web ecosystems—including core order tracking, delivery tracking for Web DaaS (Delivery as a Service), notification management, and post-checkout features like driver ratings and in-app drop-off photos. In this role, you will lead web-facing projects end-to-end, partner closely with cross-functional counterparts (Mobile, Backend, Product, Design, Data Science), drive feature delivery via modern feature flagging methodologies, and act as a web steward for the broader Diner Web ecosystem. Key Responsibilities & Scope Technical Ownership & Web Delivery Repo Management: Act as a core contributor and owner across our web properties: Diner Web: Main web application handling post-purchase order status, delivery progression, and order support. Delivery Tracking (Web DaaS): Web tracking interfaces powering enterprise and third-party delivery experiences. Notification Templates & PPX BFF Integration: Manage front-end notification views and collaborate on the PPX Backend-For-Frontend (shared with the Braveheart team). Project Ownership: Take full ownership of web projects—from dissecting product briefs, conducting spike investigations, and writing technical specs to final rollout and post-launch retrospectives. Architecture & API Design: Define clean JSON contracts and API endpoints with Backend counterparts; establish custom metrics, telemetry, and Datadog dashboards in partnership with Product. Qualifications Must-Haves Experience: 5+ years of professional software engineering experience with a focus on modern web applications (React, Next.js, TypeScript, or equivalent web frameworks). End-to-End Ownership: Proven experience taking complex features from product design (Figma) and API contract definition through build, release, and post-launch telemetry. Feature Flagging & Experimentation: Hands-on experience with feature management platforms (e.g., DevCycle, LaunchDarkly, Optimizely) for controlled rollouts and A/B testing. Monitoring & Operational Excellence: Experience setting up production observability (Datadog, Sentry, or similar), handling on-call rotations, and triaging production incidents (SEVs). Communication & Leadership: Strong cross-functional collaboration skills; comfort leading discussions across Web, Mobile, BE, Product, Design, and QA. Nice-to-Have s Experience with Backend-For-Frontend (BFF) architectures or Node.js services. Experience with CI/CD platforms (Spinnaker, Jenkins, GitHub Actions) and web deployment pipelines. Background in e-commerce, food delivery, logistics, or real-time tracking systems.
