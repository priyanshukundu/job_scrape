Software Solutions Developer I – Transportation Technology Solutions Join a team that develops innovative software solutions supporting some of the industry's most complex transportation and infrastructure projects. In this role, you will collaborate with transportation engineers, GIS specialists, planners, and software developers to create applications that improve project delivery, data management, mobility planning, asset management, and transportation decision-making. What You'll Do Collaborate with technical leads, engineers, and stakeholders to translate business and project requirements into scalable software solutions. Design, develop, test, and maintain web-based and desktop applications that support transportation planning, traffic engineering, transit, and infrastructure projects. Build new features and enhance existing applications while ensuring performance, reliability, and user experience. Develop intuitive user interfaces and workflows that simplify complex engineering and geospatial processes. Troubleshoot, debug, and optimize applications to support project teams and clients across a variety of transportation programs. Participate in code reviews, solution design discussions, and agile development activities within a collaborative technical environment. Why This Role Matters Your work will directly support transportation agencies and infrastructure programs by delivering digital tools that improve how projects are planned, designed, managed, and delivered. From GIS-integrated applications to data-driven transportation solutions, you'll help shape technology that enables smarter and more connected communities. Minimum: BA/BS + None or demonstrated equivalency of experience and/or education Experience with object-oriented programming using Java or C# . Experience developing web applications using JavaScript , AJAX , and SQL . Preferred Qualifications Experience problem-solving skills and the ability to work collaboratively within multidisciplinary project teams. Experience with modern application development frameworks and technologies, including: Hibernate ORM Velocity Template Language jQuery and jQuery UI Knockout MVVM Apache Lucene/SOLR ESRI ArcObjects API Direct Web Remoting (DWR) Kotlin TypeScript Go Rust Relocation is not an option for this position.
